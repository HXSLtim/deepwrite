# 题材指南

> 来源：web-novel-writing-skill (MIT License)
> 用途：选题确认（步骤2）、G3写作约束、题材适配模板

---

## 一、玄幻/修仙

### 核心特征
- 可量化、有层级、有规则、有特色的修炼体系
- 推荐7-9个大境界，每个分3小层
- 宗门/家族等级体系
- 天地法则（天劫、因果、气运）

### 经典套路
| 套路 | 开局 | 要点 | 代表 |
|------|------|------|------|
| 废柴逆袭 | 天赋低/被废 | 前期压抑足够 | 斗破苍穹 |
| 重生回档 | 巅峰重生 | 不能只靠信息差 | 重生之都市修仙 |
| 天才少年 | 天赋异禀遇变故 | 天外有天 | 完美世界 |
| 大器晚成 | 平凡谨慎 | 每步成长有坚实理由 | 凡人修仙传 |

### 爽点设计
- 越级战斗：幅度1-2小境界，靠技巧/宝物/体质，不靠突然爆发
- 境界突破：前3-5章铺垫，描写身体变化+天象+反应
- 前期3-5章一突破，中期10-15章，后期20-30章
- 打脸：对方先嚣张→主角低调展示→旁观者反应是放大器

### 节奏
```
小副本(10-20章) → 宗门内斗(15-25章) → 地域争霸(20-30章) → 天下大战(25-40章)
```

### 常见坑点
| 坑点 | 解决方案 |
|------|---------|
| 战力崩塌 | 建立严格战力标准表 |
| 配角工具化 | 给重要配角独立支线 |
| 地图抛弃 | 安排回访旧地 |
| 金手指贬值 | 金手指应能随主角成长升级 |
| 女角色花瓶 | 给女性角色实力和独立性格 |

## 二、都市

### 核心特征
- 现代都市背景，生活细节要真实
- 力量隐蔽，有法律/科技/社会规则约束
- 爽点来源：身份反差、财富碾压、社会地位逆袭

### 子类型
| 子类型 | 核心设定 |
|--------|---------|
| 都市异能 | 隐藏在现代社会的超自然力量 |
| 兵王回归 | 退伍/退隐强者回归都市 |
| 神医/鉴宝 | 专业领域绝技 |
| 重生经商 | 前世记忆赚钱 |
| 赘婿逆袭 | 被看不起的女婿身世惊人 |
| 都市修仙 | 在现代社会修炼 |

### 爽点设计
- 身份揭露：每圈层揭露一次（家庭→公司→城市→全国）
- 财富碾压：财富是工具不是目的
- 能力展示：层级递进，不一开始展示全部
- 感情线推进：都市文权重远高于玄幻

### 节奏
```
事件1(5-8章) → 事件2(3-5章) → 事件3(8-12章) → 事件4(10-15章) → 循环
```
3-4条并行故事线：主线+事业线+感情线+暗线

### 常见坑点
| 坑点 | 解决方案 |
|------|---------|
| 金手指过强 | 设置明确限制和强于主角的对手 |
| 后宫失控 | 控制在3-4个主要女性角色 |
| 现实逻辑崩塌 | 尊重基本社会规则 |
| 配角降智 | 反派要有合理的计谋和行动逻辑 |

## 三、言情

### 核心特征
- 以感情线为绝对主线
- 所有情节都应服务于男女主的感情发展
- 读者来看的是"爱情"

### 子类型
| 子类型 | 特点 | 核心体验 |
|--------|------|---------|
| 甜宠文 | 全程撒糖 | 甜蜜幸福感 |
| 虐恋文 | 大量误会/阻碍 | 虐心后的极致甜蜜 |
| 古言 | 古代背景 | 古典美感+权谋爱情 |
| 现言 | 现代都市 | 贴近真实生活 |
| 穿越/重生 | 时空穿越 | 信息差+逆袭+爱情 |
| 玄幻言情 | 修仙背景 | 仙侠美学+生死相恋 |

### 感情升温七阶段
```
阶段1：相遇(1-5章) → 阶段2：冲突/接触(5-15章) → 阶段3：好感萌芽(15-25章)
→ 阶段4：暧昧期(25-40章)最甜 → 阶段5：确认关系(40-50章)
→ 阶段6：考验期(50-70章) → 阶段7：HE
```

### 关键规则
> 虐的前提是"甜够了"。不甜就虐，读者只会觉得烦不会觉得心疼。
> 虐的篇幅不超过总篇幅的30%，虐后必须有加倍的甜。

### 男女主互补原则
- 外冷×活泼 = 被融化的甜
- 腹黑×天真 = 养成的甜
- 冷面×话多 = 被撩到的甜

### 常见坑点
| 坑点 | 解决方案 |
|------|---------|
| 男主过于完美 | 给一个真实的缺点或创伤 |
| 女主无自主性 | 至少一半困难由女主解决 |
| 感情跳跃 | 严格遵循七阶段模型 |
| 虐无止境 | 虐不超30%，虐后加倍甜 |
| 男主语言同质化 | 根据人设差异化对话风格 |

## 四、科幻

### 核心特征
- 力量来源是"科技"而非"灵气/魔法"
- 设定要有科学逻辑基础
- 科技发展要推动剧情

### 子类型
| 子类型 | 核心设定 |
|--------|---------|
| 星际探索 | 人类走向宇宙 |
| 赛博朋克 | 高科技低生活 |
| 末日求生 | 文明崩溃后生存 |
| 时间旅行 | 因果悖论+蝴蝶效应 |
| AI觉醒 | 人与机器的边界 |
| 文明进化 | 种族/文明升级 |
| 机甲/战争 | 驾驶机甲作战 |

### 节奏
```
探索(5-10章) → 发现(2-3章) → 理解(3-5章) → 应用(5-8章) → 新问题(1-2章) → 循环
```

### 关键规则
> 80%篇幅用于故事和角色，20%用于科技设定。
> 科技发展要有先后顺序，不能跳步。

### 常见坑点
| 坑点 | 解决方案 |
|------|---------|
| 设定过硬 | 硬核设定不超总内容15% |
| 科技发展跳跃 | 设计科技树，严格按路径推进 |
| 忽视社会影响 | 每项科技突破都应影响社会 |
| 外星人拟人化 | 设计真正异质化的外星思维 |
| 数据不一致 | 建立严格数据表 |
