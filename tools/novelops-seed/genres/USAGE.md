## 二、语料库详解

### 2.1 platform-patterns.md — 平台模式

**用途**：选题调研（步骤1）、G4平台规则门、运营包装

**内容概要**：
- **番茄小说**：前500字规则、黄金三章、4种读者动机、打脸流程、情绪节奏表
- **晋江文学城**：读者画像、热门标签、感情线七阶段、虐/甜比例规则
- **起点中文网**：长线结构、读者特征、章节标准
- **其他7个平台**：七猫/飞卢/纵横/刺猬猫/菠萝包/潇湘/红袖/17K/塔读

**使用场景**：
```
步骤1 选题市场调研 → 读取 platform-patterns.md 获取目标平台的读者画像和偏好
步骤6 运营包装     → 读取平台模式，确认章节长度和更新节奏
G4 平台规则门     → 按平台模式检查章节长度/节奏/合规
```

**关键规则速查**：

| 平台 | 章节长度 | 节奏 | 前3章要求 |
|------|---------|------|---------|
| 番茄 | {{作品设置:单章字数下限}}-{{作品设置:单章字数上限}} | 快 | 第1章必须有冲突+金手指 |
| 晋江 | 1200-2000 | 中 | 注重文笔和角色塑造 |
| 起点 | 2000-3000 | 慢热 | 前30章立住世界观 |

### 2.2 suspense-hooks.md — 钩子系统

**用途**：G3写作约束、G4钩子检查、`next-hook.md`管理

**内容概要**：
- 10种钩子类别（问题/威胁/发现/身份/倒计时/奖励/秘密/反转/决策/悬念）
- 章节结尾公式：强结尾 = 问题 × 威胁 × 发现
- 打脸钩子流程
- 好奇心缺口规则（每答案制造新问题）
- 钩子密度要求

**使用场景**：
```
G3 草稿生成   → 参考钩子公式设计章末钩子
G4 钩子检查   → 检查钩子类型、密度、是否触犯弱结尾禁令
G7 落盘      → 更新 章卡·下钩清单 的钩子台账
```

**关键密度规则**：
- 每章至少1个重大钩子
- 每场景至少1个中等钩子
- 每500-800字至少1个微小钩子

**禁止的弱结尾**：睡觉、吃饭、回家、普通聊天、无意义总结、情绪平稳结束

### 2.3 character-templates.md — 角色模板

**用途**：步骤3人物档案、G6角色一致性检查

**内容概要**：
- 6种角色模板：主角/反派/导师/对手/恋爱对象/配角
- 每种模板的元素清单和设计问题
- 角色语言档案扩展（词汇偏好/句式/口头禅/情绪表达/禁用词）
- 人设互补原则

**使用场景**：
```
步骤3 人物档案 → 根据模板创建角色，填写语言档案
G3 草稿生成   → 注入角色语言档案到prompt
G6 一致性检查 → 检查对话是否符合角色语言档案设定
```

**语言档案示例**：
```
角色：苏婉清
词汇偏好：古语词多，不用现代口语
句式特征：短句为主，反问多
口头禅："有意思" "倒是会给自己找台阶"
情绪表达：不直接说，通过动作暗示（转茶杯=在思考）
禁用词：不会说"OK""没问题"等现代词汇
```

### 2.7 anti-ai-patterns.md — 反AI模式清单

**用途**：G3禁词扫描、G5参考指标、Humanizer去AI化

**内容概要**：
- **4层检测体系**：词汇层面/句式层面/结构层面/情节层面
- **Humanizer 3-Pass流程**：Detection → Rewrite → Audit
- **质检员行动指南**：3次以上禁用→重要问题，机械降神→致命问题
- **可自动化的正则规则**（已集成到指标自检（文风六卡·卡6 体检清单））

**使用场景**：
```
G3 草稿生成   → 写作时参考禁用词/句式/叙事清单规避
G5 指标门禁   → 指标自检（文风六卡·卡6 体检清单）自动检测AI模式，输出命中详情
G3→G5 修复   → 根据命中详情，参考Humanizer 3-Pass改写
```

**4层检测速查**：

| 层面 | 检测内容 | 严重度 |
|------|---------|--------|
| 词汇 | 不禁/竟然/一股XX涌上心头/嘴角微微上扬 | 3次以上→重要 |
| 句式 | 随着...也.../他不知道的是/仿佛...一般 | 3次以上→重要 |
| 结构 | 战斗三步曲/完美对话/角色同质化 | 严重 |
| 情节 | 机械降神/无代价胜利/全员崇拜 | 致命→重写 |

## 三、Prompt模板详解

### 3.1 writer-prompt.md — 写作Agent

**用途**：G3草稿生成时的系统prompt参考

**核心指令**：
1. **写作优先级**：冲突 > 好奇心 > 情感 > 进度 > 描写
2. **场景公式**：每个场景必须包含目标/冲突/风险/神秘/决策
3. **章节公式**：开头→冲突→升级→决策→钩子
4. **反AI约束**：30+禁用词、5类禁用句式、5类禁用叙事
5. **留存检查清单**：冲突/好奇心/进度/情感张力/钩子/结尾期待

**集成方式**：
```
G3 步骤3 草稿生成时：
  1. 读取 writer-prompt.md 作为系统prompt参考
  2. 读取 genre-guides.md 获取题材适配参数
  3. 读取 anti-ai-patterns.md 获取禁用清单
  4. 注入角色语言档案（来自 character-templates.md）
  5. 按场景类型（冲突/日常/过渡）调整对话占比
```

---

### 3.2 editor-prompt.md — 编辑Agent

**用途**：G5/G6质量审查时的系统prompt参考

**7步审查流程**：
1. 剧情逻辑 → 2. 角色一致性 → 3. 力量一致性 → 4. 节奏 → 5. 对话 → 6. 钩子质量 → 7. AI痕迹检测

**AI痕迹自动扫描清单**（10项）：
- 频繁使用"不禁""竟然""居然"
- "一股强大/无形的力量"空洞描述
- "仿佛...般"模板比喻
- 连续段落相同句式开头
- 排比句超过两组
- 所有角色语气趋同
- 过度心理旁白标记
- 段尾连续感叹号/省略号
- 总结性时间过渡
- 战斗模式模板化

**严重性分级**：

| 级别 | 说明 | 处理 |
|------|------|------|
| 🔴致命 | 违反硬性规则、逻辑硬伤 | 阻断发布 |
| 🟠严重 | 设定矛盾、大量AI痕迹 | 强烈建议修复 |
| 🟡重要 | 小偏差、节奏微调 | 建议修复 |
| 🟢建议 | 文笔可提升 | 可选 |

---

### 3.3 humanizer-prompt.md — Humanizer去AI化

**用途**：G3草稿生成后的去AI化处理、G5参考指标

**3-Pass流程**：

```
Pass 1: Detection（检测）
  扫描10类AI模式：
  1. AI词汇 → 2. 夸张抬高 → 3. 同义词循环 → 4. 叙事犹豫
  5. 机械排比 → 6. 泛化描述 → 7. 对话标签滥用 → 8. 情感标签
  9. 华丽堆砌 → 10. 系动词回避

Pass 2: Rewrite（重写）
  保留：作者voice、角色对话模式、有意文学手法
  改写：按通用改写原则表替换

Pass 3: Audit（审计）
  最终扫描，确保无遗漏
```

**通用改写原则速查**：

| AI模式 | 改写方向 |
|--------|---------|
| "不禁皱眉" | "眉头拧在一起" |
| "一股暖流涌上心头" | "眼眶微热" |
| "嘴角微微上扬" | "挑了挑眉" |
| "他感到非常愤怒" | "手指陷进掌心的肉里，指节发白" |
| "随着修炼的深入" | "又一个月过去了。当他再次凝聚灵力时" |

**已集成到指标自检（文风六卡·卡6 体检清单）的正则规则**：
- 30+ AI典型模式正则（词汇/句式/叙事）
- `calc_ai_pattern_density()` 函数自动检测
- 2项参考指标：`ai_pattern_total`（≤3）、`ai_pattern_density`（≤0.05）

### 4.2 G3写作流程（集成后）

```
G3 步骤1：加载上下文
  → 读取大纲、角色档案、前章状态、伏笔表
  → 读取 genre-guides.md 获取题材参数
  → 读取 character-templates.md 获取角色语言档案

G3 步骤2：场景规划
  → 按 Scene-Sequel 引擎设计 Goal/Conflict/Disaster/Sequel
  → 参考 suspense-hooks.md 选择钩子类型

G3 步骤3：草稿生成
  → 使用 writer-prompt.md 作为系统prompt
  → 注入 anti-ai-patterns.md 禁用清单
  → 按题材参数调整对话占比

G3 步骤4：禁词扫描
  → 扫描 anti-ai-patterns.md 中的禁用词/句式
  → 扫描 G3原有敏感词（政治/色情/暴力）

G3 步骤5：Humanizer去AI化（可选）
  → 按 humanizer-prompt.md 3-Pass流程处理
  → Pass1检测 → Pass2改写 → Pass3审计
```

### 4.3 G5指标门禁（集成后）

**硬门禁（7项，不通过则拒绝）**：

| 指标 | 阈值 | 说明 |
|------|------|------|
| σ² | ≥8 | 句长标准差 |
| TTR | ≥0.40 | 用词多样性 |
| Pσ² | ≥20 | 段长标准差 |
| BurstCV | ≥0.40 | 句长变异系数 |
| ParaCV | ≥0.30 | 段长变异系数 |
| 3gramRep | ≤0.08 | 3-gram重复率 |
| 3gramUniq | ≥0.85 | 3-gram唯一率 |

**参考指标（9项，仅预警）**：

| 指标 | 阈值 | 说明 |
|------|------|------|
| EGR | ≤2.0 | 情感颗粒度比 |
| Cσ² | ≥0.15 | 过渡词密度方差 |
| Iσ² | ≥1.8 | 信息密度方差 |
| 对话占比 | 5%-65% | 对话字符/总字符 |
| 标点CV | ≥0.30 | 标点间距变异系数 |
| Telling总数 | ≤5 | Show Don't Tell违规数 |
| Telling密度 | ≤0.15 | Telling/总句数 |
| **AI模式总数** | **≤3** | 反AI检测命中数 |
| **AI模式密度** | **≤0.05** | AI模式/总句数 |

## 五、使用示例

### 5.1 启动新书时

```
步骤1 选题调研：
  → 读取 platform-patterns.md
  → 获取番茄/晋江等平台模式和读者画像
  → 结合 WebSearch 搜索2026年市场数据

步骤2 选题确认：
  → 读取 genre-guides.md
  → 选择题材（如古言宫斗），确认套路和爽点设计

步骤2.5 核心创意卡：
  → 读取 power-system-templates.md
  → 设计金手指/力量体系

步骤3 人物档案：
  → 读取 character-templates.md
  → 按模板创建角色，填写语言档案

步骤6 运营包装：
  → 读取 title-patterns.md
  → 选择标题公式，生成Top5标题
```

### 5.2 每章写作时

```
G3 草稿生成：
  → 读取 writer-prompt.md（写作Agent prompt）
  → 读取 genre-guides.md（题材参数）
  → 读取 anti-ai-patterns.md（禁用清单）
  → 注入角色语言档案
  → 生成草稿

G3 禁词扫描：
  → 按 anti-ai-patterns.md 扫描禁用词/句式/叙事

G5 指标检测：
  → python 指标自检（文风六卡·卡6 体检清单） chapter.txt
  → 检查7项硬门禁 + 9项参考指标
  → 查看AI模式命中详情

G5 未通过时修复：
  → 读取 humanizer-prompt.md
  → 按3-Pass流程改写命中段落
  → 重新检测
```

### 5.3 指标检测命令

```bash
# 基础检测（7硬门禁 + 9参考指标，含AI模式检测）
python 指标自检（文风六卡·卡6 体检清单） chapter.txt

# JSON输出（供程序读取）
python 指标自检（文风六卡·卡6 体检清单） chapter.txt --json

# 启用AITextDetector第二层参考检测
python 指标自检（文风六卡·卡6 体检清单） chapter.txt --aitext

# 模仿评价（对比两段文本）
python 指标自检（文风六卡·卡6 体检清单） chapter.txt --compare sample.txt
```
