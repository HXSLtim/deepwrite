## 一、番茄小说

### 1.1 核心原则

> 读者不是在读小说，是在追情绪。每本成功故事至少满足以下一种：力量幻想、复仇、好奇心、愿望满足、浪漫、生存、成长、身份优势。

### 1.2 前500字规则

前500字决定生死。必须包含：

* 引入主角

* 引入冲突

* 引入好奇心

* 引入承诺

禁止：世界构建、背景解释、长描写、信息倾倒。

### 1.3 三种开场类型

| 类型   | 读者情绪 | 示例              |
| ---- | ---- | --------------- |
| 屈辱开场 | 愤怒   | 离婚、背叛、驱逐        |
| 力量觉醒 | 兴奋   | 系统激活、特殊能力、传承、重生 |
| 生存危机 | 紧张   | 末日、灾难、战争、逃生     |

### 1.4 黄金三章

* 第1章：钩子、问题、冲突

* 第2章：升级、压力、障碍

* 第3章：反转、反击、新机会

### 1.5 四种读者动机

| 动机   | 读者想要什么          |
| ---- | --------------- |
| 力量幻想 | 影响力、地位、掌控、认可    |
| 复仇   | 正义、惩罚、打脸时刻、洗刷冤屈 |
| 成长   | 可见进步、新能力、成就、里程碑 |
| 好奇心  | 答案，每个答案制造新问题    |

### 1.6 打脸设计流程

屈辱 → 压抑 → 证据 → 反转 → 观众震惊 → 认可

### 1.7 留存信号

* 强信号：冲突、神秘、竞争、倒计时、危险、秘密、目标

* 弱信号：描写、旅行、反思、解释、日常

### 1.8 情绪节奏

* 每3-5章：奖励

* 每8-12章：重大回报

* 每20-30章：里程碑事件

* 绝不可过度延迟奖励

### 1.9 章节结尾公式

必须包含：问题、威胁、发现、决策、秘密。
禁止以：旅行、睡觉、吃饭、日常行动结尾。

## 二、晋江文学城

### 2.1 读者画像

* 以女性为主（18-35岁）

* 对文笔和角色塑造要求高

* 偏好情感细腻、有深度的作品

* 重视角色成长弧光

### 2.2 热门标签

甜宠、穿书、重生、宫斗宅斗、年代文

### 2.3 节奏特点

* 允许慢热，但角色互动要密

* 感情线七阶段：相遇→冲突→好感→暧昧→确认→考验→HE

* 虐的前提是"甜够了"，不甜就虐读者只会觉得烦

* 虐的篇幅不超过总篇幅的30%，虐后必须有加倍的甜

### 2.4 内容审核

晋江有严格的内容审核，注意尺度。

## 三、起点中文网

### 3.1 读者画像

* 男性18-40岁

* 长篇小说读者

* 偏好深度世界观

* 要求逻辑自洽

* 能接受慢热

* 偏好一致规则、历史背景、探索机会、可见成长

### 3.2 结构特点

长线结构：Early Arc → Mid Arc → Expansion Arc → Endgame Arc
延迟满足、大规模回报。

### 3.3 章节标准

* 日更4000-6000字

* 单章2000-3000字

* 前30章立住人设和世界观
