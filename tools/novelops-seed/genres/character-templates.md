# 角色模板

> 来源：Chinese-WebNovel-Master (MIT License)
> 用途：步骤3人物档案、G6角色一致性检查
> 强约束：**角色性格差异必须明显**，每个角色的行为方式、说话风格、决策逻辑必须可区分

---

## 一、主角模板

**目的**：推动故事前进。

**元素**：
- 核心欲望
- 外部目标
- 内在需求
- 致命缺陷
- 隐藏优势
- 成长弧线

**设计问题**：
- 主角想要什么？
- 为什么得不到？
- 必须成为什么才能成功？

**性格行为特征卡**（必须填写，G6硬检查）：

| 维度 | 特征 | 具体行为规则（DO / DONT） |
|------|------|------------------------|
| 决策方式 | 冲动型 / 三思型 / 直觉型 / 算计型 | DO：遇到危机时先行动再想 / 先分析再行动<br>DONT：从不做无准备的冒险 / 不会冲动行事 |
| 情绪表达 | 外放型 / 隐忍型 / 面瘫型 / 情绪化型 | DO：开心就大笑 / 从不把情绪写在脸上<br>DONT：不在敌人面前示弱 / 不会当众哭 |
| 说话风格 | 话少型 / 话痨型 / 毒舌型 / 温柔型 / 官方型 | DO：每句不超5字 / 喜欢开玩笑 / 说话带刺<br>DONT：不说废话 / 不会说甜言蜜语 / 不轻易许诺 |
| 待人方式 | 信任型 / 多疑型 / 礼貌型 / 冷淡型 | DO：对陌生人保持警惕 / 对弱者有同情心<br>DONT：不轻易相信别人 / 不会主动讨好 |
| 面对冲突 | 硬刚型 / 避战型 / 智取型 / 嘴炮型 | DO：能动手就不吵 / 用计谋化解 / 用说话气死对方<br>DONT：不做无意义的争斗 / 不会退缩 |
| 价值观底线 | 有明确红线 / 利益至上 / 原则灵活 | DO：绝不伤害无辜 / 恩仇必报<br>DONT：不会背叛朋友 / 不会为利益牺牲底线 |

**语言档案扩展**：
- 词汇偏好（古语/现代/方言）
- 句式特征（短句/长句/反问多）
- 口头禅（每章至少2次）
- 情绪表达方式（不直接说，通过动作暗示）
- 禁用词（角色不会说的词）

**语言区分度要求**（G6硬检查）：
- 主角与主要配角的说话方式必须有可感知的差异
- 每个主要角色至少有1个独特的语言标记（口头禅/句式/词汇偏好）
- 对话中不标注"XX说"也能通过语气猜出是谁在说话

## 二、反派模板

**目的**：创造有意义的对抗。

**元素**：
- 目标
- 资源
- 权力基础
- 动机
- 弱点

**规则**：
- 反派坚信自己是正确的
- 反派必须有可理解的动机
- 反派的行动应基于核心动机，不是纯粹为激怒主角
- 保留质疑者、嫉妒者或根本不关心主角的人

**性格行为特征卡**（必须填写，G6硬检查）：

| 维度 | 特征 | 具体行为规则（DO / DONT） |
|------|------|------------------------|
| 决策方式 | 谋略型 / 霸道型 / 隐忍型 / 疯狂型 | DO：步步为营 / 说一不二<br>DONT：不会亲自下场 / 不会给对手第二次机会 |
| 情绪表达 | 伪善型 / 冷酷型 / 歇斯底里型 / 淡定型 | DO：表面温和内心毒辣 / 情绪不外露<br>DONT：不会在下属面前失态 / 不会轻易动怒 |
| 说话风格 | 文雅型 / 威严型 / 阴阳怪气型 / 直白残忍型 | DO：说话引经据典 / 命令式语气 / 喜欢话里有话<br>DONT：不会说废话 / 不会跟蝼蚁讲道理 |
| 待人方式 | 驭下型 / 轻视型 / 利用型 / 偏执型 | DO：对下属恩威并施 / 把人当棋子<br>DONT：不信任任何人 / 不会真正尊重谁 |
| 面对冲突 | 碾压型 / 借刀杀人型 / 猫鼠游戏型 / 逃遁型 | DO：喜欢看对手绝望 / 从不脏自己的手<br>DONT：不会给对手公平对决的机会 / 赢了就赶尽杀绝 |
| 价值观底线 | 有底线的恶 / 无底线的恶 / 自认为正义 | DO：不妇孺下手 / 有恩报恩有仇报仇（自己的逻辑）<br>DONT：不杀降（骄傲） / 不会违背自己的准则 |

## 三、导师模板

**目的**：引导主角。

**元素**：
- 知识
- 秘密
- 限制
- 教学风格

**常见功能**：
- 引入世界
- 解释力量体系
- 触发成长

**性格行为特征卡**（必须填写，G6硬检查）：

| 维度 | 特征 | 具体行为规则（DO / DONT） |
|------|------|------------------------|
| 教学风格 | 严厉型 / 放养型 / 引导型 / 嘴硬心软型 | DO：对徒弟要求极高 / 让徒弟自己摸索<br>DONT：不会直接给答案 / 不会轻易夸徒弟 |
| 说话方式 | 玄奥型 / 直白型 / 调侃型 / 沉默型 | DO：说话说一半 / 喜欢用比喻<br>DONT：不会把话说死 / 不多管闲事 |
| 性格底色 | 深藏不露 / 老顽童 / 冷面热心 / 看破红尘 | DO：平时嘻嘻哈哈关键时候靠谱 / 外表冷漠内心关心<br>DONT：不会炫耀实力 / 不轻易出手 |

## 四、对手模板

**目的**：制造竞争。

**元素**：
- 相似目标
- 不同方法
- 持续比较

**好处**：
- 激励主角
- 创造张力
- 展现成长

**性格行为特征卡**（必须与主角形成对比，G6硬检查）：

| 维度 | 主角特征 | 对手特征（必须相反/不同） | 对比效果 |
|------|---------|------------------------|---------|
| 决策方式 | [主角类型] | [相反类型] | 同样局面做出完全不同的选择 |
| 行事风格 | [主角风格] | [相反风格] | 道不同不相为谋 |
| 说话方式 | [主角风格] | [相反风格] | 对话中天然有张力 |
| 价值观 | [主角底线] | [不同/相反底线] | 核心冲突来源 |

> **铁律**：对手与主角至少在3个维度上有明显差异，否则人设同质化。

## 五、恋爱对象模板

**目的**：创造情感参与。

**元素**：
- 吸引力
- 冲突
- 兼容性
- 情感赌注

**规则**：
- 感情线必须影响剧情
- 关系必须演变
- 女性角色要有独立人格和自己的事业/目标

**性格行为特征卡**（必须与主角形成互补/碰撞，G6硬检查）：

| 维度 | 主角特征 | 恋爱对象特征 | 化学反应类型 |
|------|---------|------------|-------------|
| 外冷 × 活泼 | 冷面寡言 | 热情话多 | 被融化的甜 |
| 腹黑 × 天真 | 心思深沉 | 单纯直率 | 养成的甜 |
| 强势 × 不服输 | 控制欲强 | 倔强独立 | 强强碰撞 |
| 话多 × 毒舌 | 活泼话痨 | 毒舌吐槽 | 欢喜冤家 |

> **铁律**：恋爱对象与主角必须在至少2个核心性格维度上形成互补或碰撞，不能太相似。

## 六、配角模板

**目的**：增强主卡司。

**功能**：
- 盟友
- 笑料
- 情报提供者
- 专家
- 情感支持

**规则**：
- 每个配角必须至少服务一个故事功能
- 重要配角应有独立支线

**性格标签**（每个配角至少1个鲜明标签）：
- 搞笑担当 — 负责调节气氛，说话自带梗
- 靠谱担当 — 稳重可靠，关键时刻不掉链子
- 神秘担当 — 话少，背景成谜
- 冲动担当 — 热血上头，经常闯祸
- 理智担当 — 冷静分析，团队大脑
- 毒舌担当 — 说话扎心，但心地不坏
- 温柔担当 — 体贴细心，治愈系
- 傲娇担当 — 嘴硬心软，口是心非

> **铁律**：每个配角必须有且只有1个核心性格标签，确保辨识度。不能"什么都会一点"。

---

## 七、人设互补原则

- 外冷男主 × 活泼女主 = 被融化的甜
- 腹黑男主 × 天真女主 = 养成的甜
- 冷面女主 × 话多男主 = 被撩到的甜
- 核心：两人的性格要"互补"或"碰撞"，不能太相似

## 八、性格区分度校验清单（G6硬检查）

> G6门禁必须逐项检查，不通过则打回G3重写。

| 检查项 | 标准 | 验证方式 |
|--------|------|---------|
| 主要角色语言可区分 | 去掉"XX说"也能猜出说话人 | 对话抽样测试：随机抽3段对话，能否准确识别说话人 |
| 决策方式不重复 | 主角/反派/对手/导师的决策逻辑各不相同 | 列出4个角色面对同一危机的选择，不能雷同 |
| 性格标签不撞车 | 每个主要角色的核心标签唯一 | 检查所有主要角色的性格特征卡，无重复标签 |
| 行为规则一致 | 角色行为符合其性格特征卡的DO/DONT | 本章中每个有台词的角色，行为不违反特征卡 |
| 情绪表达有差异 | 同样的情绪（愤怒/开心/悲伤）每个角色表达方式不同 | 愤怒时：有人摔东西/有人冷笑/有人沉默/有人说话更客气 |
| 说话节奏可区分 | 每个角色的句长分布/用词偏好有差异 | fingerprint.json中SC系数<0.75 |
