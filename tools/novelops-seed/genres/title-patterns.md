# 标题公式

> 来源：Chinese-WebNovel-Master (MIT License)
> 用途：步骤6运营包装、packaging.md

---

## 核心原则

> 标题不是摘要，是广告。
> 目的是：让读者点击。

---

## 10种标题公式

| 公式 | 模式 | 示例 |
|------|------|------|
| 身份+机遇 | 我+获得+特殊能力 | 我能看到隐藏信息 |
| 身份+反转 | 我本来是X，却成为Y | 离婚后，我成了首富 |
| 身份+系统 | 身份+系统 | 外卖员：我的系统太争气了 |
| 重生 | 重生+时间节点 | 重生2008：从摆摊开始 |
| 末世 | 末世+优势 | 末世：我提前囤积十万吨物资 |
| 直播 | 直播+特殊能力 | 直播鉴宝：开局捡漏亿元古画 |
| 财富增长 | 普通人+财富跃迁 | 摆摊十年，我成了首富 |
| 科技 | 获得未来科技 | 获得未来芯片技术后 |
| 修仙 | 凡人+修仙优势 | 凡人修仙：我能无限顿悟 |
| 学院 | 学生+特殊能力 | 高考前，我觉醒学神系统 |

---

## 高CTR关键词

| 类型 | 关键词 |
|------|--------|
| 都市 | 神豪、首富、直播、鉴宝、校花、科技、商业 |
| 玄幻 | 长生、顿悟、无敌、飞升、仙帝、神体 |
| 末世 | 囤货、求生、避难所、灾难、进化 |
| 悬疑 | 诡异、规则、禁忌、怪谈、死亡 |
| 言情 | 闪婚、重生复仇、穿书、替身、追妻 |

---

## 标题生成工作流

1. 确定类型
2. 确定目标受众
3. 确定核心卖点
4. 选择标题公式
5. 生成20个标题
6. 按CTR潜力排序
7. 输出Top 5
