# 悬念钩子系统

> 来源：Chinese-WebNovel-Master (MIT License)
> 用途：G3写作约束、G4钩子检查、next-hook.md管理

---

## 核心规则

> 每章结尾必须至少有一个钩子。绝不能在完全解决的状态下结束一章。
> 读者继续阅读是因为未解决的张力。当张力消失，留存崩溃。

---

## 10种钩子类别

| 类型 | 读者情绪 | 示例 |
|------|---------|------|
| 问题钩子 | 好奇心 | 那封信里到底写了什么？ |
| 威胁钩子 | 恐惧/紧迫感 | 三天后，怪物将进入城市 |
| 发现钩子 | 好奇心/期待 | 保险柜里竟然是她的照片 |
| 身份钩子 | 惊喜/地位反转 | 原来校花就是幕后老板 |
| 倒计时钩子 | 紧迫感 | 距离灾难降临还有24小时 |
| 奖励钩子 | 期待 | 奖励将在明天发放 |
| 秘密钩子 | 神秘 | 地下室还有第二层 |
| 反转钩子 | 震惊 | 任务奖励竟然变成惩罚 |
| 决策钩子 | 紧张 | 两条路，只能选一条 |
| 悬念钩子 | 不安 | 他为什么突然沉默了？ |

---

## 章节结尾公式

强结尾 = 问题 × 威胁 × 发现

```
示例：
他打开保险柜。
里面竟然是一张自己的死亡证明。
与此同时。
系统提示：
死亡倒计时开始。
```

---

## 打脸钩子

屈辱 → 挑战 → 证据 → 反转 → 认可 → 新威胁
绝不能在胜利后停止，必须引入更大挑战。

---

## 好奇心缺口规则

绝不全回答问题。每给一个答案，必须制造一个新问题：
```
问题A → 答案A × 问题B → 答案B × 问题C
```

---

## 钩子密度

- 每章至少一个重大钩子
- 每个场景至少一个中等钩子
- 每500-800字至少一个微小钩子

---

## 弱结尾（禁止）

睡觉、吃饭、回家、普通聊天、无意义总结、情绪平稳结束。

---

## 钩子质量检查清单

- [ ] 未回答问题存在
- [ ] 暗示未来事件
- [ ] 情绪张力残留
- [ ] 读者想看下一章
- [ ] 好奇心水平高
- [ ] 冲突未解决
