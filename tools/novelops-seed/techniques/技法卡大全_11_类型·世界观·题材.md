## `novel-how-act-cute` · 撒娇怎么写


# 撒娇怎么写

## 适用场景
- 角色用撒娇达成目的（要资源/求原谅/博关注）
- 想写"嗲而不腻"自然不尴尬
- 避免工业糖精式硬撒娇让读者出戏

## 核心技法
- **真心关心用嫌弃语气**：[角色B]受伤，[角色A]冒雨探视，开口却责备"你跑来干什么容易中暑，我这点伤都是装的"——句句赶人，字字担心，留白拉满
- **嘴硬心软反话**：嘴上"谁愿意专门等你"却提前半小时楼下等；"我才懒得管你"转头追问有没有按时吃饭——真心用冷淡语气说
- **小动作藏依赖**：扯衣角、拽袖子、声音压低拖长尾音、用称呼撒娇（哥/叔/老板），动作比语言先暴露
- **反差感**：平时冷面的人偶尔露一次软，杀伤力最大；日常爱怼人的人突然服软，读者嗑疯
- **分寸**：撒娇要有人格基础，铁血硬汉突然嗲违和；用在"只在特定人面前卸防"最动人

## 可直接套用模板/清单
- [ ] 撒娇有没有性格基础？（只对特定人卸防？）
- [ ] 用反话/嫌弃语气而非直白卖萌？
- [ ] 小动作是否先于语言暴露依赖？
- [ ] 平时冷面偶尔软，反差够不够？
- [ ] 自查：嗲而不腻，还是工业糖精？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 撒娇是反差不是常态，用在卸防瞬间最贵

## `novel-how-ancient` · 古风/古代场景怎么写


# 古风/古代场景怎么写

## 适用场景
- 古风、古代背景的院落、街道、市井、山水、室内
- 需要"几句就活"而非说明书式冗长描写
- 营造时代感与氛围

## 核心技法
- **从感官入手，让读者身临其境**：别只写看到的，调动所有感官。眼睛靠色彩与光影魔术——最忌堆砌颜色名词，要让东西动起来、有光影变化（如"青石板路泛着潮，昨夜雨水没干透，映着天光像撒了一层碎银子"）。
- **找到属于那个时代的"BGM"（听觉时代感）**：现代有车流声，古代用更夫梆子声、酒馆划拳声、乡野蛙鸣虫噪、富贵人家漏壶滴水声/绣花针穿过绸缎的摩擦声/熏炉炭火噼啪。声音最能建立时代氛围。
- **简短又传神的白描**：古代环境最怕写太细像念说明书。用"青石板、幌子、货郎、露珠"意象组合出清晨市井鲜活劲儿，不写"热闹"二字。
- **院子写法多维度**：植物（果树花树在不同时辰的姿态）、建筑布局（影壁、游廊、坐凳栏杆、什锦窗）、院中活动（花下饮酒、闲庭信步）、感受（心灵慰藉）、细节（砖石、青苔）。
- **开头环境钩子**：先抑后扬（破败后院引出隐藏神秘）、先扬后抑（奢华院落暗藏危机）、烘托法（晚霞归鸟引主角）、楔子伏笔（风雨夜古堡若隐若现）。
- **修辞让场景生动**：比喻、拟人、象征——如"月光洒在古街，银白光芒在青石板上跳跃如繁星；屋檐风铃轻摇诉说古老故事"。

## 可直接套用模板/清单
- **时代感官模板**：视觉（色彩+光影变化，避免堆名词）→ 听觉（找1个时代专属声音：梆子/划拳/漏壶/蛙鸣）→ 嗅觉/触觉（烟火气/布料触感）→ 不写"热闹/安静"等概括词。
- **院子白描清单**：植物时态 + 建筑构件 + 一处活动 + 一个细节（青苔/砖石）+ 人物感受。
- **古风开头四选一**：先抑后扬 / 先扬后抑 / 烘托引主角 / 楔子伏笔。
- **简短诀窍**：写完后删掉所有"很X/非常X"概括词，用1个具体意象替代。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 避免说明书式罗列；简短传神优于冗长细描。

## `novel-how-campus` · 校园场景怎么写


# 校园场景怎么写

## 适用场景
- 校园、青春背景的教室、操场、宿舍、食堂、走廊、图书馆
- 需要青春质感与"会动的照片"式画面
- 用环境外化学业压力、友情、暗恋、孤独

## 核心技法
- **场景=会动的照片**：不能只写"有什么"，还要写时间（清晨/考试前）、地点、人物在做什么、氛围。例："午后两点，阳光斜照进教室。老师翻课本，粉笔嗒嗒响。我坐第三排，闻到铅笔木香。"
- **镜头感写作（导演式）**：
  - 远景/空镜头：定基调，如"夕阳透过高窗将教室切成明暗方块，成排桌椅拉出长影，空气浮着粉尘，角落那人像静止岛屿"。
  - 中景：展人物关系与动作，如小组讨论四人脑袋凑一起。
  - 特写：锁关键细节直击人心，如"笔尖在两指间微颤，指节发白，试卷上'期末考试'四字像印章压住视野"。
  - 慢动作：放大高光时刻制造悬念或强调情感。
- **三层感官法（超越简单五感）**：外在感官（客观刺激：墙皮受潮像死皮、铁锈混霉味）→ 身体反应（后背一凉、汗毛竖起、鸡皮疙瘩）→ 情绪共振（心跳如捶胸腔、想起童年躲猫猫的窒息）。三层叠加读者才从"知道"变"感觉到"。
- **动态触发而非静态罗列**：不写"教室有黑板课桌"，写"他走进，手指划过桌沿一层灰；黑板留着昨天板书的半句话被蹭花一角；窗外拍球声一声两声忽然停了；阳光从篮球架方向斜射把影子投在讲台"。动态核心是"视角移动"——用脚步/目光/手电带动。
- **用声音定义空间**：早自习铃声如刀划破寂静；课间走廊炸开锅像煮沸的粥；放学操场只剩篮球撞击声敲在黄昏里；深夜宿舍静得能听到水管汩汩与心跳。声音瞬间建立真实感。
- **时间流转串联**：以一天为明线（晨起/课堂/午休/晚自习/熄灯），以标志物（校服/空调/铃声）为暗线，把平凡日常升华为有温度的青春叙事；光影是最好的画笔（被切碎的金箔般阳光、梧桐固执的绿荫、窗上扭曲的雨）。

## 可直接套用模板/清单
- **镜头模板**：远景定调（光影切割空间+长影+粉尘）→ 中景人物互动 → 特写关键细节（颤抖的手/试卷字/衣角）→ 可选慢动作放大高光。
- **三层感官模板**：外在刺激(1-2句) → 身体反应(凉/颤/疙瘩) → 情绪共振(记忆闪回/心跳)。
- **校园声音库**：铃声(刀/边界)、课间(煮沸的粥)、放学(篮球叩黄昏)、深夜(水管+心跳)。
- **时间锚点**：给场景标一个具体时刻（五点五十/午后两点/晚自习），比"有一天"更有画面。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 避免说明书式静态罗列；让画面动起来、让感官分层。

## `novel-how-cold-war` · 冷战怎么写


# 冷战怎么写

## 适用场景
- 关系出现裂痕但不至于分手/决裂
- 想写"此时无声胜有声"的张力
- 避免大段对话解释"我为什么不理你"

## 核心技法
- **牺牲语言，用动作/神态/心理深入刻画**：冷战不是"不说话"三个字概括，而是具体行为——闺蜜和老公因买房吵架冷战，仍每天起床给老公准备早餐、打领带、擦皮鞋、收拾公文包。没语言，但全是戏
- **细节暴露在意**：偷偷看对方、把对方爱吃的留着、路过时脚步放慢又忍住——肢体比嘴诚实
- **单方视角的内心戏**：用不说话那方的心理活动写"其实还在乎"，读者比角色自己先看穿
- **破冰要小**：别突然和好，用一个微小动作破冰（递杯水/顺手盖毯子），比长篇和解真实
- **别拖太久**：冷战是调味不是主菜，三五章内要有松动信号，否则读者烦

## 可直接套用模板/清单
- [ ] 冷战有没有具体行为？（做早餐/偷看/留东西）
- [ ] 用动作代替"他不理我"的概括？
- [ ] 单方内心戏是否暴露"还在乎"？
- [ ] 破冰动作小而不突兀？
- [ ] 时长控制在读者不烦的范围？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 冷战靠行为不靠解释，无声胜有声

## `novel-how-court` · 宫廷/权贵场景怎么写


# 宫廷/权贵场景怎么写

## 适用场景
- 宫廷、皇宫、王府、豪门府邸、权贵社交场
- 需要以空间与器物暗示权力结构与人物命运
- 宫斗/权谋类场景的氛围与冲突设计

## 核心技法
- **用建筑规制与空间叙事立权势**：以中轴线/核心建筑为锚，由外到内、由市井到权力核心，写"一步之隔两个世界"的界限感（朱红城门、石狮、值守侍卫、渐褪的喧嚣与被庄严肃穆取代）。府邸按亲近皇权程度呈辐射格局，一砖一瓦彰显身份与家族底蕴。
- **用器物与细节增强代入，而非堆砌奢华词**：寝殿可用"云顶檀木为梁、珍珠为帘、沉香木阔床、鲛绡宝帐"等具体材质构筑奢华实感；但更高级的是用细节暗示状态——"窗内红烛摇曳，窗外细雨横斜，积水顺檐滴落晕开涟漪，似叹息似挽留"，以景写人。
- **象征手法：用环境暗示人物命运**：凋零的花象征失宠，繁盛奇花暗示生机或反常；院落前后景反差（外院奢华 vs 后院清贫）折射人物表里。空间格局可直接设计情节（御花园偶遇、长廊对峙）。
- **权谋语言心机融入场景**：语言言此意彼、话中藏话（"姐姐今日气色真好"暗讽）；行为心机（示弱实则试探）；布局心机（计谋链条）。对白符合身份位分，最伤心的话用最平淡语气说出。
- **冲突场景设计**：关键道具（首饰、信件）引发冲突；预设突发事件应对；通过环境渲染张力。空间即权力关系的可视化。
- **留白与反差**：豪奢场面下写"糜蘭将人性腐朽殆尽"的暗面；或以"朱红大门顶悬黑金丝楠木匾额"的冷峻对比暖调奢饰，制造表里张力。

## 可直接套用模板/清单
- **空间权力模板**：选核心建筑 → 由外到内写"界限感"（喧嚣→肃穆的过渡物：门/狮/侍卫）→ 辐射格局显亲疏 → 一处前后景反差折射人物。
- **器物象征清单**：选1-2件器物/植物作命运符号（花之荣枯、帘之开合、烛之明灭）；用具体材质词替代"金碧辉煌"概括。
- **权谋对白自检**：本场对话是否含"明褒暗贬/话中藏话/示弱试探"之一？是否符合说话者位分？
- **冲突三要素**：关键道具 + 意外转折 + 环境张力渲染。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 避免只有"金碧辉煌"式堆砌；要让空间与器物承载叙事与命运。

## `novel-how-doomsday` · 末日文怎么写


# 末日文怎么写

## 适用场景
- 灾变/病毒/天灾后的世界，主角在资源稀缺中生存、变强、集结同伴。
- 男频主流：丧尸、极寒、异兽、辐射废土等。
- 核心卖点：极限压力下的选择与「白 Soft（轻松囤货）」反差爽感。

## 核心技法
- **生存动机先行**：先立住「为什么活」——护家人/找药/回基地，否则末日只是背景板。
- **极端情境三要素钩子**：时间压力（病毒扩散倒计时）+ 资源稀缺（水/粮/弹药）+ 明确威胁（丧尸潮/异兽），三者叠加制造紧迫感。
- **认知颠覆**：可让「安全区」反成陷阱、熟人变异，颠覆读者预期，提升悬疑。
- **囤货+空间流**：用「提前储备/随身空间」制造信息差爽点，灾前布局、灾后从容。
- **社群构建**：从独狼到小队到基地，人际关系即剧情燃料（背叛/结盟/牺牲）。
- **文风可软**：所谓「白 Soft」——在残酷背景下保留轻松日常与吐槽，缓解压抑、增加追读。

## 可直接套用模板/清单
- 末日设定清单：灾变类型 / 时间线 / 核心威胁 / 资源规则 / 主角先天优势。
- 开篇模板：「灾变前兆（异常信号）→ 主角抢先一步布局 → 灾变爆发众人慌乱，主角已就位 → 首场生存危机」。
- 节奏清单：独活（立生存能力）→ 救重要之人（立情）→ 建队伍（立势）→ 清大威胁（立威）。
- 自检：危机是否「具体可见」？含糊的「世界很危险」不如「三小时后丧尸破门」。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 避免无休止压抑无爽点；需给读者「从容应对」的释放感。

## `novel-how-dreamspace` · 梦境/幻觉空间怎么写


# 梦境/幻觉空间怎么写

## 适用场景
- 人物做梦、产生幻觉、潜意识浮现
- 需要"如梦似幻"氛围或虚实相生叙事
- 用梦境塑造人物、拉扯情绪、预示命运、暗示现实

## 核心技法
- **模糊现实与幻想的界限**：让现实事件逐渐与梦境/幻觉重叠，读者难辨真假，制造不确定性。这是"如梦似幻"的核心手法。
- **梦境三段思考法**：
  1. 塑造氛围感：梦境是光怪陆离、贴近现实、还是碎片化？先让读者感知氛围、共情做梦者。
  2. 突出重点刻画细节：为塑人物一致性则梦境与现实表现一致；为反差则用细节对比。细节如黑板重点。
  3. 给引导：让读者理解梦境想表达什么（如恐怖梦里仍护所爱，拉扯情绪）。任何文字必须有用。
- **现实与梦境丝滑过渡的四种开关**：① 物品引导（如陀螺图腾）② 时间锁（有限更刺激）③ 情节暗示（现实与梦细节1:1对应但某处不同，如保安说不同方言）④ 特定声音指引（猫叫、水滴）。
- **细腻感官描写营造朦胧飘渺**：视觉（月光如水洒湖面）、听觉（风里若有若无的音乐）、触觉（空气淡淡花香），让读者仿佛置身虚幻世界。
- **非线性叙事**：打破时间顺序，时间线交错重叠，让读者感到时间流逝不真实，如置身梦境。
- **象征与隐喻**：蝴蝶象征自由变化、迷[某村]喻未知迷茫，赋予事物多重含义增加深度神秘。
- **超现实场景设计**：漂浮岛屿、倒流河流、会说话的动物，打破常规逻辑带来新奇梦幻。
- **诗意语言+开放结局**：避免直白，用富节奏感的优美文字；结尾不明确解释，让读者如刚从梦中醒来仍沉浸未解之谜。
- **虚实相生叙述**：梦境既是对现实的预言也是对过去的回顾，界限模糊（梦境即现实、现实即梦境）。梦境可直接显影人物不能言说的内心与扭曲精神世界（如白日梦显影残缺人格，为后续行为做下意识铺垫）。
- **通感具象化抽象命题**：把形而上危机转为可感物理体验（"干冷的风剃掉皮肤一层""浸入雪面凝成血线"），使自我消逝获得触觉重量；重复意象构成梦境"句法规则"，每次重现携带新语义。

## 可直接套用模板/清单
- **梦境三段模板**：①定氛围(光怪/写实/碎片) → ②抓重点细节(一致或反差) → ③给引导(表达什么情绪/预示)。
- **过渡开关清单**（任选1-2）：物品图腾 / 时间锁 / 情节细节差异 / 特定声音。
- **模糊界限技巧**：现实段落逐渐混入1个梦境特征（不合常理的光、重复的人、倒置的空间），不点破。
- **虚实自检**：本段梦境是否服务人物塑造/情绪/伏笔之一？是否避免了"为写梦而写梦"？

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 梦境必须有用（塑人物/拉情绪/引剧情/伏笔），不可为炫技而写；过渡需有清晰开关避免读者混乱。

## `novel-how-exam` · 考场/比试场景怎么写


# 考场/比试场景怎么写

## 适用场景
- 限时挑战戏需要"时间咬人"的紧张感。
- 想用一场考试/比武写人物实力、心态、或翻盘。
- 多角色同场竞技，需要并置写出个体差异。

## 核心技法
- **倒计时是天然的紧箍咒**：钟摆、监考的脚步、翻卷的沙沙声、窗外渐斜的光——时间每动一下，压迫加一分。把"还剩三十分钟"变成读者自己的焦虑。
- **身体细节出卖状态**：握笔的手汗、咬住的笔帽、膝上不自觉抖的腿、咽下的口水——紧张全在微小动作里，不写"他很慌"。
- **邻座即对手（信息差）**：余光瞥见别人翻页快、别人提前交卷——制造"我是不是要输"的自我怀疑。限知视角下，邻座进度是悬在头上的刀。
- **快慢节奏切换**：开考前慢（环境铺陈、心理活动长句）；开考后快（短句、动作、时间碎片）。节奏跟着发令枪走。
- **翻盘靠铺垫**：平日被忽视的主角，在限时高压下爆发出真本事——前期埋"他早有准备"的细节，翻盘才不突兀。
- **景随情变**：卡住时连呼吸都吵；顺手时世界安静只剩笔尖。环境随答题状态起伏。

## 可直接套用模板/清单
- **时间压迫**：倒计时标记___ / 声音锚点（钟/脚步）___ / 光的角度___。
- **身体信号**：手汗___ / 抖腿___ / 咬笔___ / 吞咽___。
- **对手并置**：邻座进度___ / 主角误判___ / 翻盘伏笔___。
- **自查**：倒计时让读者焦虑了吗？紧张靠动作吗？翻盘有铺垫吗？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 考场写时间压迫与心理，不写题型讲解。

## `novel-how-farming` · 种田/经营文怎么写


# 种田/经营文怎么写

## 适用场景
- 穿越/架空/古代/系统种田，开荒建设、发家致富
- 需要构建自洽的经济贸易体系（物价、度量、商路、风险对冲）
- 平淡生活流与阶段爽点并存
- 基建、技术升级、供应链、势力博弈

## 核心技法
- **四阶段进化轨迹**：①生存型（基础建设：开荒、获工具、满足系统生存要求，无外部价值输出）②商品型（建立产销闭环：种植→加工→分销拍卖，形成稳定收入，引发多方势力关注博弈）③战略型（农业成果深度介入主线：用产出瓦解对手正当性、转化为政治话语权）④技术型（深加工、资源勘探、知识生产，完成从体力劳动到全链条升级）。让种田从经济行为升格为权力/主线工具。
- **经济系统自洽**：核心设施一体化（仓—井—坊—交换所—守望台）；统一交易单位与"分等分级"；发行"仓券/票证"打破单边价控；商路小分队制+夜宿棚+共用路标降低过路抽利；风险对冲（互保粮库、种子谱系共享、剩余-再生产闭环、丰歉年用券平抑价格）。建立"地球-异界"式物价联动公式，避免物价无规律乱跳。
- **节奏三三制（防流失）**：30% 时间建设、30% 冲突铺垫、40% 爆发解决。建设期过长必流失读者；用事件驱动，把种田置于冲突中而非流水账。
- **功能前置式伏笔**：开篇即明确核心使命（"成为第一个农业大亨"），所有后续情节均服务该目标，杜绝功能泛化。
- **数值锚定式对比**：用精确定价与可量化效果，将抽象农业价值转化为读者可感知的硬通货，强化可信度。
- **场景闭环式推进**：每个节点配套完整场景链——播种→生长监控→成熟提示→采摘→储存→销售→分成结算，拒绝跳跃式叙事。
- **生活流白描**：采用"晨起—劳作—归家—休憩"循环节律；白描为主、感官为核，比喻必有本体、象征必有载体；心理描写占比低，借动作外化（"别过眼""手捏绣花针胡乱扎布"）；对话占比高、方言助词增强生活实感。
- **反差强化式衬托**：用对手/旧势力的失败反衬主角产出不可撼动，用技术对传统体系的降维打击凸显升级。
- **背景设定细致合理**：地理环境（依山傍水、资源供给）、社会文化（等级、礼法、习俗）必须服务经营逻辑；主角技能贴合场景（农学改良土壤、厨艺开饭馆、木工造农具）。

## 可直接套用模板/清单
- **种田四幕大纲**：开荒立根（试田、初收、遇阻、发现旧资源）→抗旱/破局/商路成形（用新技术稳产出、识破价控、建分级与小队商路）→丰饶堡/制度建成（统一度量与票证、联防守村）→最终对决（上游切断、围价、税卡，以分散水源+互保+共护扭转）。
- **经济系统自检清单**：交易单位？分级标准？有无票证/债券？商路组织？风险对冲机制？物价公式？是否自洽？
- **节奏三三制拆分**：本章建设/冲突/爆发占比？建设是否超过 30% 且无事件驱动？
- **产销闭环检查**：每个产出节点是否完成"种—管—收—储—售—结算"全链？
- **角色成长曲线**：从"倾听土地/技巧型"→"可信领路人"→"制度建造者"→"共同体守护者"。

## 红线
- 用通用措辞，不照搬任何专属 IP。 的系统名称与具体剧情。
- 避免系统功能过度神化（点石成金、违反物理），设"科技树/前置任务"限制。
- 避免经济失真（物价乱跳）、节奏失衡（建设期过长）。

## `novel-how-game-live` · 直播/游戏文怎么写


# 直播/游戏文怎么写

## 适用场景
- 游戏文、电竞文、攻略/副本流、系统流
- 直播文（传统直播、古今直播、问答/盘点/剪辑流）
- 需要将游戏机制转化为文学表达
- 用"游戏思维"设计成瘾剧情与情绪金币

## 核心技法
- **规则与情感的博弈（核心魅力）**：攻略/游戏文本质是"规则框架下的无限可能"。清晰游戏规则（技能体系、联赛机制）创造"限定条件下突破限制"的戏剧张力，天然优势：目标可视化（任务进度/等级/成就量化成长）、冲突自动化（BOSS/PVP/副本自然生冲突）、知识降维（商战简化为公会资源争夺）。警惕"数据至上"陷阱——战力数值完全取代人物弧光会退化为游戏说明书，优秀作品在通关中嵌入主角自我认知突破。
- **规则系统的文学化处理**：游戏规则完成从"机制"到"隐喻"升华（副本不仅是关卡，更是人性试炼场；技能树暗含文明进化）。①设计具有"可突破性"的规则（隐藏机制/漏洞）②将系统提示转化为文学描写（"生命值-10"→"骨骼碎裂声让他眼前发黑"）③建立资源稀缺体系制造策略选择困境。
- **现实锚点设置艺术**：完全脱离现实难共鸣。有效现实支点：游戏行为对现实生活影响（职业选手手伤）、线上身份与线下人格反差（网游大神实为店员）、虚拟成就的现实价值转化（装备交易引发困境）。
- **关卡式模块化叙事**：采用"游戏关卡式"章节设计，每 3 章一完整单元（系统激活→立项→启动），单元内"问题暴露→资源调度→方案执行→效果反馈"四步闭环。高潮匹配读者生理节律（每 12 章一次"版本更新"式爆点），避免情绪疲劳。悬念用"文档埋点法"（前期小细节后期由汇报/文书揭晓，无信息冗余）。
- **专业性与人情味配比（冰山法则）**：展示 10% 专业细节，隐藏 90% 设计思路（战术指挥不罗列所有 CD，借队友震惊反应侧面体现）；避免"完美人设"，街头智慧与专业素养反差增强可信。队友关系层次建构（师徒/知己/损友立体人际网）。
- **直播流底层逻辑**：直播设定本质还是"系统"（任务-奖励机制），与系统文最大区别是多了互动性——直播观众作为气氛组强化爽感。核心三关键点：直播内容（鲜明有吸引力的主题）、主播（人设）、互动（弹幕/连线/PK/打赏）。优势：自带流量热度、易结合热点梗、代入感强、打脸层次更丰富。
- **游戏思维设计"成瘾"剧情**：彻底换脑——从"讲故事"到"做产品"，每章像游戏关卡为读者产出"情绪金币"（碾压快感、获宝惊喜、身份跃升荣耀、被人仰视满足）。傻瓜式循环：丢目标（接任务，具体可感知）→设障碍（增加难度）→赢（释放情绪，赢得有智慧有风格）。
- **世界观自洽与角色驱动**：独特核心（最与众不同的一点）+规则逻辑贯穿始终（经济/政治/力量体系）+细节浸润（风俗/俚语/传说）。角色需驱动与成长（核心欲望与内在缺陷）、群像关系网、关键剧情点的艰难抉择。"系统"文学化（技能升级/装备获取转化为训练/奇遇领悟过程）；"互动感"营造（第一人称或深度受限第三人称模拟探索未知）。

## 可直接套用模板/清单
- **关卡单元模板**：问题暴露→资源调度→方案执行→效果反馈（每 3 章一闭环）。
- **直播三要素卡**：直播内容（主题？）/主播（人设？）/互动（弹幕/PK/打赏设计？）。
- **情绪金币检查**：本章为读者产出哪种即时情绪奖励？是否"接任务→设障→赢"？
- **系统文学化清单**：数值是否转化为感官/动作？规则是否有可突破漏洞？资源是否稀缺？
- **现实锚点自检**：游戏行为如何影响现实？线上线下人格是否反差？虚拟成就是否有现实转化？

## 红线
- 用通用措辞，不照搬任何专属 IP。 的具体游戏名、系统名、副本剧情。
- 避免"数据至上"退化为游戏说明书，人物弧光不可被数值取代。
- 规则一旦确立须贯穿始终，避免剧情漏洞。

5. **数值守恒**：升级需经验/任务，不能无理由暴涨，平衡是底线。

## 模板清单
- 面板模板：属性×等级×经验条×技能栏
- 升级反馈：数值跳动+音效词+身体变化
- 平衡阀：经验来源/升级条件

## 红线
- 系统提示词（[叮]）滥用=廉价，关键时刻用。
- 数值不能无代价暴涨，须有获取逻辑。
- 系统绝对保密类设定（如你项目）绝不向队友泄露，是铁律。

## `novel-how-genre-horror` · 恐怖氛围 · 营造


# 恐怖氛围 · 营造

## 适用场景
- 想写让人背后发凉的段落，不一定是灵异，心理恐怖也适用
- 用环境、暗示、节奏替代直白的"好怕"

## 核心技法
1. **五感法则**：地下室霉味像潮湿的舌头舔后颈，手电光圈里尘埃突然凝滞——嗅觉触觉联动+动态悬停造异常。
2. **天气即情绪**：暴雨拍窗、雾锁山路、无风的闷热——天气替读者紧张。
3. **暗示不直说**：用含蓄语言暗示危险（"冰箱牛奶总在凌晨少200ml"），引发联想。
4. **节奏控制**：紧张时用短句快叙述；渲染氛围时放慢细腻描写——张弛造紧迫。

## 模板清单
- 五感：霉味钻进鼻腔，手电光里浮尘凝住，那不是尘，是某物呼吸的鳞粉
- 天气：雨敲了一夜窗，到天亮还没停，像有人在敲
- 暗示：她数过，牛奶每天少200ml，从她搬来那天起
- 节奏：短句。门响。她没动。门又响。这次，从里面

## 红线
- 禁Jump Scare滥用（每万字不超3次）
- 禁血腥无主题（描写要服务恐惧内核）
- 禁"好怕"直述（用环境动作外化恐惧）

- **武功描写真实性**：虽虚构但需真实感与逻辑性——通过动作细腻描写、力量合理运用、武功原理解释增强可信；在传统基础上创新独特招式与武学理念（招式蕴含人生哲理）。
- **人物职业图谱（避免依附）**：侠客（独行/游侠/世家/落魄）、门派中人（掌门/长老/核心/边缘/叛徒）、特殊职业（镖师、捕快、仵作、医/毒医、药师、工匠、商人、伶人、乞丐、隐士、刺客、盗匪）、朝廷相关（清/贪官、权宦、禁军、密探）、女性角色（侠女/闺秀/魔女/医女/舞姬/女扮男装/女弟子）——赋予独立人格与能力，不依附男性。
- **门派设定避坑**：传统门派（少林/武当/峨眉/丐帮等）有历史可考，不能完全否认其存在，可尽量使其不与主线冲突；新编门派须遵循客观规律（后缀寺/宫/门/坊/谷/派/教/帮/堂/阁/山庄等），历史关系要自洽。

## 可直接套用模板/清单
- **江湖世界三件套**：地理气质（地域→武林秩序）、门派图谱（宗旨/武功/等级/关系）、江湖规矩（道义/解决方式/货币）。
- **侠之五维检查**：家国/恩仇/道义/一诺/孤独——主角体现哪几维？是否有蜕变与两难？
- **武功体系卡**：外功招式、内功心法、脉络成长、秘密禁术、门派间关系（同盟/竞争/渗透）。
- **人物职业分配**：列出本作需要的职业图谱，确保女性角色独立、无脸谱化。
- **门派合规自检**：现实门派是否妥善处理？新门派命名/历史关系是否自洽？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 避免套路化/脸谱化人物，"写人就得讲人性"。
- 江湖规矩与武功体系须内部逻辑自洽，禁术不能万能解一切。

# 市集/集市场景怎么写

## 适用场景

## 核心技法
- **五感轰炸出烟火**：此起彼伏的叫卖、活鱼溅起的水腥、熟食的油气、摩肩接踵的体温——视觉之外的感官把"热闹"写进身体。

- **景随情变**：落魄者看满桌佳肴是讽刺；归乡者看熟悉摊贩是慰藉。

- **自查**：烟火气靠五感吗？情报藏进喧嚣了吗？有典型个体吗？

## `novel-how-multi-thread` · 多线并行（多线程叙事）怎么写


# 多线并行（多线程叙事）怎么写

## 适用场景
- 群像文/竞技文/双男主多主角文需要铺多条线
- 视角切换混乱、读者问"哪条是主线"
- 设计支线如何服务主线不注水

## 核心技法
- **主时间轴锚定法**：以一条线（主角线）为主时间轴，其他线作为穿插事件；视角始终跟着主角，支线信息通过"消息/电话/偶遇"带入，读者永远知道"现在在主时间轴上"。
- **交汇点密度控制**：每 3-5 章设 1 个交汇点（多线信息同一场景汇合），太密读者来不及消化、太疏忘了支线；交汇点本质是"信息差碰撞"非"角色聚会"。
- **平行交叉线**：选两条线满足空间不同+人物不同+目标不同，A 线推到"将要发生"切 B 线，B 线推到"马上动手"切回 A，合并时爆点。
- **因果链多线**：主角每个重要行为在另一条线产生反应——"这章主角做了什么，下章谁被迫行动"，避免单线。
- **转场三策略**：①情绪凑一对（紧张对紧张）②共同话题过渡（聊到某人/某物自然切场）③大事件聚线（宗门大比把所有线聚齐）。
- **3-5 条黄金区间**：少于 3 条张力不足，多于 5 条难跟踪；主角线占 50-60%，其余平分。
- **切换锚点**：每条线开头给明确锚点（角色名/地名/时间坐标），POV 切换要有交棒理由（悬念高点/信息差），顾情绪延续（悲壮死亡别立刻切搞笑）。

## 可直接套用模板/清单
- **多线结构模板**：结构1主线+群像式（支线有明确起点终点，关键节点与主线交汇，支线可独立展开但不能独立结束）；结构2多主角并行（镜像事件：同事件不同视角）；结构3时空交错（现在线/过去线，明确转换信号）。
- **每条线自检**：有自己的小目标和小冲突吗？不是纯为主角铺路的填充线吗？上次登场累积字数/故事时间是否冷了？
- **戏份帐**：盯"有人莫名其妙消失"而非"大家一样多"；同一卷高度活跃主线压到 3-4 条，其余冷却待命。
- **切场提示**：加"同一时间，宗门后山的密林中""就在主角竞标成功时，城郊反派基地里"等过渡。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 误区警示：把多线=每章换视角（读者每章重新定位）、多条线毫无交集变注水、支线抢主线风头、交汇点写成大场面而非信息碰撞、副线贪多顾此失彼。

## `novel-how-power-system` · 升级体系怎么写


# 升级体系怎么写

## 适用场景
- 玄幻/科幻/游戏文搭力量金字塔
- 避免后期"战力通货膨胀"崩盘
- 让实力对比一眼可判、突出武力为尊或能力秩序

## 核心技法
- **阶梯状上升**：准武者→武者→武王→武尊→武帝…每级再分小级，呈清晰阶梯
- **战力多维度**：等级之外含武技/天赋（A/S/SS级），同等级比"战技精湛+战斗经验"，不是纯数值
- **锚定题材作用**：体系复杂化要有笔力驾驭，否则覆盖卖点。发番茄类读者，尽量简单化、逻辑自洽
- **可量化锚点**：如"拳力100-300吨=准武者一阶"，读者脑中有具体标尺，对比不模糊
- **上限必须明确**：修炼/科技体系要有清晰分级且明确上限，不然后期战力必崩
- **同级异兽/特殊存在强于人类**：制造越级挑战的空间，保留紧张感

## 可直接套用模板/清单
- [ ] 主等级阶梯（5-9个大级足够，别无限叠）
- [ ] 每级细分小级（如初/中/高/巅峰）
- [ ] 战力维度：等级之外的武技/天赋/资源维度
- [ ] 量化锚点：给读者一把可对比的尺
- [ ] 写定上限+突破契机，锁死后期不崩
- [ ] 自问：这体系服务卖点吗？还是为复杂而复杂？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 体系是服务爽点的工具，复杂化需笔力，新手从简

## `novel-how-prison` · 监狱场景怎么写


# 监狱场景怎么写

## 适用场景
- 角色被关，需要写出"墙在呼吸"的压迫而不是"他进了监狱"。
- 想用牢狱戏写人物蜕变、结盟、或暗中布局越狱。
- 封闭空间里的权力结构（牢头/看守/新人的食物链）。

## 核心技法
- **封闭空间=窒息具象化**：铁栏的间距、墙上的划痕（数日子的刻度）、窗缝漏进的光的角度——用空间细节让"被囚"可触摸。光每天移动几寸，就是时间的刻度。
- **时间感扭曲**：牢里没有昼夜，靠放风、饭点、点名切分日子。写出"日子被切碎"的麻木，比写"他很绝望"有力。
- **权力结构即戏剧**：新人如何被"规矩"教育、牢头与看守的默契、谁在食物链顶端——牢狱是微型社会，关系即剧情。
- **声音与寂静**：远处的铁门声、脚步声在走廊的回响、深夜的咳嗽——声音在封闭空间被放大，自带悬疑张力。
- **越狱暗线靠细节铺垫**：偷偷磨的勺、记下的看守轮换、墙角的松动——前期埋功能性细节，后期回收成高潮。
- **景随情变**：初入时每声声响都惊跳；待久后连再审讯都面无表情——环境不变，人变了，反差即人物弧光。

## 可直接套用模板/清单
- **压迫细节**：栏距___ / 划痕（日子）___ / 光的角度（时间）___。
- **权力图**：顶端___ / 新人___ / 与看守的关系___。
- **越狱伏笔**：磨的物___ / 记下的规律___ / 松动处___。
- **自查**：封闭感写出来了吗？时间被切碎了吗？越狱伏笔前期埋了吗？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 监狱写压迫与权力，不写游览指南。

## `novel-how-rebirth` · 重生文怎么写


# 重生文怎么写

## 适用场景
- 主角带着前世记忆回到过去，要改写命运（复仇、致富、护住重要之人）。
- 男频/女频通用，核心卖点是「信息差」与「弥补遗憾」。
- 适合需要强情绪驱动与明确目标的题材。

## 核心技法
- **前世必须够惨**：重生的动力来自「上一世失去/被辜负」，惨得越具体，读者越共情、越盼主角逆天改命。
- **记忆即金手指**：重生的优势是「已知未来」——知道哪些人会背叛、哪只股会涨、哪件事会出事。用它制造信息差爽点。
- **第一个动作要具体**：重生后立刻做一件改变命运的小事（拦住某个人/避开某个坑），让读者当场看到「不一样了」。
- **复仇分阶段**：小反派先收拾，大反派留到最后；每阶段有证据、有反转、有打脸。
- **弥补遗憾线**：除复仇外，留一条温情线（护家人/圆夙愿），平衡爽感与情感厚度。
- **模板可套**：复仇流 / 甜宠弥补流 / 时代红利经商流。

## 可直接套用模板/清单
- 前世设定清单：死因或惨况 / 最大遗憾 / 关键仇人 / 未说出口的话。
- 开篇模板：「死亡或惨剧回放（1 段）→ 睁眼回到那年（锚点清晰）→ 立刻做一件改变的小事 → 旁人反应反差 → 立下本世目标」。
- 节奏清单：第 1 步小赢（立信）→ 第 2 步中赢（翻盘）→ 第 3 步大赢（清算总账）。
- 自检：重生后行动是否「有信息差支撑」？若和普通人没区别，则金手指失效。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 避免「重生即全能」——需保留阻碍与代价，否则爽点廉价。

## `novel-how-romance` · 爱情戏怎么写（不尬）


# 爱情戏怎么写（不尬）

## 适用场景
- 写男女主从相识到暧昧、试探、确认心意的全过程
- 改掉"他很爱她""心跳加速""小鹿乱撞"等空洞直白抒情
- 写亲密戏/表白戏时觉得油腻、没感觉、读者出戏
- 感情线拖节奏、和主线脱节

## 核心技法
- **局部放大法 / 微动作特写**：不写全景、不写"心动了"，只写局部——指尖无意相碰后停留的半秒、呼吸停滞的瞬间、收回手时衣袖带起的一缕冷香、耳尖泛红、捻衣角、对视后迅速低头。用物理反应（汗液、呼吸、瞳孔收缩、僵硬肌肉）代替心理描写，此时无声胜有声。
- **嘴硬心软 / 反话藏真心**：高级感情戏不靠告白，靠"口是心非"。关心藏在责备里（"你又跑来做什么"），真心用嫌弃口气说出口。语言留白，给读者脑补空间。
- **推拉节奏的动态平衡**：试探→靠近→回避→爆发。先制造充分吸引理由，再"进一步退两步"：暧昧拉满时突然外部事件打断/角色想起使命重新戴上面具拉远距离，最后在生死关头等极致情境爆发。节奏平 = 干巴巴。
- **接近-错过法**：设计"几乎要发生却被中断"的时刻（要牵手杀出前任、告白前车按喇叭），读者期待值反而冲更高。
- **用"不说爱"表达爱**：最高级台词从不说"我爱你"。用行动替台词——"昨天路过奶茶店习惯性点了两杯"；沉默制造心动——并肩走手背碰一下同时缩回。
- **吊桥效应**：共同面对危机时感情升温是下意识、自然的。剧情线与感情线必须同步推进，不能毫不相关。
- **临界点事件**：前15章内至少安排1个"一方脆弱时刻被另一方看见"的节点，让关系质变。
- **甜蜜时刻埋雷**：确认关系后给亲密举动设障碍（接吻前有人敲门），制造张力而非纯撒糖。

## 可直接套用模板/清单
- **微动作清单**：心动紧张→捻衣角、躲闪、耳尖红、碰指尖即收回；吃醋别扭→扭头看别处、攥紧水杯、放慢脚步等对方。
- **反话模板**：嘴上嫌弃行为迁就；嘴上冷漠内心在意；嘴上说不等其实一直在等。
- **推拉四步**：试探(出暧昧话看反应)→靠近(正向反馈拉近距离)→回避(到嘴鸭子飞了)→爆发(极致情境下压抑全释放)。
- **感情线自查清单**：①前3章内CP是否建立"独一无二的联结"(共同经历/只有他们懂的暗号)；②前10章内≥2次身体语言试探(眼神触碰/意外肢体接触)；③前15章内≥1个临界点事件；④每5章感情线是否与主线同步推进(并肩作战中升温)。
- **避坑清单**：拒绝恋爱脑(角色要有自己的人生目标底线)；避免外貌堆砌(不反复写"倾国倾城")；不强行误会(基于细节推理而非看背影认错人)；感情进展要有铺垫(每次心动有迹可循)；感情线必须服务主线。

## 红线
- 用通用措辞，不照搬任何专属 IP。

## `novel-how-scifi` · 科幻文怎么写


# 科幻文怎么写

## 适用场景
- 以科学设定/未来想象驱动的网文：星际文明、赛博朋克、废土科幻、近未来推理等。
- 男频偏「探索+升级」，女频偏「情感+哲思」；核心是「奇观感（Sense of Wonder）」。
- 适合需要严谨又易懂的世界观设定的题材。

## 核心技法
- **奇观感优先**：用「一根针见血」的未来细节（会发光的街、被数据化的记忆）瞬间把读者拉进异世界。
- **硬软平衡**：硬科幻重科技自洽，软科幻重人与社会；多数网文取「软硬之间」——设定可信、人不悬浮。
- **If...then 思想实验**：从「如果某技术成立，世界会怎样」推演社会/伦理后果，这是科幻骨架。
- **开篇锚定「非现实」**：500 字内用一处明显异于今日的设定（重力异常/AI 执政）告诉读者「这不是现在」。
- **世界构建五法**（通用化）：技术外推 / 平行历史 / 废土重建 / 异星接触 / 意识网络空间。
- **情感锚点**：再硬的科幻也要一个「人」的牵挂（女儿/故土/自由），否则读者无代入。

## 可直接套用模板/清单
- 科幻设定清单：核心科技 / 社会形态 / 冲突来源 / 人的牵挂 / 代价与副作用。
- 开篇模板：「一个未来日常细节（立奇观）→ 暗示背后的技术规则 → 主角因该技术陷入麻烦 → 抛出核心谜题」。
- 设定自检：技术若拿走，故事是否成立？成立=包装；不成立=真科幻骨架。
- 自检：设定是否「服务人物与冲突」？为炫技而炫技会劝退。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 设定需自洽且服务于剧情，避免名词堆砌无人物。

## `novel-how-system` · 系统文怎么写


# 系统文怎么写

## 适用场景
- 想写一本以「系统/金手指」为核心驱动力的网文（签到、任务、抽奖、回收、兑换等类型）。
- 主角需要清晰可见的「成长外挂」，靠系统推动剧情与爽点。
- 男频爽文中，需要让升级节奏可控、收益即时可见。

## 核心技法
- **系统是工具，不是主角**：系统服务于主角目标，话不要太多、不要抢戏；它的功能是「发布任务—给奖励—推动升级」，而非代替主角做决定。
- **三套底层逻辑**：
  1. 目标清晰——读者一眼知道主角要什么（变强/赚钱/活下去）。
  2. 即时反馈——完成即有奖励，不让读者空等。
  3. 冲突前置——任务往往伴随阻碍/赌注，逼主角行动。
- **系统类型可套**：签到型（每日固定收益）、任务型（完成目标发奖）、抽奖/转盘型（随机惊喜）、回收/兑换型（以物易物）、养成型（培养某事物换成长）。
- **代价与限制**：系统越强，越要设冷却、门槛或副作用，避免「无代价碾压」导致剧情真空。
- **爽点节奏**：小爽（单章任务完成）3 章一波，中爽（阶段升级）10 章一波，大爽（身份/实力跃迁）30 章一波。

## 可直接套用模板/清单
- 系统设定清单：类型 / 触发条件 / 奖励内容 / 冷却或代价 / 是否可成长。
- 单章模板：「接到任务（带赌注）→ 犹豫或立 flag → 行动受挫 → 系统奖励到账 → 实力/处境肉眼可见变化」。
- 开篇钩子：先用一个「主角绝境+系统觉醒」把读者钉住，再补设定。
- 自检：系统是否让主角「更主动」？还是「替主角思考」？前者留，后者删。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 系统不可无代价无限强，否则剧情失去张力。

## `novel-how-time-skip` · 时间跳跃/过渡怎么写


# 时间跳跃/过渡怎么写

## 适用场景
- 需要跳过无戏的时段（赶路、养伤、修炼），又不想硬切出戏。
- 想用自然转场替代"三天后""多年以后"的生硬。
- 写长期跨度，保持读者不迷失。

## 核心技法
- **感官细节做转场纽带**（场景构建共识）：上一个场景收尾于"关门的回响"，下一个以"相似的声响"开启——感官串联全程，读者几乎无感跳转。不用"几天后"这类直白话术。
- **概括带过非关键期**：养伤/修炼用一两句"半月过去，伤口结了痂，剑也快了三分"收束，不铺流水。把字数留给有戏的时刻。
- **以物记时**：用"第三十七次日出""坛里酒见底"等具体物象代指时长，比数字有体感。
- **跳跃后的锚点**：跳完后第一句给读者新坐标（在哪、谁在、什么状态），防迷失。
- **长跨度的意象**：用草木枯荣、季节轮转（见 novel-how-plant）承载大时间跨度，诗意又清晰。
- **景随情变**：略过的时段里，环境可悄悄变（天暖了/雪落了），读者从景知时。

## 可直接套用模板/清单
- **转场纽带**：上场收尾声___ / 下场同声起___。
- **概括句式**：非关键期用___（一句带过）___。
- **记时物象**：第N次日出___ / 酒见底___。
- **自查**：转场靠感官纽带吗？非关键期略写了？跳后给锚点了吗？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 时间跳跃靠感官纽带，非关键期略写，不硬切。

## `novel-how-transmigration` · 穿越文怎么写


# 穿越文怎么写

## 适用场景
- 主角从现代（或另一世界）穿越到一个全新地图/身份，靠认知差与金手指生存升级。
- 男频/女频通用：历史穿越、穿书、异界大陆、末世前穿等。
- 核心是「换了环境后的适应与降维打击」。

## 核心技法
- **换地图+换身份双设计**：明确「从哪来、到哪去、成了谁」，身份决定初始资源与困境（奴婢/皇子/废柴/书里反派）。
- **冷开场**：开篇直接把读者扔进穿越现场（睁眼即在异境），用感官反差（气味/服饰/语言）立住世界，设定后补。
- **专业向穿越**：让主角带一门现代专业技能（医术/厨艺/工程/管理）去降维打击，比「全能」更可信、更出戏少。
- **反套路**：可故意打破「穿越必开后宫/必称霸」预期，制造新鲜感（如穿越成炮灰自救）。
- **金手指要有边界**：认知差、系统或物品都可，但设限制（能量耗尽/被世界规则排斥），避免无脑碾压。
- **文化碰撞爽点**：用现代观念（平等/科学/商业）冲击旧世界规则，制造冲突与笑点。

## 可直接套用模板/清单
- 穿越设定清单：原身份 / 新身份 / 新世界规则 / 携带金手指 / 金手指限制。
- 开篇模板：「穿越瞬间的感官冲击（3 行内）→ 确认处境与危险 → 用一项专长化解首个危机 → 立住人设与目标」。
- 冲突来源：身份危机（被识破）/ 规则冲突（现代 vs 古代）/ 信息差误用反噬。
- 自检：主角的「现代认知」是否真正推动了剧情？还是只用来装逼？

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 金手指需有代价/限制，避免穿越即无敌导致剧情空心。

## `novel-how-urban` · 城市/都市场景怎么写


# 城市/都市场景怎么写

## 适用场景
- 都市、现代背景小说的街道、写字楼、商圈、夜景、通勤
- 需要"真实质感"而非宣传画式表面描写
- 用城市空间承载人物时间与劳动

## 核心技法
- **从一个可感知的动作开始，而非宏大判断**：与其写"城市充满活力"，不如写卷帘门升起、信号灯变绿、地铁人群同时迈步、雨水顺路缘流动。具体动作让读者自行感受活力/紧张/疲惫。
- **建立远/中/近三层次**：远景=天际线、道路走向、建筑密度；中景=站牌、护栏、店面、树木、车辆；近景=鞋底水迹、手中饭盒、墙面剥落涂层、窗内短暂亮起的灯。三层配合，城市才不停留在表面。
- **感官绑定 + 空间位移**：极少用上帝视角概括，一切经人物感官过滤——暴雨中不是"大雨倾盆"而是"雨水无视伞面被狂风刮得砸在脸上"；短句分号模拟真实移动时视线切换（看表→抬头→低头三动作对应三短句）。
- **设置贯穿全文的线索**：线索可以是通勤路线、一辆公交运行、一场从下午持续到夜里的雨、旧建筑旁不断升高的新楼。单一线索连接不同人群和场景，让分散细节产生方向。
- **保留矛盾，不强行写成和谐景观**：热闹商业街让居民难休息，整洁新区缺少阴凉，宽阔道路让行人更难过马路。城市真实质感来自便利、拥挤、陌生、温暖、疲惫同时出现。
- **夜景的声与光**：光是城市的皮肤（路灯昏黄拉长的影子、霓虹碎片拼接的欲望、深夜书店像孤岛的灯），声音是脉搏（市井交响乐般的吆喝/喇叭/划拳，或凌晨只剩自己心跳与秒针的"声音真空"）。
- **去中心化多感官铺陈**：视觉（灰蓝天色、高楼轮廓）+听觉（闹钟、扫帚、地铁）+嗅觉（汽油、早餐摊香）+触觉（微凉的风）同步，让都市成为可被客观测绘的感知场域。

## 可直接套用模板/清单
- **三层结构模板**：远景(天际线/路网) → 中景(站牌/店面/车流) → 近景(水迹/饭盒/剥落墙皮/窗内灯) → 一条贯穿线索(通勤/降雨/旧楼旁新楼)。
- **感官绑定写法**：不用"X很Y"，写"人物感官接收X"：暴雨=雨水砸脸+狂风刮伞+视线破碎的路灯倒影。
- **矛盾清单**：写城市时至少保留一对矛盾（热闹vs难眠 / 整洁vs无荫 / 宽阔vs难行），避免单向赞美或批判。
- **夜景双轴**：光轴（霓虹/孤灯/拉长影）+ 声轴（喧嚣市井 或 寂静心跳），二选一主导基调。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 避免只写高楼和霓虹的宣传画式表面；要落到可触摸的生活经验。

## `novel-how-wasteland` · 末日废土场景怎么写


# 末日废土场景怎么写

## 适用场景
- 末日、废土、灾后、文明崩塌后的世界
- 需要"真实可验证"的荒芜质感而非随意幻想
- 用环境外化生存压力与人物创伤

## 核心技法
- **物证考古学披露设定**：不用旁白解释世界观，用废墟细节说话——建筑形制否定摩天楼预设、日记纸张浸水程度暗示气候湿度、器物型号锁定技术代际、植物成熟期佐证演替周期。让设定可被读者"复现验证"。
- **污染梯度渗透法**：世界观按可测量污染浓度梯度披露——边缘低强度（铁锈+尘埃味）、中强度（血沼搏动+甜腻臭氧）、高强度（光线吞噬+空间褶皱）。用盖格计数器嘀嗒频率、结晶纯度等"可测量指标"替代抽象形容。
- **物质主义修辞系统**：形容词必须有物理参照（哑光/幽绿/暗红/晶莹），动词含力学参数（拧开含扭矩、刺入含深度）。比喻严格限定废土物质范畴（血沼搏动如腐烂心脏、雾谷吞噬光线），规避"心如刀割"等生理化抽象表达，把情绪外化为环境反应。
- **创伤显影术**：角色性格不用直述，用身体记忆的物理痕迹承载——"卸下血泵时肩背肌肉的细微震颤"显影克制，"擦拭时指腹在枪管刻痕上的三秒停顿"显影疲惫。心理描写占比极低，全通过手部动作与呼吸变化呈现。
- **通感与环境成生命体**：反复出现的气味/歌声/摩擦声把抽象废土转为可触可听可嗅的感官实体，使环境成为有呼吸的生命体；留白美学（删除可被系统收编的标识）迫使读者用情感定位世界。
- **动词强调生理实感**：避免"怒目而视""势如破竹"等成语化；比喻关联生存威胁（阳光如死神慵懒的指针）；"腐臭"一词同时唤起嗅觉+触觉+视觉三重体验，形成沉浸式废土场域。

## 可直接套用模板/清单
- **废土考古模板**：选一处废墟 → 列3个可测量物证（材质/型号/侵蚀程度）→ 由物证反推一条设定（时代/气候/技术）→ 不写旁白，让读者自己拼出世界观。
- **污染梯度清单**：低/中/高强度各写1个感官指标（气味/视觉/声音），用可量化词（频率、纯度、温度）替代形容词。
- **创伤显影写法**：塑造角色时不写"他很疲惫"，写"某个重复性小动作+身体痕迹（肌肉/呼吸/指尖）"。
- **废土比喻库自检**：本段比喻是否都来自废土物质范畴？是否避免了"心如刀割"类生理化成语？

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 废土≠无逻辑幻想；设定需"可见即可信"，避免概念化描述。

- 世界构建清单：地图 / 历法 / 货币 / 语言碎片 / 历史断层（留坑）。

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 神明/宗教设定仅作虚构世界观，不影射现实信仰。

## `novel-how-wuxia-moves` · 武侠招式怎么写


# 武侠招式怎么写

## 适用场景
- 武侠 / 古典题材中一招一式的呈现：剑法、刀法、拳掌、奇门兵刃。
- 想让招式"有门道"而非堆砌名词，或想写出"江湖味""意境"。
- 高手对决、门派武学展示、以武写人。

## 核心技法
- **两条路：写形 or 写意，互不冲突**。
  - 写形（实写）：硬桥硬马描绘攻防发力，如"左腿微屈，右臂内弯，手掌画个圆圈，呼的一声向外推去"，读者如亲见。适合奠基底蕴、过场陪衬。
  - 写意（虚写）：偏重气度与神韵，如"一招使出，似玉燕大鹰翩翩飞舞"。适合高手对决、情绪高潮。
  - 进阶：先写意定神韵，再写实落细节（"先虚后实"）。
- **动词炼金术**：建立专属招式动词库——空间穿透（贯穿/洞穿/劈裂）、瞬间移动（掠影/幻形/游走）、力量传递（震荡/反震/余波）。平庸"剑光如雪" vs 震撼"剑锋撕裂空气"。
- **场景化嫁接三维武学空间**：时间（晨雾中的剑舞 vs 夜色里的剑影）、空间（竹林青竹剑法 vs 沙漠流沙剑意）、感官（剑鸣如龙吟 / 剑气带松香 / 剑痕凝寒霜）。
- **节奏韵律（呼吸感）**：借鉴快慢交替、虚实相生、力度渐变（轻如柳絮→重若崩雷）。如"七连刺 + 三重横扫""三招实击接七步虚晃"。
- **文化基因植入**：器道合一（依兵器特性创新，如扇剑→蝶翼穿花）、哲学隐喻（阴阳/中庸）、地域特征（江南清雅 vs 西北刚烈）。
- **动作链写人**：每个招式动作有明确目的、环环相扣；一连串动作一气呵成不拖泥带水，角色性格自然立住。最后用一句观感总结收尾（"直如迅雷陡作，不及掩耳"）。

# 玄幻文怎么写

## 适用场景
- 东方背景的通用玄幻：以「力量等级+地图探索+逆袭」为主线的男频主流爽文。
- 核心是「废柴逆袭」与清晰的升级爽感。
- 适合需要简单易懂 yet 鲜明力量体系的题材。

## 核心技法
- **废柴逆袭骨架**：主角开局被轻视（血脉废/修为低），靠金手指与隐忍翻盘，打脸路径清晰。
- **境界命名简单鲜明**：如 斗者→斗师→大斗师→斗灵→斗王→斗皇→斗宗→斗尊→斗圣→斗帝 的阶梯；名要「一听知强弱」，避免生僻。
- **1 境界 = 1 地图 = 1 冲突**：每突破一阶进入新地图、遇新势力、解新矛盾，结构天然驱动长篇。
- **3/10/30 爽点节奏**：3 章小爽（单场胜）、10 章中爽（阶段升级/灭小势力）、30 章大爽（身份跃迁/清算大敌）。
- **多体系世界架构**：可在主力量外叠「炼药/炼器/阵法」等副体系，丰富金手指与变现。
- **防设定过载**：体系宜简不宜繁，读者记不住=出戏；鲜明比复杂重要。

## 可直接套用模板/清单
- 玄幻设定清单：力量 ladder / 初始辱点 / 金手指 / 阶段地图 / 大敌递进。
- 开篇模板：「被当众羞辱（立辱点）→ 金手指觉醒/秘密曝光 → 第一场反杀立威 → 抛长线大目标」。
- 节奏清单：辱→忍→小胜→升级→中胜→清算→更大地图。
- 自检：境界名是否「一听就懂」？复杂设定是否必要？

## 红线
- 用通用措辞，不照搬任何专属 IP。

- 体系求简求明，避免战力膨胀失控与设定劝退。
