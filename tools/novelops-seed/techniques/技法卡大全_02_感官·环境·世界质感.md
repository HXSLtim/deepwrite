## `novel-how-animal` · 动物意象怎么写


# 动物意象怎么写

## 适用场景
- 想用一只动物写人物的孤独、忠诚、或柔软面。
- 灵宠/战马/信鸽等"功能性动物"需要立住不工具化。
- 写动物死亡、或人兽之间的无声羁绊。

## 核心技法
- **动物是人性镜子**：冷硬主角只对猫温柔，反差立显其人柔软面；弃犬被收留，暗合主角自身处境。动物照出人不想说的那面。
- **象征与隐喻**（见 novel-how-symbolism）：鹰=自由/孤高；狼=群与忠；笼中鸟=被困。动物可承担主题，不靠旁白点破。
- **功能性动物要立住**：灵宠不是道具，给它习性、小脾气、与主角独特的互动（只肯睡他肩头）。读者爱的是"活物"不是"设定"。
- **人兽互动写无声羁绊**：不写"他们感情深"，写"它总在他噩梦时舔他手背"。动物的本能靠近，是最纯粹的信。
- **动物死亡/离去**：比人死更戳"无辜感"。写主角对一只动物的愧与念，常比写人更轻易破防——因动物不会争、不会怨。
- **景随情变**：主角安稳时动物绕膝；主角将死时动物反常安静贴着他。动物的反应=环境温度计。

## 可直接套用模板/清单
- **镜像设计**：动物照出主角哪面___ / 反差点___。
- **功能性立物**：习性___ / 小脾气___ / 专属互动___。
- **羁绊动作**：它做什么显亲密___。
- **自查**：动物照人性了吗？功能性动物立住了吗？互动无声有羁绊吗？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 动物写人性镜子与羁绊，不写工具设定。

## `novel-how-env-city` · 城市环境描写


# 城市环境描写

## 适用场景
写现代都市、赛博城市、古都街巷，需要让环境成为情绪容器、用城市质感烘托人物处境时。

## 核心技法
1. **五感落地**：霓虹色温/尾气味/地铁轰鸣/路面湿热，别只写"繁华"。
2. **在场者眼睛**：用[角色A]的视线选景（疲惫者看路灯频闪，兴奋者看招牌），环境即心理。
3. **城市即阶级**：CBD玻璃幕 vs 巷口摊贩，同一城两种温度，天然冲突源。
4. **动态城市**：人流潮汐/堵车/夜市苏醒，城市有呼吸，场景不静物。
5. **地标锚定**：一个具体地标（桥/塔/老街）作为情感坐标，反复出现成记忆点。

## 模板清单
- 城市感官表：视觉×听觉×气味×触感×温度
- 视角选景：人物情绪→对应城市细节
- 阶级对照：富人区/平民区同框并置

## 红线
- 信息轰炸式堆城市名词致死，每场景1–2个核心意象。
- 环境不服务情绪=无效描写，景随情变。
- 地标别硬塞，须与人物命运挂钩才立得住。

## `novel-how-env-rain` · 雨雾雪天气氛围


# 雨雾雪天气氛围

## 适用场景
用降水天气（雨/雾/雪/雹）烘托情绪、遮蔽视线制造悬疑、表达洗刷或窒息感时。

## 核心技法
1. **雨即情绪**：细雨（怅惘）/暴雨（宣泄或毁灭）/夜雨（孤独），雨是心情外延。
2. **雾藏悬疑**：能见度低制造未知，雾中身影/声源吊悬念。
3. **雪双重性**：初雪浪漫/暴雪绝境，雪埋痕迹也埋希望。
4. **感官湿冷**：衣贴背/鞋吸水/指发僵，身体记忆强化。
5. **天气转折**：雨停日出对应情绪转机，天气是节奏器。

## 模板清单
- 天气情绪表：雨/雾/雪×人物状态
- 遮蔽用法：雾中未知/雨后清场
- 转机锚：雨停/雪霁对应情节转折

## 红线
- 天气不能随便下，须服务情绪或情节。
- 暴雨宣泄别滥用于每场高潮，疲劳。
- 天气转机别机械（每次雨停就好事），需铺垫。

## `novel-how-env-ruin` · 废墟废弃描写


# 废墟废弃描写

## 适用场景
写废土、遗址、废弃建筑、末日残骸、被遗忘的文明，需要荒凉感、历史回声与"曾经繁华"的刺痛时。

## 核心技法
1. **今昔对照**：断柱上残存雕花/儿童鞋卡在废墟，繁华余痕戳心。
2. **静默压迫**：无人声只有风穿破窗，寂静本身恐怖。
3. **时间痕迹**：锈/苔/坍塌层级，用衰变讲历史。
4. **拾荒质感**：翻找残物发现旧物，物证带出前主人故事。
5. **重生萌芽**：废墟中一株野草，荒凉里给希望，但别廉价。

## 模板清单
- 废墟今昔：残存物×昔日用途×现状
- 衰变层级：锈/苔/塌的时间线
- 物证钩：旧物×前主人暗示

## 红线
- 废墟不是单纯凄凉，须有"曾经有人"的回声才戳。
- 静默恐怖靠细节，别只写"很安静"。
- 希望萌芽（野草）别硬煽，要自然从废墟长出。

## `novel-how-env-sea` · 海洋水域描写


# 海洋水域描写

## 适用场景
写大海、河流、湖泊、雨夜水面、船上生活，需要水的流动感、无常感或隐喻（时间/命运）时。

## 核心技法
1. **水有三态情绪**：平静如镜（安宁）/波涌（躁动）/怒涛（毁灭），水即心情。
2. **声音锚定**：浪拍/雨打/船骨呻吟，水声是场景BGM。
3. **无常隐喻**：潮起潮落/水流不返，暗喻命运与时间。
4. **水生危险**：暗流/深渊/未知生物，水域下藏未知。
5. **咸湿触感**：盐粒/湿衣/腥风，身体记忆强化在场。

## 模板清单
- 水情绪表：静/涌/怒×对应人物状态
- 水域声音：浪/雨/船/风
- 隐喻钩：潮信/逆流/沉没

## 红线
- 水描写别只"蓝蓝的大海"，要具体质感与情绪。
- 水域危险须真实，别让角色随意横渡无代价。
- 隐喻别硬点破，留白让水自己说话。

## `novel-how-env-wild` · 自然荒野描写


# 自然荒野描写

## 适用场景
写山林、旷野、雪山、密林、荒原，需要原始自然的压迫感、孤绝感或治愈感时。

## 核心技法
1. **尺度碾压**：巨树/远山/无垠天幕显人渺小，孤独与敬畏来源。
2. **感官纯净**：风声/松涛/雪落无声，自然之声对比人心喧哗。
3. **危险潜伏**：荒野不全治愈，暗藏兽迹/天气突变/迷路，张力来源。
4. **治愈对照**：都市疲惫者在自然中喘息，景即疗愈。
5. **时间感**：日出到星沉的光影变化，自然有自身的钟。

## 模板清单
- 荒野感官：风/声/温差/足迹
- 尺度描写：仰视巨物/平视无垠
- 危险信号：兽踪/天变/迷向

## 红线
- 自然描写忌旅游宣传腔，须带人物情绪滤镜。
- 荒野不全是治愈，要保留危险真实感。
- 景物堆砌无人物=空镜，必须有人在场感。

## `novel-how-environment` · 环境描写怎么写（不水字数）


# 环境描写怎么写（不水字数）

## 适用场景
- 开篇出场、转场、大场景交代
- 日常/剧情/打斗场景的现场感
- 用景物烘托人物情绪、塑造人物
- 任何"需要让读者看见地方"的段落，但又怕拖节奏

## 核心技法
- **先问三问，再动笔**：这段描写能透露人物什么信息？能推动/暗示情节吗？能营造/强化什么情绪？三问至少满足一个才写，否则删。
- **镜头推移法**：按顺序写——从远到近、从整体到细节、从上到下，不要东一句西一句。读者跟着视线走，画面自然出来，还能顺带引出躲在角落的人/物。
- **人物视角法（最省力不水字数）**：主角注意力在哪，环境就写到哪；和目标、情绪无关的一律不写。被追杀的人不会注意砖什么颜色、墙边长什么花，只关心出口和身后的脚步声。
- **情绪烘托法**：不要直写"他很害怕"，用环境把情绪具象化。钟摆滴答敲在心口、天阴得发黑、风卷树叶撞玻璃——一个"怕"字不提，读者却感到压抑。
- **细节锚点法**：抓 1-2 个最有代表性的细节，胜过写全整个场景。用具体细节代替空泛形容词。
- **动词 > 形容词**："风很大"不如"风把窗帘掀起来又甩下去"。动起来的景比静止的景让人记得住。
- **能一句带过别写三句**："黄昏，风有点凉"七字，画面、凉意、心情全有。读者扫过环境描写往往只用几秒，服务三件事之一即可——交代人物状态、烘托情绪、推动情节。
- **让环境成为"心理镜"**：同一空间，心情不同看到的细节完全不同。阳光可以是满足的金边，也可以是监狱的铁栏。
- **让环境推动情节**：给环境加一个会变化/带危险的属性（身后门在缓缓自动关上、身后的脚步声近了），环境本身就成了情节驱动力；让物品当"沉默的证人"（洗手台上多了一支陌生口红）。

## 可直接套用模板/清单
- **镜头推移模板**：远景（天/山/建筑轮廓）→ 中景（门/桌/墙）→ 近景（蜡烛/草堆/衣角）→ 特写（引出关键物或人）。
- **人物视角过滤清单**：此刻他/她最可能注意什么？→ 只写这个。用他/她的口头禅或职业思维去比喻环境（木匠觉得山脊像刨痕，厨师觉得晚霞像文火焖出的焦糖色）。
- **不水字数自检**：删掉这段，剧情/人物/情绪是否少了一块？少 → 必须留；不少 → 砍。
- **动词替换练习**：把每个形容词改写成"主语+动作"。例："巷子很暗"→"高墙把光线嚼得只剩一线"。

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 不为了"好看/炫文笔"写环境；环境是工具不是目的。

## `novel-how-food` · 食物/吃喝描写怎么写


# 食物/吃喝描写怎么写

## 适用场景
- 想用"一顿饭/一道菜"写人物底色或关系。
- 需要烟火气中和压抑，或写饥饿/乡愁/团圆。
- 避免"他吃了一碗面"式无效交代。

## 核心技法
- **吃相即人品**：狼吞虎咽=饿/急/率真；细嚼慢品=从容/讲究；挑食剩饭=娇/挑；给旁人夹菜=顾人。怎么吃，比吃什么更写人。
- **五感写食**：色泽（视觉）、香气（嗅觉）、外皮脆内里软（味觉触觉）、热气氤氲（视觉）。只写"好吃"是失败，写感官才让读者馋。
- **以食写关系**：谁做给谁吃、谁舍不得吃留一口、谁把好的推过去——食物是爱的无声语言。共餐=亲密，分食=患难。
- **食物承载乡愁/记忆**：一口家乡味勾出整段过往；久饿后第一口热的，写出生之喜悦。食是情感的触发器。
- **饥饿写状态**：久未进食的手抖、闻到味本能咽口水的本能——饥饿是身体最诚实的告白，可外化角色处境。
- **景随情变**：团圆时饭菜香暖；离别时同一道菜噎喉。食味随心境变。

## 可直接套用模板/清单
- **吃相信号**：狼吞___ / 细品___ / 留一口___ / 推好的___。
- **五感勾选**：色___ / 香___ / 味触___ / 热气___。
- **食载情**：谁做给谁___ / 乡愁触发___ / 饥饿本能___。
- **自查**：吃相写人了吗？五感馋人了吗？食物传情了吗？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 食写人与关系，五感勾人，不写"好吃"二字。

## `novel-how-magic-combat` · 法术 / 异能战斗怎么写


# 法术 / 异能战斗怎么写

## 适用场景
- 玄幻、修仙、奇幻、都市异能等超自然战斗：施法、斗法、元素对撞、异能交锋。
- 想写出"出招前天地异动、一招风云变色"的气场，又不至于水字数。
- 法宝、符箓、阵法、能量特效类对抗。

## 核心技法
- **气氛渲染四问**：为什么打？跟谁打？在哪里打？影响力/围观者如何？给双方充分理由，确定地点与围观人群（超自然战斗往往藏不住，需围观者反应）。
- **招式与气场（区别于武侠物理攻击）**：出招前沿有天地异动（大风、雷电、星辰异象）显气场；出招后风云变幻、空气扭曲、能量特效爆发。再叠加旁观者震惊（"天怎么红了"）。
- **视角把控**：以主角视角推进，写主角心理（藐视敌方 / 暴怒）；配角只写动作与神态（咬牙咳血、傲慢、如临大敌），不抢戏；可加远处旁观者感受烘托。
- **力量来源与功法效果**：描写力量从何处涌出、功法特性、法宝威力（施展时间、特效、破坏范围），而非只报招式名。
- **战斗结构（爽文公式）**：气势对拼 → 语言交锋（反派挑衅、主角淡定）→ 出招展示 → 敌人防御 → 碾压/秒杀 → 路人惊叹。先铺垫反派极强，再被破，反差即爽感。
- **五感 + 旁观者反应**：用路人惊叹侧面衬托强大；注重细节（表情、动作、环境破坏）。
- **篇幅自律**：玄幻打斗不宜过长，2000 字章节中打斗部分建议 ≤700 字（约 1/3），避免被评水字数。

## 可直接套用模板 / 清单
- **施法模板**：[气场铺垫：天地异动] → [主角视角心理/意图] → [出招：力量涌出 + 功法特效 + 环境变化] → [敌人应对/破防反应] → [旁观者惊叹/结果衔接]。
- **斗法反转模板**：[反派极强铺垫] → [语言交锋] → [主角轻描淡写破局] → [反派错愕] → [路人震惊收束]。
- **自检清单**：
  - 四问（为何/与谁/何地/影响）答了吗？
  - 出招前气场、出招后特效是否到位？
  - 主角心理 + 配角神态是否分离描写？
  - 是否有旁观者反应做爽点加速器？
  - 篇幅是否控制在章节 1/3 内？
- **避坑**：不要只喊招式名无画面；不要全程上帝视角；不要超长灌水。

## 红线
- 用通用措辞，不照搬任何专属 IP。

## `novel-how-mountain-top` · 山顶/高处场景怎么写


# 山顶/高处场景怎么写

## 适用场景
- 角色登顶/临崖，需要"天地很大我很小"的孤绝或格局感。
- 想用高处写顿悟、决断、或与宿敌的终极对峙。
- 风雪、险峰作为人物意志的试炼场。

## 核心技法
- **高度=孤独与格局的双重隐喻**：脚下云海、远处群峰——既显主角渺小（孤独），又显其已凌驾众生（格局）。俯瞰的视角天然带"看透"的意味。
- **风雪是试炼**：刺骨的风、缺氧的喘、冻僵的指、脚下碎石的松动——身体的险境外化内心的关口。登顶的难，写的是"值不值得"。
- **一览众山小的转折**：在顶上回望来路，此前纠结的事忽然变小——高处天然制造认知跃迁，适合人物顿悟或最终决策。
- **声音的稀疏**：高处风声盖过一切，人声、心跳被放大。寂静与风啸交替，营造神性/肃杀。
- **崖边=边界**：站在边缘俯瞰深渊，是"退一步平庸/进一步成"的具象。慢镜头写这一步。
- **景随情变**：胜利者看日出是犒赏；败者看云海是虚无。同一高度，两种心境。

## 可直接套用模板/清单
- **高度隐喻**：渺小（孤）___ / 凌驾（格局）___ 各用在哪___。
- **试炼细节**：风___ / 缺氧___ / 冻指___ / 碎石___。
- **顿悟/抉择**：顶上回望___ / 决定的事___ / 崖边那一步___。
- **自查**：高度双隐喻用上了吗？风雪试炼写了吗？俯瞰带来认知跃迁吗？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 高处写格局与试炼，不写风光游记。

## `novel-how-nature` · 山林/自然场景怎么写


# 山林/自然场景怎么写

## 适用场景
- 山林、山水、田园、海岸、旅途中的自然景观
- 需要风景有"性格"与情绪，而非明信片式复刻
- 用自然外化人物心境

## 核心技法
- **黄金法则：没有绝对客观的风景，只有人物主观眼中的风景**。快乐与悲伤的人看同一座山是两个世界。先决定希望这片风景传递什么情绪（宁静/狂野/压抑/神秘），再用拟人化去写：微风"蹑手蹑脚溜过草地"、乌云"像沉闷军队从天边压境"。
- **注入情绪的词让风景有性格**：同样"山树瀑蓝天"，用"沉默顽固、压抑、决绝、粉身碎骨、沉闷怒吼、冷酷"等带情绪色彩的词，风景立刻充满压迫感与力量感，映射人物困境。
- **五感综合实战模板**：【远景光影+视觉】+【中景形态+视觉】+【风声/鸟鸣+听觉】+【草木/泥土气息+嗅觉】+【风的温度+触觉】+【淡淡味觉一笔收尾】。例："夕阳漫过原野染青草暖金；村落沉暮色炊烟升；风掠草尖轻响，空气裹泥土青草淡香；晚风不燥不寒拂脸；呼吸带清浅温润。"
- **四大写景视角（告别流水账）**：
  1. 由远及近（最稳，适合开篇定调）：大远景→中景主体→近景细节→特写点睛。
  2. 由高到低：天空→云层→山峦/屋顶→林木→地面→流水。
  3. 整体→局部：先写整片气韵，再收拢定格极小细节（落叶/残花/露珠/小虫）。
  4. 移步换景：立足→前行所见→转角新景→驻足定格，如带读者散步。
- **味觉写景（小众高阶）**：山间晚风带草木清浅甘冽，深吸胸腔透清爽；雨后空气入喉淡润甜，洗去尘燥。一笔拉高格调，用于山野/暮色/夜雨。
- **动静结合**：先写静态画面（湖面如镜倒映垂柳），再引入动态（微风拂过柳枝泛涟漪）。"风定花犹落，鸟鸣山更幽。"
- **发现独特性+确定顺序+多种感官**：每处景物有独特征（枫叶红似火、锯齿如巧手勾勒）；按空间顺序条理清晰；感官真实贴切不牵强。
- **拟物化比喻/四时流转/留白**：远山如青瓷茶盏、云海泼翻茶汤；春樱冬雪藏年轮；留白虚实相生（桥那端水墨晕染的远方）。

## 可直接套用模板/清单
- **五感综合模板**：远景光影 → 中景形态 → 听觉(风/鸟) → 嗅觉(草木/泥土) → 触觉(风温) → 味觉一笔收尾。
- **视角选择器**：开篇定调用由远及近；定点写景用由高到低；余味悠长用整体→局部；游记叙事用移步换景。
- **性格赋予清单**：写前先定情绪词 → 用拟人动词+带情绪形容词 → 抓1-2个最独特细节大力渲染、忽略其余。
- **动静练习**：本段是否先静后动？是否有"摇曳/流淌/蒸腾"类动词替代静态描述？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 避免"蓝天白云青山绿水"俗套与地理说明书式无效描写；风景须为故事服务。

## `novel-how-plant` · 植物意象怎么写


# 植物意象怎么写

## 适用场景
- 想用一株植物（盆栽/树/花）承载时间流逝或人物命运。
- 需要"枯荣即兴衰"的隐喻而不靠旁白。
- 写庭院、药草、或主角与某株草木的漫长陪伴。

## 核心技法
- **草木即时间刻度**：一株苗从种下到开花结果，默默丈量主角经历的岁月。读者看花开花落，就懂"过了很久"。比"三年后"更有体感。
- **枯荣=兴衰隐喻**（见 novel-how-symbolism）：繁花=得意/盛年；凋零=衰败/失去；新芽=希望（见 novel-how-hope）。植物的状态变化=人物弧光的镜像。
- **以草木喻人**：倔强活着的野草=主角处境；被挪盆仍活的树=韧性；名贵却娇的花=易碎的美好。选物贴合人物。
- **药草/功能性植物**：若写采药、培育，给植物具体效用与主角与它的互动（每日浇灌、叶枯则忧），让"种草"成为人物日常的锚点。
- **留白式收束**：结尾写"那株他种下的树，今年又开了"，不抒情，时光与念想尽在花里。
- **景随情变**：主角欣喜时草木葱茏；心境枯槁时连叶子都蔫。植物随人心。

## 可直接套用模板/清单
- **时间刻度**：种___ / 开花___ / 对应主角经历___。
- **枯荣映射**：繁花=___ / 凋零=___ / 新芽=___。
- **喻人选物**：野草___ / 挪盆树___ / 娇花___。
- **自查**：草木丈量时间了吗？枯荣映人运了吗？结尾留白了吗？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 草木写时间与命运，枯荣即兴衰，不靠旁白。

## `novel-how-weather` · 天气描写怎么写（雨/雪/雾）


# 天气描写怎么写（雨/雪/雾）

## 适用场景
- 用天气外化人物内心波动（从压抑到释放、从阴霾到明朗）
- 渲染离别、重逢、孤独、阴谋、治愈等场景
- 做情节隐喻、铺垫重大转折

## 核心技法
- **天气是最直观的情绪映射工具**：从晴到阴、从雨到晴，天气变化本身就是角色内心的变化。可以延迟映射（先写下雨铺垫，十分钟后再写她终于哭出来呼应），也可以反向衬托（阳光灿烂的午后收到病危通知）。
- **通用天气-情绪映射表（可套用）**：
  - 细雨 → 忧伤、怀念、惆怅、温柔；雨丝细密、打在脸上凉凉、模糊视线。
  - 暴雨 → 失控、释放、愤怒、悲伤；雨声轰鸣、天地混沌、砸在心上。
  - 雪 → 宁静、孤独、纯净、绝望；无声、覆盖一切、世界变安静。
  - 薄雾 → 迷茫、犹豫、朦胧、神秘；看不清前方、轮廓模糊、像隔一层纱。
  - 烈日 → 焦灼、烦躁、愤怒；光线刺眼、空气扭曲、皮肤发烫。
  - 彩虹 → 希望、释然、喜悦；转瞬即逝、像一种承诺。
- **天气的四个戏剧维度（避免平铺直写）**：序幕（征兆，如蜻蜓低飞划出弧线）、高潮（爆发，如闪电撕裂天幕）、变奏（微妙变化，如雨脚忽密忽疏像钢琴家犹豫的指法）、尾声（过后的痕迹，如暴雨洗过的天空蓝得像刚出窑青瓷）。
- **雨/雪/雾的专属写法**：
  - 雨：雨声像白噪音模糊世界，只剩两个人；雨水顺着额头流下分不清是雨还是泪；"下了三天，像老天爷哭了一整个季节"。
  - 雪：落下来没有声音，世界安静得像坟墓；人站路灯下像一尊雪雕；大雪封城，只有故事还在继续。
  - 雾：像一层薄纱裹着山、树、石板路；雾沾脸凉丝丝像母亲的手；卖豆浆的吆喝声穿过雾变得软软的。
- **光线与色彩渲染**：清晨微光=希望新生；正午强光=焦灼无处可逃；黄昏暖光=怀念感伤；夜晚冷光=孤独恐惧。色彩象征：红=愤怒/危险，蓝=忧郁/孤独，灰=压抑/麻木，金=温暖/回忆，黑=恐惧/未知。

## 可直接套用模板/清单
- **天气-情绪映射模板**：选情绪 → 选对应天气 → 写"前奏征兆→爆发/持续→尾声痕迹"三阶段 → 保证含 ≥2 种感官（视觉+听觉/触觉/嗅觉）。
- **延迟映射练习**：第1章写天气（铺垫），关键情绪在第3章才爆发（呼应），让天气成为伏笔。
- **雨/雪/雾速写清单**：雨=声音白噪+视线模糊+凉意触感；雪=静默+覆盖+单体孤独剪影；雾=包裹感+轮廓模糊+远处声音变软。

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 禁忌：为写天气而写天气；违背自然规律（台风天突然星空）；单一重复使用（全程都是雨天）。

## `novel-how-worldbuild-show` · 世界观怎么展示


# 世界观怎么展示

## 适用场景
- 幻想/科幻/异界文，背景规则多但不能开头砸设定
- 避免" info dump "——大段旁白说明把读者劝退
- 让世界通过情节和人物自然渗出来

## 核心技法
- **设定写细、展示渐进**：世界观文档可以写极详细，但正文要像剥洋葱，前三章只亮最必要的冲突相关规则，其余随情节展开
- **用人物眼睛看世界**：新场景通过主角/配角的观察、疑惑、误读来呈现，比旁白说明更有代入感
- **VO（视点人物）展示**：借角色的五感+反应带出环境规则（"这里连呼吸都要付费"比"本城实行空气税"生动）
- **旁白克制**：非必要不跳出上帝视角解释。能用动作/对话暗示的，别用说明
- **规则即冲突源**：世界观设定尽量和主角困境绑定——限制主角的规则，本身就是戏剧张力
- **前后统一**：力量/货币/阶级规则一旦定下，全文不可自相矛盾（靠大纲+设定文档锁）

## 可直接套用模板/清单
- [ ] 设定文档写全，正文只在前三章亮冲突相关规则
- [ ] 新世界：借主角眼睛+五感带出，不用旁白砸
- [ ] 每条规则能否和主角困境挂钩？能→保留，不能→后置
- [ ] 自查：有没有超过3行的纯设定说明？有就改成展示
- [ ] 全文规则一致性，靠大纲设定表核对

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 展示>说明，让读者在情节里自己拼出世界
