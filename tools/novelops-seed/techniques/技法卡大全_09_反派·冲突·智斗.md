## `novel-how-bizwar` · 商战怎么写


# 商战怎么写

## 适用场景
- 霸总文、行业文、创业文、家族企业斗争
- 公司竞标、并购、股价做空、舆论战、供应链争夺
- 商战作为个人能力证明、组织进化引擎、文明对话语言
- 用商业规则本身构建"力量体系"

## 核心技法
- **双方必须势均力敌**：商战的张力来自"对弈双方各有千秋"，而非一边倒的碾压。给对手合理优势（如对手产业带动上下游、促进周边升值），让局势举棋不定，故事由此展开。
- **六类常见竞争手段**：①股票做空（摸清对手持仓，反向砸钱拉爆头寸）②商业间谍（窃机密、拍私生活、盗代码、举报违规）③舆论战（热搜、舆情危机，需黄金响应窗口）④供应链/渠道封锁 ⑤价格战与补贴烧钱 ⑥借政策/法规条款反制（如银行抽贷条款、准入负面清单）。
- **三幕式商战模型**：第一幕（风险识别期）单点突破、节奏紧凑；第二幕（系统构建期）多产业线并行、波浪式推进，每轮高潮后接技术细节铺陈；第三幕（规则升维期）沉潜式留白，重心转向技术伦理与文明命题思辨。最高潮往往是"以专业主义解构流量神话"。
- **力量体系即商业规则本身**：无超自然设定，社会规则披露融入情节（危机源于某条款细则、成立需符合某法规）。地理风貌与产业绑定（港口物流优势、高校科研资源直接解释设厂选址）。
- **行业报告体语言**：语体凝练书面白话，杜绝方言俚语网语；环境描写聚焦功能性信息；比喻全部源自商业领域；心理描写占比低，且严格限定于决策逻辑推演。
- **人物由行为细节承载**：摒弃外貌与内心独白，特质全由动作细节外化（如固定消费精确到小数暗示财务自律）；配角用"职业动作"区分（永远边啃肉边看财报、习惯用器物敲桌思考）。
- **渐进揭示法**：商战能力不以金手指突兀出现，严格遵循"认知—实践—反馈"闭环，层层递进使成长可信。
- **伏笔锚定法**：关键商战节点均埋超前伏笔（早期一通电话为后期贷款提供合法性；前期对挪用公款的精准预判实为已掌握财务漏洞）。伏笔是商战逻辑链的刚性铆钉。
- **镜像对照法**：设置多组方法论/路径/战略镜像（人脉资本 vs 制度资本、代际方法论对照），深化思辨厚度。

## 可直接套用模板/清单
- **商战开局检查**：双方是否势均力敌？对手有无合理优势？冲突是否源于真实商业逻辑（非个人恩怨降智）？
- **竞争手段库**：做空 / 商业间谍 / 舆论战 / 供应链封锁 / 价格战 / 法规反制——选 2–3 种组合，避免只用"一句话破产"。
- **三幕商战结构**：风险识别（单点）→系统构建（多线+技术细节）→规则升维（留白+伦理）。
- **行业术语体自检**：本章比喻是否都源自商业/行业？环境是否功能性？心理是否限决策逻辑？
- **伏笔锚定清单**：列出 3 个商战关键节点，各自提前埋设的"刚性铆钉"是什么？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 避免绝对碾压式"霸总商战"，对弈须势均力敌。
- 商业规则/术语须自洽可验证，不能凭空编数值。

## `novel-how-conspiracy` · 阴谋布局（长线）怎么写


# 阴谋布局（长线）怎么写

## 适用场景
- 百万字长篇的阴谋主线、跨百章伏笔、全局棋局
- 需要把零散线索织成"密不透风的网"
- 避免长线坑填不上、中后期逻辑崩盘、烂尾
- 大纲/人物卡/伏笔清单等控局工具运用

## 核心技法
- **草蛇灰线≠一次性铺垫**：线索如草丛里蛇的淡痕，时隐时现、断断续续，横跨百章才集中回收。核心规则：①初次埋设弱化存在感（不刻意渲染、不标注"此物关键"）②中段间断露痕（每隔数十章轻轻提一次，不让读者彻底遗忘）③终局集中闭环（所有零散线索串联，解释前文所有反常细节）。
- **分层挖坑法（长短坑拆分）**：把所有伏笔按短期/中期/长期精准拆分，各司其职互不干扰。短期坑（3–10 章回填）负责留住追读、制造小反转；中期坑（50–100 章回填）支撑单元剧情、拉升口碑；长期坑（全书贯穿）锚定主线、锁定铁杆读者。小坑高频填、中期坑按时填、长期坑慢慢铺。
- **嵌套回填法（填坑即挖坑）**：填掉旧坑同时自然诞生新坑——浅层伏笔解决表层冲突→回填中暴露更深层秘密→无缝开启新主线。每一次回填都不是"结案收尾"，而是层层递进的剧情解锁（填小坑出中坑，填中坑出大坑），杜绝流水账与平淡期。
- **隐性留白回填法**：前期只用细碎细节铺垫，不刻意强调、不制造悬念，后期轻轻一笔回扣，读者恍然大悟。显性挖坑靠悬念抓人，隐性挖坑靠细节封神（如童年老宅常青的某株花，前期日常细节，后期揭晓是离世至亲所种，温柔隐喻隐秘陪伴）。
- **兜底容错回填法（防烂尾）**：①废坑合理化——无效伏笔不强行删除，改为"反派刻意布置的烟雾弹/虚假线索"；②小坑合并化——多个零散小坑统一归属一个终极大坑批量闭环。没有烂剧情，只有不会回填的伏笔。
- **伏笔的网状结构**：线性伏笔 A→B→C，网状伏笔 A 同时指向 B/C/D，B 又指向 E/F。设计核心悬念，不同卷埋下指向它的伏笔，并让伏笔间相互关联（第一卷细节是第三卷事件起因）。
- **埋设三要素**：自然不刻意（融入对话/环境/动作/细节，不直白告知）、精准不冗余（每个伏笔服务剧情/人设/世界观）、提前有规划（动笔前梳理完整伏笔清单）。
- **回收三技巧**：准时不吊胃口（短期几十章、中期百章、长线高潮/结局揭秘）、高潮回收爽感翻倍（多伏笔汇聚层层揭秘）、全程闭环无一遗漏（开篇微小细节后期必有呼应）。
- **主节点控局（长篇不崩盘）**：根据大纲设几个最关键主节点（灯塔），故事未偏离主线即明证；每连载五章回头复盘，总结概要推演将来，若与大纲偏差，无论如何绕路也需抵达下一主节点。修改主节点须慎之又慎，反复推演与其他节点及结局的逻辑关系。

## 可直接套用模板/清单
- **草蛇灰线三步**：弱化初埋→间断露痕→终局闭环。列出本书 3 个长线物证/习惯/台词。
- **分层挖坑表**：短期坑（回填章数+收益）/中期坑/长期坑，各列 2–3 条。
- **嵌套回填模板**：浅层解决→暴露深层→开启新线。检查最近一次填坑是否出了新坑。
- **兜底两公式**：废坑→反派烟雾弹；散坑→合并归终极大坑。
- **伏笔清单（必建）**：编号/伏笔内容/埋设点/类型(道具/习惯/台词/设定)/计划回填点/归属主线。每 5 章复盘更新。

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 避免开篇堆海量大坑、长短混杂导致后期圆不上。
- 伏笔须提前规划、全程闭环，杜绝无回填的废坑（除非兜底合理化为烟雾弹）。

## `novel-how-smart-protagonist` · 智商在线主角（不降智）怎么写


# 智商在线主角（不降智）怎么写

## 适用场景
- 设计高智商/谋略型主角，怕读者说"作者替他作弊"
- 反派或配角被强行降智来衬托主角
- 想写势均力敌的智斗拉锯
- 自检：主角聪明靠旁白说、危机提前铺垫半章、对手全是弱智

## 核心技法
- **聪明必须靠行动体现，不靠介绍说明**：读者不信"作者说他聪明"，只信情节。"[角色A]早已看穿一切"=一句空话；要写"在这一刻换成别人已完，但[角色A]没完"。
- **快反应决策公式：突发危机 + 极限选择 + 意外解法**：
  - 突发危机要"突然"：不给准备时间，事情直接发生（宴会意外坠落、对手当众指控），[角色A]没时间慢慢分析。
  - 极限选择只给两条烂路：如认栽/硬刚、牺牲自己/牺牲别人，写清让读者看懂。
  - 意外解法：在突发下迅速做出更优解，展现应变而非神棍预知。
- **聪明对手互相衬托**：设定与[角色A]旗鼓相当的对手[角色B]，形成"我预判你的预判"左右互搏。更爱对手（一碗水端平甚至偏爱对手）写出来更有意思；单方碾压易显"状其多智而近妖"。
- **压缩时间显急智**：普通人临场反应慢、事后才想到，而高智商者当即反应且想得周到（如当场列出头层二层三层逻辑、预判对方反应）。作者花几天想，写角色一秒想好，这合法。
- **精简台词也是一种压缩**：无信息量的问句越少双方越显聪明；双方都聪明可进一步精简到"打机锋"，但酌情用以免迷惑。
- **大材小用**：把规模大、强度高的事件素材，拿来写规模小、强度低的剧情（班上搞班长竞选如总统竞选、小城镇炒农作物期货如金融战）。"烹小鲜如治大国"。
- **好记性靠伏笔回收**：过目不忘类设定，用备忘录严格记录其经历/知道什么，通过伏笔回收展现效果，避免作者自己记混。
- **绕开读者思路**：当读者思考 A 和 B 哪种好时，让[角色A]选更好的 C 方案。

## 可直接套用模板/清单
- **高智商主角写法自检**：
  - [ ] 聪明通过具体行动/选择展现，无"作者说他聪明"
  - [ ] 危机突发不给准备时间，主角临场应变
  - [ ] 极限选择只给两条烂路，解法意外但合理
  - [ ] 有旗鼓相当的高智商对手（非降智配角）
  - [ ] 台词精简、信息密度高
  - [ ] 用伏笔回收体现"好记性/博学"而非堆术语
  - [ ] 大材小用或 C 方案反套路展现思维
- **避坑**：不要给反派/配角强行降智；不要通篇堆看不懂的术语念经；不要危机前铺垫半章消解紧迫感。

## 红线
- 用通用措辞，不照搬任何专属 IP。

## `novel-how-spy` · 谍战/卧底怎么写


# 谍战/卧底怎么写

## 适用场景
- 谍战、特工、潜伏、双面间谍、地下工作
- 多阵营（三方以上）动荡年代背景
- 身份伪装、情报传递、信任攻防
- 用物证与行为细节承载叙事，而非心理独白

## 核心技法
- **多阵营框架（核心前提）**：选择一个动荡年代/时期，构建三个以上不同立场的势力。多阵营让[角色A]能在绝境中穿梭、获取情报、完成任务，配角塑造更灵活，任务多样性避免审美疲劳（如被[阵营A]营救却推入[阵营A]的险境，再被[阵营B]所救或重陷敌手，循环往复但适量）。
- **多面维度角色设定**：谍战人物一般具极复杂设定（如一人有多重身份：表面/实际/最终成为）。前期规划人设框架：阵营、派系、表面、实际、最终。灰色地带角色值得推敲——好人不必全优点，坏人不必全缺点，矛盾角色最出彩。
- **身份即武器（认知折叠）**：身份认知从严格区分多重身份→主动制造混淆→彻底消解边界（所有社会角色成为可随时拆卸安装的战术模块）。关键信息从不直述，通过多重视角拼贴完成（伪视角→半真视角→全真视角三次认知折叠达成"身份即武器"揭示）。
- **伪装的最高标准：不可证伪性**：伪装不是扮演，而是对目标人群生理特征、心理状态、社会痕迹的系统性模拟——所有细节指向"不可证伪"。
- **物证链伏笔（三次出现法则）**：核心伏笔以日常物品为载体，严格遵循"三次出现"——首次埋设→二次强化→三次闭环（揭示身份/背景内在统一）。物品即加密情报载体（纸条、暗语电话、行为本身）。
- **静默爆发式节奏**：每章前 80% 铺陈日常细节，最后 20% 突然切入高危动作，形成生理阅读压迫感。关键节点平叙完成，拒绝情绪渲染，迫使读者自行补全震颤。
- **行为考古学塑造**：摒弃心理描写，性格全由可验证动作/微表情外化（攥紧某物指节泛白暗示恐惧与决断并存；敲击窗台手指骤停暴露情绪波动；标志性动作确保信息过载中瞬时识别角色）。
- **情报密度世界观**：年代不作为背景板，而以情报价值分层呈现（霓虹亮度决定夜间接头可视距离、曲目更换周期反映管控强度、住宅距某机构公里数绑定任务参数）。地理/势力绑定具体任务参数，拒绝静态风貌描摹。
- **方言口语与专业术语精密咬合**：内心独白用现代/地域口语强化身份印记，外部叙事用时代白话+专业术语；修辞极少用比喻，高频意象（刀=身份切割，线=情报网络）均服务场景功能。

## 可直接套用模板/清单
- **三幕谍战结构**：身份锚定（穿越/审讯/牢房博弈，被动→主动）→信任攻防（潜伏、接头、暗战，多层悬念反转）→格局升维（战场延伸，个人存亡→组织战略，终局前刻意放缓蓄力）。
- **多阵营检查**：是否有三方以上势力？主角是否能在阵营间穿梭制造循环绝境（适量）？
- **物证链三次法则**：列出核心物证，确认首次埋设/二次强化/三次闭环节点。
- **伪装不可证伪清单**：生理特征？心理状态？社会痕迹？细节是否系统性模拟？
- **行为外化卡**：为每个关键角色定 1 个标志性动作/微表情，替代心理独白。

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 多阵营循环适量，不可过多导致混乱。
- 谍战背景若涉近现代史实，遵循合规表述，灰色角色可推敲但不美化侵略方。
