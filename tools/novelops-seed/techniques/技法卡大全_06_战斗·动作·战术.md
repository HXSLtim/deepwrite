## `novel-how-chase-escape` · 追击与逃亡怎么写


# 追击与逃亡怎么写

## 适用场景
- 一方追、一方逃的移动中战斗：街头逃亡、丛林追杀、载具追逐、猎杀与反猎杀。
- 想写出"屏住呼吸"的紧张感与一波三折的险象环生。
- 逃跑过程中边移动边战斗/周旋的桥段。

## 核心技法
- **四要素**：被追者、追击者、脱险动作、人物感受——追逐本身的节奏比参与者更重要。
- **布局三环节**：① 确立追逐规则；② 明确赌注（被抓的真实危险）；③ 以激励事件拉开追逐。
- **空间收窄制造紧张**：地理范围越小紧张感越强；让被追者一度走投无路，被抓即有真正危险。
- **阻碍设计（极限拉扯）**：预设陷阱、地形限制、工具短缺等阻碍。一场追逐约 3 个大阻碍 + 若干小阻碍，制造逆转与意外，出乎预期但不违前文逻辑。
- **时间锁与地域锁**：叠加时间压力（倒计时式危机）或地域封锁（密闭空间、边境线），将氛围推至极致。
- **期待落点**：明确读者期待逃走还是被擒？向读者期待靠拢（爽文装逼 / 虐文失利 / 感情线），别写嗨了忘了目的。
- **情绪节点化**：走投无路的绝望、即将脱险的狂喜——情绪由人物传递给读者，节点呈现才有感染力。
- **张弛交替**：不能全程满弓。紧张中穿插短暂喘息，让读者多悬一会儿心。
- **动作驱动**：追逐以肢体行动推进，少用大段心理描写；追击者须有合理机会逼近甚至暂时抓获被追者。

## 可直接套用模板 / 清单
- **追逐模板**：[规则+赌注+激励事件] → [第一阻碍/脱险] → [第二阻碍/反转] → [第三阻碍/极限拉扯] → [时间锁或地域收紧] → [落点：逃脱/被擒/假象] 。
- **紧张感清单**：
  - 四要素是否齐全？被捕获的真实危险是否明确？
  - 空间是否受限（范围越小越紧）？
  - 是否设计了 3 大阻碍 + 小阻碍？
  - 是否有时间锁/地域限制？
  - 期待落点是否贴近读者预期？
  - 是否有张有弛（含短暂喘息）？
- **避坑**：别让追逐变成纯跑步无阻碍；别遗漏"被抓的危险"以致紧张感空洞；别只靠心理长段拖慢节奏。

## 红线
- 用通用措辞，不照搬专属设定 / IP 的具体载具与世界规则。

## `novel-how-command` · 命令/威压对话（强者气场）


# 命令/威压对话（强者气场）

## 适用场景
- 上位者训话、boss 下达指令、强者登场
- 威慑、警告、服从测试、不卑不亢的对抗
- 需要"他本身即是威压"而非靠喊叫

## 核心技法
- **气场即隐形压迫**：从眼神写内心强大，语言配合动作加强，再用周围人反应做衬托对比（配角大气不敢出、额头冒汗、不战自溃）。
- **强者画像**：学识阅历深厚、个人风格鲜明（不苟言笑却得体）、身体语言沉稳（惜字如金、目光深邃、声音清冷有力）、遇事不慌是最终拍板者。
- **威压靠"存在"而非外放**：顶级强者无需刻意施压，本身即是压迫。可用"真空"手法——风在其周身死去、影子静止、连空气都向其流动。
- **命令台词短、冷、定**：一字一顿、不容置疑、不带情绪起伏却定人生死。越克制越有压迫感。
- **配角反应外化威压**：不能只靠主角自己撑冷酷，写下属在注视下"嘴巴张合四五下终是一字没说出"，压迫感由他人反应落地。
- **不卑不亢对抗模板**：弱势方立身不动、字字铿锵、简洁回绝，用坦荡强势斩断招揽。
- **威胁的本质**：让对方相信你能做、敢做、已开始做——具体时间 + 点名软肋 + 限定时间，比空喊狠话有力。

## 可直接套用模板/清单
- 气场三件套：①视觉锚点（极致的普通/异象）②他人极端反应（恐惧、臣服、窒息感）③声音描写（轻却人人听清、如大道纶音）。
- 命令句检查：能否删到最短？有无情绪废话？是否"定人生死"不容商量？
- 衬托写法：写完强者台词，补一句旁人生理反应（咽唾沫、倒退着走出门、不敢呼大气）。
- 对抗张力：弱势方用"简单三字+沉稳傲骨"（"威胁我？"）破对方气场。
- 威压禁忌：避免全程靠形容词堆"冷峻威压"，要用具体行为与第三人反应落地。

## 红线
- 用通用措辞，不照搬专属设定 / IP。

## `novel-how-curbstomp` · 秒杀 / 碾压怎么写


# 秒杀 / 碾压怎么写

## 适用场景
- 主角或强者一击终结战斗：秒杀小怪、碾压反派、降维打击。
- 擂台/冲突中"轻轻一掌对方飞出"的装逼名场面。
- 想用短篇幅制造极致爽感与反差。

## 核心技法
- **先扬后抑的反差爽感**：先铺垫反派嚣张至极、主角一再隐忍，情绪积累到临界点后主角瞬间暴起一招制敌，读者酣畅淋漓。
- **强弱反差写法**：被碾压方拼尽全力的绝杀一击，触碰强者的壁垒便如泥牛入海；强者甚至未碰对方衣角，对方已重伤倒飞。突出"轻松"二字。
- **篇幅配比**：
  - 秒杀：50–100 字，极快，短句动词密集，一击必杀。
  - 碾压：200–300 字，快，装逼打脸。
  - 势均力敌：500–800 字；苦战：800–1500 字。
- **技能描写三要素**：技能名 + 视觉效果；威力量化（破坏范围 / 地形改变）；技能对比（凸显主角更强）。
- **旁观者反应不可缺**：路人震惊 / 捧哏是爽点加速器，一句话即可。
- **五阶段节奏（单场完整战斗）**：试探→交锋→危机→爆发→终结；秒杀只取"试探 + 终结"压缩。
- **收尾三式**：低调离场（打完就走不解释）；一句话压场（气势到位别废话）；意境收束（画面定格让人记得久）。

## 可直接套用模板 / 清单
- **秒杀模板（极简）**：[反派铺垫/挑衅] → [主角淡漠出手的极短动作链] → [反派全力一击被轻易瓦解的对比] → [一击结果 + 路人震惊] → [低调/意境收尾]。
- **碾压模板**：[反派自信登场] → [主角轻描淡写化解 + 视觉特效] → [反派错愕] → [压制性反打 + 环境破坏] → [旁观者捧哏 + 装逼收束]。
- **自检清单**：
  - 反派是否先被铺垫得足够强/嚣张？
  - 是否用"轻松 vs 全力"的反差对比？
  - 字数是否符合秒杀/碾压的短篇幅？
  - 是否有旁观者一句震惊？
  - 收尾是否有余韵（低调/压场/意境）？
- **避坑**：不要毫无铺垫就秒杀（无爽感）；不要写成长篇苦战消解"碾压"感；不要让配角抢戏。

## 红线
- 用通用措辞，不照搬专属设定 / IP 的招式名与等级。

## `novel-how-duel-aftermath` · 战斗后遗症 · 代价回收


# 战斗后遗症 · 代价回收

## 适用场景
- 一场大战落幕，需要写"赢了但付出了什么"
- 想让战斗不止于"敌人倒了"，而是改变人、改变地、改变关系

## 核心技法
1. **身体的诚实**：颤抖的手、视线模糊、伤口才觉疼——肾上腺素退去后的真实。
2. **环境的战损**：焦痕、碎裂的器物、未干的血——景是战斗的墓志铭。
3. **心理余震**：手还在抖、耳边回响兵刃声、对[角色B]最后眼神挥不去——胜者的PTSD。
4. **关系位移**：活下来的人看彼此的眼神变了，死了一个谁，剩下的少了什么。

## 模板清单
- 身体：[角色A]撑着断刀起身，才发现左腿麻得没知觉，低头看见血把裤管浸透
- 环境：风卷过战场，灰里混着焦糊味，半截断旗插在尸堆上
- 余震：他闭上眼，耳边还是[角色B]最后那声闷哼，挥之不去
- 关系：活下来的[角色C]默默替他包扎，两人都没说话，以前的话此刻都轻了

## 红线
- 禁战斗一结束角色生龙活虎（代价要滞后显现才真）
- 禁环境毫发无伤（大战该留痕）
- 禁死人毫无重量（一个配角死了要有人的反应）

## `novel-how-duel-brawl` · 拳脚近身 · 力量型


# 拳脚近身 · 力量型

## 适用场景
- [角色A]是力量型：巨斧、重锤、体术、肉身硬抗
- 想写出"每一次命中都地动山摇"的压迫感

## 核心技法
1. **动作幅度即力量**：跨步、拧腰、抡圆、砸落——大开大合，不用精巧小动作。
2. **环境破坏当反馈**：地面龟裂、石柱震碎、尘土炸开——打人也要打景，景坏=力大。
3. **呼吸与负荷**：力量型不轻松，写喘、写肌肉绷紧、写落地时膝盖陷进土里。
4. **近身的脏与痛**：拳头砸在肉上的闷响、鼻梁塌陷、牙齿飞溅——近身战要写"触感"。

## 模板清单
- 起手：[角色A]跨步拧腰，巨斧抡圆劈下，风声先到
- 破坏：斧刃嵌进地面，蛛网裂痕炸开三丈，[角色B]被气浪掀退
- 近身：一拳砸在[角色B]小臂，骨裂闷响，对方整条胳膊垂了下去
- 负荷：[角色A]落地时双膝陷进泥里半寸，喉间滚出粗喘

## 红线
- 禁力量型无喘息（全程爆发=读者无紧张感）
- 禁只写"轰的一声"不写具体破坏（破坏要可观察）
- 禁力量型角色免疫痛觉（挨打没反应=不可信）

## `novel-how-duel-break` · 兵器损毁 · 临场换械


# 兵器损毁 · 临场换械

## 适用场景
- [角色A]的武器在战斗中被打断/震飞/夺走
- 想写"失去倚仗后反而更狠"的逆转，或空手入白刃的压迫

## 核心技法
1. **损毁要有过程**：不是突然断，是先前出现裂纹、卷刃、嗡鸣——给读者预感。
2. **失控瞬间最真**：兵器脱手的惊愕、虎口空了的错愕，半秒空白后才是应变。
3. **捡械/空手即人物**：顺手夺[角色B]的副武器、抄起断木、用身体撞——换械方式见性格。
4. **空手更脏更近**：没了距离，拳肘膝撞、咬、撞、抱摔，把战斗拉进最原始的层。

## 模板清单
- 预感：长刀与重斧交击的第三下，刀脊绽开一道细裂，嗡鸣变了调
- 断裂：第四下，刀身从中折断，半截铁刃旋转着嵌进泥里
- 空白：[角色A]虎口一空，愣了半息——只半息
- 应变：他顺势扑上，左手扣住[角色B]手腕夺斧，右膝顶向其肋下

## 红线
- 禁武器说断就断无铺垫（前文没裂纹=读者出戏）
- 禁断械后立刻掏出更强备用武器（削弱牺牲感）
- 禁空手战写得太干净（近身该有血、有咬、有脏）

## `novel-how-duel-clash` · 兵器对撞 · 镜头化写法


# 兵器对撞 · 镜头化写法

## 适用场景
- 冷兵器对决的"交击瞬间"——刀剑、长枪、钝器、鞭锏相碰
- 想写出"金属撞击的质感"与"力量博弈的张力"，而非干巴巴"叮当一声"

## 核心技法
1. **三感联动定质感**：听觉（金铁交鸣/刺耳锐响）+ 视觉（火花/崩溅的火星烫手）+ 触觉（虎口震麻/兵器传来的反震）。一次交击至少落两个感官。
2. **用兵器反应反推人**：刀身弯了、剑脊龙纹崩裂、长刀被震断——兵器是身体的延伸，损毁即代价。
3. **交击即博弈**：每一次碰撞都要推进"谁占上风"，不要为响而响。震退半步、虎口发麻、兵器出现裂纹，都是力量对比的读数。
4. **慢镜头放大高光**：旁人眼中只是一瞬，在[角色A]瞳孔里刀锋轨迹凝结成血色弧线——主观时间拉伸。

## 模板清单
- 出招：[角色A]横刀格挡，刀脊撞上[角色B]的剑刃
- 质感：叮一声锐响，火星烫在虎口，血珠顺着纹路渗进铁锈
- 博弈：这一撞[角色A]被震退半步，虎口发麻——[角色B]力道更沉
- 代价：长刀出现细裂纹，再撞一次就会断

## 红线
- 禁堆砌招式名不写后果（"力劈华山"后没反应=空响）
- 禁上帝视角同时写双方内心（限知视角只写[角色A]感知）
- 禁每击都"火花四溅"审美疲劳，交替用闷响/震退/裂纹/脱手

## `novel-how-duel-elegance` · 武戏文唱 · 留白美感


# 武戏文唱 · 留白美感

## 适用场景
- 高手过招不靠狂轰滥炸，靠意境、韵律、留白
- 想写出"武打如绝句"的视觉美与节奏感，而非动作堆砌

## 核心技法
1. **意境大于形式**：少写具体招式名，多写"如孤峰峭拔""如远山清峻"的气韵。
2. **以静写动**：高手对峙时写风、写衣角、写呼吸，暴起只在电光一瞬。
3. **招式如诗起承转合**：一场对打如绝句，四五个回合写得有起势收势，节奏即美。
4. **留白给想象**：不写尽每一击，写"剑光一闪，檐角铜铃无风自落"——读者自己补。

## 模板清单
- 气韵：[角色A]长剑贴胸挺身而立，如孤峰峭拔，冷傲凌人
- 静：两人对峙，风过衣角，谁都没动，铜铃却无端响了一声
- 动：下一瞬剑光一闪，檐角铜铃无风自落，[角色B]的发带断在半空
- 收：剑已归鞘，[角色B]颈侧多一道红线，血珠慢慢渗出

## 红线
- 禁通篇形容词无动作（"大气磅礴"不落地=空）
- 禁留白变含糊（读者补得出=留白，补不出=没写）
- 禁意境流全程无代价（美感也要有伤、有险）

## `novel-how-duel-hidden` · 暗器远程 · 速度型


# 暗器远程 · 速度型

## 适用场景
- [角色A]是刺客/射手/操控系，靠速度、距离、暗器、瞬移取胜
- 想写"看不见人影就已中招"的压迫，或远程火力压制

## 核心技法
1. **先到效果后到人**：暗器破空声先响，[角色B]反应时已经中招——速度感来自"结果早于理解"。
2. **连击的"数学感"**：三连、五连、扇形覆盖——暗器不是一发，是网。
3. **空间切换诡谲**：瞬移/位移写"出现位置的违和"——上一帧在左，下一帧贴脸。
4. **远程的"看不见的线"**：操控系写能量丝、术式锁链、视线标记，让读者感到被锁定。

## 模板清单
- 先声：[角色A]的袖中先飞出一点寒光，[角色B]低头时第二枚已到喉前
- 连击：三枚钱镖成品字封死退路，第四枚从脚下射穿靴底
- 切换：残影还在原地，真身已贴到[角色B]背后，刀刃比体温先到
- 锁定：[角色B]发现周身浮起八道术式，退一步便多一道缠上脚踝

## 红线
- 禁"瞬间移动无代价"（瞬移需冷却/落地破绽/轨迹暴露）
- 禁远程角色零风险（暗器也会被格挡、被近身反杀）
- 禁速度描写只剩"嗖的一声"（要给落点、要给命中反馈）

## `novel-how-duel-move` · 招式拆解 · 写实法


# 招式拆解 · 写实法

## 适用场景
- 想展示[角色A]的具体武学/术式，而非"他打了一拳"带过
- 写实派打斗：招式名 + 动作描写 + 拆招反应

## 核心技法
1. **招式名要有"形"**：名字本身暗示动作（拔草寻蛇/野马分鬃/玉带缠腰），读者脑中自动生成画面。
2. **动作词精准**：劈、砍、刺、跃、扑、撩、格、挑——用动词替代形容词。
3. **起承转合如绝句**：一场对打四五个回合，写足起势→进身→交击→变招→收势的节奏。
4. **拆解而非罗列**：每一式都要有[角色B]的拆招/闪避/反击，双方向前推，不是单方面表演。

## 模板清单
- 起势：[角色A]亮了个"举火烧天"的架式
- 进身：[角色B]踏中宫走洪门，剑到人到，掐剑诀"拔草寻蛇"斩下盘
- 拆招：[角色A]倏地闪开，剑走轻展"白蛇吐信"刺小腹
- 变招：叮当一声，剑刃碰剑刃，激起火花

## 红线
- 禁招式名堆砌成目录（连发五招名无动作=流水账）
- 禁"无招胜有招"式偷懒（想偷懒就用虚实结合法替代）
- 禁招式与人物性格脱节（沉稳者不该用花哨浮夸招）

## `novel-how-duel-spell` · 法术对决 · 能量型


# 法术对决 · 能量型

## 适用场景
- [角色A]与[角色B]以术式/法术/[某能量体系]/灵力对抗
- 想写出"能量碰撞的奇观"与"施法的前摇后摇"

## 核心技法
1. **施法有前摇**：结印、吟唱、蓄力——给读者"他要放大招了"的期待。前摇越长，爆发越爽。
2. **能量可视化**：雷火炸开映青紫、电弧缠刃烧红刀身、冰霜蔓延冻住地面——用颜色与动态写能量。
3. **咒语/术式名当节奏器**：念到第几句、结到第几个印，控制紧张感。
4. **碰撞=规则对抗**：不是谁数值高谁赢，是属性相克、术式博弈（火遇风更猛、水克火）。

## 模板清单
- 前摇：[角色A]双手翻飞结印，舌尖尝到铁锈味，空气开始发烫
- 蓄力：雷火在掌心炸开，整座山谷映成青紫色，电弧如活蛇缠上敌刃
- 释放：他推出那一掌，雷火化作怒龙撞向[角色B]的水墙
- 碰撞：水遇雷炸成白雾，[角色B]被反震退三步，袖口焦黑

## 红线
- 禁"念个名就赢了"（无前摇无博弈=廉价）
- 禁能量描写全靠"耀眼的光芒"（要给颜色/温度/声音/气味）
- 禁属性相克前后不一（前文水克火，后文火随意烧水=设定崩）

## `novel-how-duel-sword` · 技巧型对决 · 风格差异化


# 技巧型对决 · 风格差异化

## 适用场景
- [角色A]是敏捷/技巧型，靠速度、破绽捕捉、节奏变化取胜
- 想让不同角色的打法一眼区分（力量型 vs 技巧型 vs 法术型）

## 核心技法
1. **剑气/术式轨迹可视化**：写清攻击的"线"——弧线、直线、螺旋，让读者看见轨迹。
2. **破绽捕捉大于硬碰**：技巧型不拼力量，抓[角色B]换招的空档、旧力已尽新力未生的一瞬。
3. **节奏变奏**：忽快忽慢，残影欺身是快，凝滞蓄势是慢，快慢交替打乱对手预判。
4. **兵器碰撞的"声音性格"**：剑客用清脆铮鸣，重刀用沉闷钝响，声音即人设。

## 模板清单
- 轨迹：[角色A]剑尖划出半弧，擦着[角色B]肋下掠过，带起一缕被切断的发丝
- 破绽：就在[角色B]旧招用老、新招未起的半拍，[角色A]的剑已抵上咽喉
- 变奏：前一瞬残影还在一丈外，下一瞬剑锋已贴颈——他根本没给反应时间
- 声音：铮一声轻响，像冰裂，[角色B]的护腕应声落地

## 红线
- 禁"快到看不清"当万能描写（要看清才有爽感，用残影/轨迹替代模糊）
- 禁技巧型角色无代价取胜（破绽捕捉也需时机与风险）
- 禁所有技巧型写得雷同（每人要有标志性动作/武器音色）

## `novel-how-duel-underdog` · 以弱胜强 · 借力打力


# 以弱胜强 · 借力打力

## 适用场景
- [角色A]战力、体型、兵力均劣于[角色B]
- 想写"不硬刚、用巧劲和脑子赢"，而非突然爆种

## 核心技法
1. **明确劣势，再破它**：先让读者知道[角色A]差在哪（力气小/等级低/没武器），巧胜才有分量。
2. **借力三法**：借[角色B]的力（格挡引导其撞墙）、借地形（引到窄处限其发挥）、借环境（绊索/落石/水）。
3. **小伤换大破**：以局部受伤换对手破绽，伤要有代价感，不是无血通关。
4. **胜利要"险"**：赢在毫厘——差半寸被斩、最后一口气压制，险胜比碾压更爽。

## 模板清单
- 劣势：[角色A]的臂力不到[角色B]一半，硬拼必碎
- 借力：[角色A]不挡，侧身让斧劈空，顺势推[角色B]肘部，那斧狠狠剁进自己脚边的岩壁
- 地形：斧卡住的半秒，[角色A]滚到石后，[角色B]追来时被暗藏的绊索绊倒
- 险胜：[角色A]趁其扑地，断刃抵住其后颈——差一寸就被反手掐死

## 红线
- 禁"弱者无伤赢"（巧胜也该带伤，否则不真实）
- 禁靠外挂瞬间翻盘（翻盘要可解释、可复现）
- 禁把[角色B]写傻来衬[角色A]（强敌变蠢=降智）

## `novel-how-fight-beat` · 战斗节拍（起承转合）


# 战斗节拍（起承转合）

## 适用场景
- 任何独立战斗场面，需要内部节奏清晰
- 防止"上来就打、打到最后不知道为什么停"

## 核心技法
1. **起势（铺垫张力）**：双方站位、兵器出鞘、气场对峙。用环境静默（寒鸦嘶鸣、铜铃轻响）把弦绷紧再动手。
2. **交锋（试探与反制）**：招式碰撞、互相试探，制造"谁更强"的悬念。可插入失传招式等小惊喜。
3. **转折（意外变故）**：暗器、援军、功法反噬、身份揭露等打破平衡。这是爽点爆发点。
4. **收势（定格余韵）**：胜负已分用一个画面收尾（断剑插雪地、胜者踩碎败者影子），不啰嗦解释。
5. **喘息缝**：在强节拍之间留"慢节奏"——刀卡树桩时注意到三年前旧痕，用环境/回忆给读者喘气。

## 模板清单
- 起势：环境 + 对峙（约 200 字）
- 交锋：2–3 回合递进（约 500 字）
- 转折：意外变量（约 200 字）
- 收势：定格 + 一句余韵（约 150 字）

## 红线
- 忌只有交锋没有起势，读者没进入状态就开打。
- 忌转折太弱（"他突然变强了"无依据）。
- 忌收势啰嗦复盘，画面定格胜过旁白总结。

## `novel-how-fight-camera` · 战斗镜头与节奏（影视化运镜）


# 战斗镜头与节奏（影视化运镜）

## 适用场景
- 任何需要"读者脑中能放电影"的打斗场面
- 想控制张弛、避免全程高强度导致疲劳

## 核心技法
1. **镜头三景切换**：
   - 近景特写：兵器纹路、肌肉颤动、虎口血珠（放大细节）
   - 中景：招式轨迹、双方位移
   - 远景扫视：战场全局、十万黑甲漫过丘陵（压迫感）
   - 上一段远景摧山裂石，下一段切近景人物眼中剑光，交替使用。
2. **慢动作拆解高光**：把决定性瞬间拉长——刀刃切空气声成蜂鸣，旁人眼中他只挥一次刀，但在主角瞳孔里轨迹凝结成血色弧线。
3. **快慢交替**：高潮用密集短句连招（"剑光如瀑！三招、五招、十招！"）；衔接处插入喘息、环境、回忆慢下来。
4. **感官联动**：听觉（金属锐响/骨裂闷响）、视觉（光影变化/血溅轨迹）、触觉嗅觉（血腥味/兵器冰凉）一起上。
5. **空间定位**：用参照物（古槐、石桥、铜鼎）和方位词（左劈、右旋、后跃）串起动作轨迹，防混乱。

## 模板清单
- 起势：远景交代战场 + 近景对峙（约 200 字）
- 爆发：快节奏短句连招（约 400 字）
- 高光：慢动作特写拆解（约 200 字）
- 喘息：中景 + 环境/心理慢板（约 200 字）
- 收势：远景定格（约 100 字）

## 红线
- 忌持续高强度无喘息，读者会疲劳。
- 忌无空间参照导致"打成一团雾"。
- 忌只写视觉忽略其他感官。

## `novel-how-fight-chase` · 追击逃亡


# 追击逃亡

## 适用场景
- 逃命、追捕、千里奔袭、城市/山林追逐戏
- 读者预期：喘不过气的紧迫感与"会不会被追上"的悬念

## 核心技法
1. **地形即节奏**：用空间切换制造快慢——开阔地（暴露、加速）→ 窄巷（转弯、惊险擦过）→ 死路（绝境心跳）。地形推动紧张曲线。
2. **身体信号外化恐惧**：呼吸灼烧、小腿灌铅、耳膜轰鸣，用生理反应替代"他很害怕"的形容词。
3. **后方威胁具象化**：追兵不必全程露脸，用"脚步声逼近/箭矢钉在脚边/引擎轰鸣由远及近"让威胁可感。
4. **意外助攻/绊脚**：逃亡中插入可变因素（路人挡路、旧伤发作、天气突变），避免一路平跑。
5. **喘息不松懈**：短暂停顿（躲进暗处屏息）后立刻被嗅到，制造"刚松口气又被掐住"的循环。

## 模板清单
- 起逃：触发追击的事件 + 主角第一反应（约 200 字）
- 追逐：3 个地形段落，每段"加速/惊险/险被抓"（约 700 字）
- 转折：意外变量 + 绝处逢生或反设局（约 300 字）
- 脱险：短暂安全 + 埋下"对方不会罢休"的钩子（约 150 字）

## 红线
- 忌全程"他拼命跑"无空间变化，必须用地形制造节奏。
- 忌追兵无存在感（用声音/痕迹/后果让它一直在场）。
- 忌逃脱后彻底安全，要留"被盯上"的余震。

## `novel-how-fight-cornered` · 绝境反杀


# 绝境反杀

## 适用场景
- 主角寡不敌众、重伤濒死、被逼入死角后的逆转
- 读者预期：手心出汗的"他怎么活下来"，而非轻松翻盘

## 核心技法
1. **先压到谷底**：反杀的爽感 = 绝境的真实度。让主角真受伤、真无力、真被逼到墙角，读者才相信后续逆袭。
2. **藏一手伏笔**：逆转的资本必须是前文铺垫过的（某道具/某功法隐患/某伤疤对应的弱点），不能凭空开挂。
3. **极限专注态**：绝境中主角感知会"慢下来"——用慢动作拆解高光瞬间（刀锋轨迹凝结成弧线），放大冲击力。
4. **借势不硬刚**：反杀常靠"借敌人之力/环境之利"（诱敌撞柱、借爆炸掩护、用对方轻视做陷阱），而非纯数值碾压。
5. **代价感**：反杀后要留伤、留后遗症、留心理阴影，胜利才有重量。

## 模板清单
- 谷底段：主角被围/重伤/退路断绝（约 300 字）
- 觉醒段：回忆/伏笔闪回 + 抓住唯一破绽（约 300 字）
- 逆转段：慢动作高光 + 借势反杀（约 500 字）
- 余痛段：惨胜代价 + 一句冷硬收束（约 150 字）

## 红线
- 忌"说好听自己牛"——反杀靠动作和伏笔，不靠旁白吹。
- 忌零代价获胜，绝境反杀后必须留伤或留心理阴影。
- 忌逆转资本前无铺垫（"突然想起师父教的"必须前文教过）。

## `novel-how-fight-environment` · 环境与战斗（环境即武器）


# 环境与战斗（环境即武器）

## 适用场景
- 战斗发生在有特色的空间（森林、雪原、废墟、船上、密室）
- 想用环境侧面写破坏力、制造战术机会

## 核心技法
1. **破坏力外化**：不必写"他很猛"，写"拳风擦过石柱震出蛛网裂痕""巨锤砸城墙砖石混火星飞溅"——破坏即实力。
2. **环境当战术点**：主角借古槐跃起踢落槐叶绞碎剑气；断箭残留体温混合腐叶血腥味——细节让空间真实。
3. **功法呼应环境**：冰系出招方圆十丈冻结成冰雕，连血滴凝成红晶；火系出招整谷映成青紫。世界观设定通过环境特效落地。
4. **意外道具成关键**：被打飞的酒坛泼进火盆腾起火光，照亮对手袖口刺青——环境细节推动剧情。
5. **天气造氛围**：开篇写天气压抑借景造气氛，雨/雪/雾都能压低能见度制造偷袭机会。

## 模板清单
- 入场：用 1–2 句点明环境特征与可借力的物体
- 交战：每 2 个动作插入 1 处环境反馈（破坏/利用）
- 转折：环境意外成为破局钥匙（光照/陷阱/掩体）
- 收尾：战后环境定格（雪地黑坑/断桥余烟）

## 红线
- 忌环境只是背景板，必须参与战局。
- 忌破坏力与等级不符（下忍一拳轰平山头需有设定支撑）。
- 忌光线/天气突然变来服务剧情而无铺垫。

## `novel-how-fight-group` · 群战调度（多线分战场）


# 群战调度（多线分战场）

## 适用场景
- 大型决战、攻城战、帮派群殴、多人围杀主角等混乱大场面
- 读者预期：看懂谁在哪打、局势如何倾斜

## 核心技法
1. **单视角锚定**：群战最容易"上帝视角混乱"。锁定一个视角角色（通常是主角），用他的余光/听觉感知局部，绝不同时写甲看见乙偷袭丙、丙又躲丁——读者会迷路。
2. **分战场开辟**：最终决战可切 2–3 条分战场（主角线/队友线/敌方大将线），每条线各自有"小高潮"，最后汇流。全挤一起会写乱。
3. **敌人差异化**：给杂兵贴可辨识标签（使剑的两个、使斧的一个、远处弓手），读者脑中才有画面；否则"一群黑衣人"等于没有敌人。
4. **环境当角色**：把地形画成地图——巨石、溪流、断桥都是可利用的战术点，主角借环境以少胜多才 believable。
5. **节拍汇总**：群战也要有"总攻号角→胶着→转折点（某关键人物倒下/援军到）→溃败或反推"的宏观节奏。

## 模板清单
- 战前：双方阵容 + 地形锚点（约 200 字）
- 主视角战斗：聚焦 1vN，借环境突围（约 600 字）
- 分战场切片：2 条友方/敌方线各 150 字，用"与此同时"衔接
- 汇流：关键转折 + 局势定调（约 200 字）

## 红线
- 忌全知乱切，必须有一个稳定视角锚。
- 忌杂兵无辨识度（"数十名敌人"必须至少给 2–3 个具体特征）。
- 忌只有"打"没有"势"，群战要写出兵力天平的倾斜方向。

## `novel-how-fight-pit` · 战斗描写避坑（五大雷区）


# 战斗描写避坑（五大雷区）

## 适用场景
- 自检已写的战斗段落
- 新手最常犯的"写了等于没写"问题排查

## 核心技法（对应五坑）
1. **数据堆砌**：❌"攻击力+1000 暴击30% 造成2000伤害"；✅写炎龙虚影冲出岩壁剥落、盾牌符文炸裂如流星雨。用画面替代面板。
2. **上帝视角混乱**：❌甲看见乙偷袭丙、丙躲丁、丁被戊击中……；✅锁定单一视角，穿插"余光里黑衣人毒针擦耳飞过"。
3. **招式名堆砌**：❌连使"亢龙有悔/神龙摆尾/降龙十八掌"无画面；✅掌风未至地面裂龙纹，喊招时气浪卷落叶逼对手单膝跪地。
4. **只写动作无后果**：战斗要有破坏力反馈、旁观者反应、主角代价，否则像打空气。
5. **节奏一成不变**：全程高密度连招读者会麻木，必须快慢交替+喘息缝。

## 模板清单（自检五问）
- 这段能脑中放电影吗？（清晰度）
- 有快慢节奏吗？（节奏感）
- 视角乱吗？（观察距离）
- 招式有画面吗？（非纯名词）
- 打完留了什么？（代价/后果/变化）

## 红线
- 以上五坑任中一项，战斗即失败。
- 忌用游戏数值代替文字张力。
- 忌多线全知混战无锚点。

## `novel-how-fight-scenes` · 打斗怎么写（画面感 / 镜头）


# 打斗怎么写（画面感 / 镜头）

## 适用场景
- 近身肉搏、刀剑格斗、拳脚相向的战斗段落。
- 想把"他出一拳，对方躲过，反手一刀"这种流水账写出临场感与燃点。
- 任何需要"读者脑中自动播放画面"的动作戏。

## 核心技法
- **分镜思维**：把混战拆成镜头切换，一句一画面、一句一动作。多用句号当剪辑点——短句自带紧迫感，强制拉快读者阅读速度。
  - 远景定调（气氛）→ 中景交手（过招）→ 近景特写（火星、滴血、瞳孔）。
- **打击感公式**：受力点 + 声音特写 + 身体反馈。不写"他给了对手一拳"，写"这一拳砸在胃部，发出闷响，对手弯折成 V 型，双脚离地向后滑了半米"。
- **五感联动**：听觉（骨裂脆响、兵器入肉的闷涩声）、触觉（虎口震麻、汗刺眼）、嗅觉（血腥、硝烟、铁锈）、空间感（距离/方位）。拟声词让战斗立体。
- **节奏呼吸法**：打戏是"动词爆发"与"名词喘息"交替。激烈交锋用密集短动词，对峙/策略调整时插名词与感官（汗滴、喘息、刀尖微颤）。
- **战斗即博弈**：让动作承载"为什么这么打"——发现对方左腿有伤故意引诱移动、假装破绽、利用环境。读者看到主角用脑子才"爽"。
- **微表情点到即止**：不写"眼神充满杀意"，写"眼睛眯成一条缝"。犹豫、皱眉、愣神一瞬，传递心理波动。
- **定格收尾**：战斗结束用静止画面定调——剑尖滴血、两人影子交叠、周围声音消失只剩喘息，制造仪式感与余韵。

## 可直接套用模板 / 清单
- **镜头模板**：【特写】X 动作 →【快切】Y 动作 →【中景】Z 反应 →【音效】拟声 →【慢镜】高光瞬间。
- **打击感模板**：[动作]砸在[受力部位]。([声音特写]) [对方身体反馈：姿态/位移/生理反应]。
- **节奏自检清单**：
  - 是否一句一画面、短句推进？
  - 受力点、声音、身体反馈三者是否齐全？
  - 是否调动了 ≥2 种非视觉感官？
  - 高潮前是否有"博弈/算计"而非纯对轰？
  - 结尾是否有定格画面？
- **避坑**：避免"回合制流水账"（A出拳→B格挡→B踢腿→A闪避）；避免违反人体工学的动作拼接；避免全程只有动作没有性格（谨慎型角色会下意识检查武器损耗）。

## 红线
- 用通用措辞，不照搬专属设定 / IP。

## `novel-how-fight-showoff` · 装逼打脸单挑（爽文核心套路）


# 装逼打脸单挑（爽文核心套路）

## 适用场景
- 男频玄幻/都市异能等需要"主角很牛"被直观展示的战斗
- 读者预期：看对手怎么被反衬成笑话

## 核心技法
1. **反差铺垫**：对手无比重视（养精蓄锐、吃药、提前布防），主角轻描淡写（照旧喝茶/吐槽）。重视度反差越大，打脸越响。
2. **语言交锋前置**：对方出言挑衅热血，主角照旧淡定，语言上的"不接招"先立住逼格。
3. **慢镜头吹牛再秒杀**：起手式力量来源、功法牛逼之处先铺，吹完这一拳才刚打出，对面如何自信迎接、如何"我挡！啊竟挡不住"心理崩塌，最后被秒。
4. **路人惊叹收尾**："此子恐怖如斯"类旁观反应，把主角之强从第三方嘴说出，比自夸可信。
5. **观战方写法**：若主角是旁观者，则路人不相帮时淡定喝茶，直到有人砸飞撞向主角才轻描淡写推开——"你是要管爷爷的闲事？"

## 模板清单
- 铺垫：对手重视 + 主角轻描淡写（约 300 字）
- 语言：挑衅 vs 淡定（约 200 字）
- 开打：吹牛→出招→对方自信→崩塌秒杀（约 500 字）
- 反应：路人惊叹/对手怀疑人生（约 150 字）

## 红线
- 忌主角前期也慌，装逼流的"稳"是核心人设。
- 忌秒杀无铺垫显得作者偷懒，必须先把对手垫高。
- 忌全程只有主角爽无代价，长期需有"惜败显格"的对照局。

## `novel-how-fight-solo` · 单挑对决（1v1 公平对决）


# 单挑对决（1v1 公平对决）

## 适用场景
- 擂台赛、约战、生死决斗、门派比武等双方正面硬刚的场面
- 读者预期：看两个人"各显神通"，而非一方碾压

## 核心技法
1. **站位即气场**：开场用"起势"建立对峙——双方站位、兵器出鞘、环境静默（寒鸦嘶鸣/风停），把张力拉满再动手。
2. **回合感≠回合制**：用"试探→交锋→变招→压制→反转"的节拍推进，每一回合都要有"这一下比上一下更狠"的递进，避免重复挥砍。
3. **招式即性格**：暴躁者招式刚猛带怒吼；冷静者极少多余动作、直取旧伤/破绽。招式选择暴露人格。
4. **旁观者反差**：用围观者的"以为谁赢"衬托真实走向，制造打脸前的认知落差是 solo 的爽点放大器。
5. **收势定格**：胜负已分后用一个余韵画面收尾（断剑插雪地/胜者踩碎败者影子），不啰嗦。

## 模板清单
- 起势段：天气/氛围 + 双方登场 + 气场对峙（约 300 字）
- 交锋段：3–5 个递进回合，每回合"动作+感官+对方反应"（约 800 字）
- 转折段：暗器/援军/功法反噬等意外（约 200 字）
- 收势段：定格画面 + 一句话余韵（约 150 字）

## 红线
- 忌"数据堆砌"（攻击力+1000 造成 2000 伤害），用画面替代面板。
- 忌"招式名堆砌"无画面支撑，招式名必须与动作绑定。
- 忌双方一直平手没事发生，solo 必须有明确的"谁在上风"的位移感。

## `novel-how-fight-style` · 战斗风格差异化（性格外化）


# 战斗风格差异化（性格外化）

## 适用场景
- 多个角色各自出战，需要读者"看打法就知道是谁"
- 想用战斗暴露人格，而非用旁白介绍性格

## 核心技法
1. **力量型**：巨斧劈砍、震地猛击，重点写动作幅度、爆发力、环境破坏，可带怒吼与破坏欲。
2. **敏捷型**：瞬移突袭、暗器连击，重点写速度感、残影、空间切换。
3. **法术型**：符文吟唱、元素操控，重点写能量特效、咒语韵律、阵法构建。
4. **技巧型**：剑气轨迹、破绽捕捉，重点写兵器碰撞细节、节奏变奏、以巧破力。
5. **冷静型**：极少多余动作，直取对方虎口旧伤，剑落时甚至不看眼睛——"人狠话不多"靠动作立住。
6. **暴躁型**：招式刚猛直接，边打边骂，破坏欲外化人格。

## 模板清单
- 出场：用第一个动作定调风格（例：他没拔剑，只是把刀插进地面掀起石板）
- 中段：3 个风格化招式，每个呼应性格标签
- 收尾：胜利方式也符合性格（冷静者收剑入鞘，暴躁者踩碎对方兵器）

## 红线
- 忌所有角色打法雷同（"他又是一剑"用遍全场）。
- 忌用旁白说"他很冷静"，必须用打法证明。
- 忌风格与设定矛盾（体修使出繁复剑阵需有解释）。

## `novel-how-gunfight` · 枪战怎么写


# 枪战怎么写

## 适用场景
- 现代/近未来题材的枪战场面：警匪、特战、生存、末日。
- 室内近距离战斗（CQB）、街头交火、狙击对决。
- 想把"他开枪了，敌人倒了"简笔画升级为有压迫感的实战描写。

## 核心技法
- **环境先立**：交代地点、地形、能见度。环境细节让读者融入紧张气氛。
- **动态镜头 + 生理反馈**：每 3 句高强度战斗内至少插 1 次角色的生理或心理反馈，避免审美疲劳。例："枪口焰照亮回廊尽头那张惨白的脸，后坐力撞肩窝的钝痛还没传到大脑，手指已本能扣下第二发"。
- **专业性适度**：枪支使用、战术动作要准确（上膛、换弹、据枪、掩体、火力交叉），但不写成弹道测试报告。写"人的反应"而非参数。
- **拟声与措辞**：开枪用拟声词；历史/武侠风忌用违和外来语，现代题材可用战术术语但点到即止。
- **角色心理**：有人恐惧有人冷静，刻画参战者情绪状态，让读者理解内心世界。
- **镜头由大到小**：先远景交代全局 → 再缩小到两人同框概括激烈 → 最后特写拔枪/瞄准细节。
- **节奏掌控**：紧凑有力，交替对抗与合作，用段落长短控制快慢。

## 可直接套用模板 / 清单
- **CQB 交火模板**：[环境/掩体/能见度] → [枪口焰 + 后坐力生理反馈] → [对方暴露/中弹反应] → [战术动作：换弹/转移/火力压制] → [一句话喘息/心理] 。
- **对枪模板**：[远景交代双方站位] → [中景射击与躲避] → [特写：某一方拔枪/上膛/瞄准细节] → [命中或落空反馈] → [余波]。
- **枪战自检清单**：
  - 环境/地形/能见度是否先立？
  - 是否每 3 句插了生理/心理反馈？
  - 枪支动作是否准确但不堆参数？
  - 是否用了拟声词与合适措辞？
  - 镜头是否由大到小推进？
- **避坑**：不写"他开枪了敌人倒了"简笔画；不写弹道报告式数据；不频繁跳上帝视角。

## 红线
- 用通用措辞，不照搬专属设定 / IP 或真实武器型号炫技。

## `novel-how-melee-battle` · 群战 / 混战怎么写


# 群战 / 混战怎么写

## 适用场景
- 多人 vs 多人：团战、帮派火并、战场混斗、围攻。
- 几十人至上万人的大乱斗，容易写得像一锅乱粥。
- 想写出群像、层次与悲壮感。

## 核心技法
- **分镜头控节奏，主次分明**：① 先定大环境基调；② 写主线核心交锋立"主心骨"（两个核心人物单挑）；③ 再写支线推进群像；④ 多线汇合造高潮。让读者清晰看到每个人在做什么。
- **主视角 + 多线切换三原则**：
  1. 切换必须有"触发点"（主角看到队友遇险→切队友视角），无触发即跳戏。
  2. 主角为主、他人为辅：群像中主角视角占主体，配角戏份为衬托主角存在。
  3. 旁观者视角是"爽点加速器"：主角精彩操作后切旁观者震惊捧哏，一句话即可。
- **群战核心**：不是"一个人怎么赢"，而是"一群人怎么死光"，越悲壮越热血。
- **群战铁律**：正规军必须先死（逻辑通顺）；普通人不给名字只给动作与物件（读者通过前置伏笔认人）；死亡节奏加速（前慢后快如多米诺）；收尾不煽情，只陈述遗物，越克制越悲壮。
- **侧面迂回**：若无法面面俱到写惨状，从侧面烘托（远处飞鸟惊走、血流成河、血雾黑烟）。
- **张弛有度**：一章之内设置一张一弛，烈血之后接柔情，避免读者麻木。

## 可直接套用模板 / 清单
- **混战模板**：[大环境定调] → [主线核心交锋立骨] → [支线群像推进，触发点切换] → [多线汇合高潮] → [收尾：悲壮/克制陈述]。
- **团战模板**：[局势建立：一句话环境+敌我位置] → [危机爆发+主角首次出手解围] → [多线切换穿插，每配角≤150字且关联主角] → [高潮：主角底牌+旁观者捧哏] → [收尾悬念]。
- **自检清单**：
  - 是否有"主心骨"单挑线避免散乱？
  - 视角切换是否都有触发点？主角是否 ≥60%？
  - 旁观者是否一句话捧哏？
  - 若悲壮：正规军先死？普通人无名字？死亡加速？主角被"按住"？收尾克制？
  - 是否有张弛（非全程高强度）？
- **避坑**：别写上帝视角多角色混战（甲看乙偷袭丙…读者迷路）；聚焦单一视角穿插关键信息；别通篇血红违禁。

## 红线
- 用通用措辞，不照搬专属设定 / IP 的阵营与战法名词。

## `novel-how-strategy` · 权谋/谋略怎么写


# 权谋/谋略怎么写

## 适用场景
- 朝堂党争、宫廷权斗、世家博弈、多方势力拉扯
- 主角用脑子而非武力破局，核心是"斗心眼"
- 需要设计有层次的利益网、动机网、因果链
- 写反派/对手棋逢对手、不降智

## 核心技法
- **三层利益网**：每个权谋角色活在三层嵌套的利益里——表层（公开宣称：家族荣耀、国家大义）、中层（实际追求：权力巩固、派系扩张）、底层（绝不示人：童年创伤、隐秘执念）。表层中层可随剧情调整，底层永不动摇。张力来自角色如何一边维护底层目标、一边灵活改写上层说辞。
- **规则漏洞利用**：顶级权谋不是犯规，而是发现并利用规则的隐藏漏洞——文字漏洞、程序漏洞、认知漏洞。破局点落在"所有人看得见却无人深思的规则细节"上。
- **信息差为王**：权谋的本质是谁掌握别人不知道的信息。让读者比角色多知一点（制造悬疑）或比主角少知一点（制造意外），两种手法交替使用。
- **立场而非善恶**：赢家不是最聪明，是最懂隐忍、最懂人性、最留后手的人。反派要有政治理想与苦衷，是棋逢对手而非单方面被虐。人人有软肋，抓住软肋才能拿捏人。
- **因果链**：平庸权谋走一步看一步，高明权谋走一步看三步并留好陷阱。每个动作引发多个连锁反应。写作前列出每个角色的目标、底牌、弱点，设计波及所有角色的核心事件。
- **延迟引爆**：前期给一个看似微小的承诺→中期被所有人遗忘→高潮时以颠覆局势的方式兑现。
- **守规再破规**：先符合朝堂规矩/礼法祖制，再在规则里钻空子，比强行开挂高级。
- **侧面暗示**：不写"他要算计谁"，用对话、眼神、送礼、调官、流言侧面铺垫，让读者自己品。

## 可直接套用模板/清单
- **人物三幕动机卡**：①对外宣称动机 / ②身边人知道却未说出口的动机 / ③连自己都不愿承认的动机。三层写满，人物立住。
- **权谋情节万能结构**：起因（皇权空虚/利益冲突/旧怨伏笔）→布局（安插眼线、制造假象、拉拢中立、埋下后手）→交锋（借刀杀人、栽赃、釜底抽薪、舆论造势、以退为进）→反转（卧底反水、假消息中计、废棋握关键证据、反派早已入连环局、上位者全程控局）→收局（温和制衡 / 斩草除根 / 两败俱伤）。
- **反派不降智清单**：有野心、有苦衷、有过人本事；与主角互为镜像而非纸片；每次失败都让局势更难而非更蠢。
- **信息差检查**：本章读者比谁多知道？比谁少知道？两种视角交替，避免全透明。

## 红线
- 用通用措辞，不照搬专属设定 / IP（具体桥段仅作原理示例，不得照抄人物与剧情）。
- 避免"万能主角"陷阱：主角可聪明但必须经历失败、付出代价。
- 权谋手段避免单一化，千层布局考验耐心、手段、格局。

## `novel-how-tournament-duel` · 擂台 / 比武怎么写


# 擂台 / 比武怎么写

## 适用场景
- 擂台赛、门派大比、比武招亲、公平 1v1 切磋。
- 想用"前期压得越低，打起来越爽"的铺垫制造悬念与高潮。
- 多方势力围观、盘口赌注、亲友团反应的大场面较量。

## 核心技法
- **前期铺垫（压低期待）**：谁邀战？为何？对手多强多讨厌？旁人风凉话？亲友劝退？采取策略（藏拙/秒杀/力敌/智取）？压得越低，读者期待越高。
- **气氛渲染**：天气、景物、万众瞩目。三分打斗七分铺垫——先抓情绪再写激烈。
- **登场对比**：对手拉风登场（多人陪同、万人呼喊、气势磅礴）vs 主角满场唏嘘嘲讽登场，形成鲜明反差。
- **多维度描写**：① 人物表情；② 动作细节（小动作、后手准备）；③ 环境描写（破坏力侧面烘托）；④ 心理活动；⑤ 旁观者反应；⑥ 氛围渲染；⑦ 招式/效果落地。
- **打斗写法三模式**：写实法（招式名+动作拆解出画面）、写虚法（攻击者状态+招式效果+影响+被攻击者反应）、虚实结合（最常用，按文笔长短调配）。
- **结果预判博弈**：各方势力各自看好谁？预判与事实的反差即转折张力。
- **裁判与规则**：规则是什么（可否杀人/限制/空子）？固定礼仪或挑衅动作？给比武以框架感。
- **战斗力悬殊处理**：差距大时描写要短，重点刻画内心/神情/观众反应；五五开则硬碰硬 + 气象词汇；大招重点写成本与效果。

## 可直接套用模板 / 清单
- **擂台模板**：[铺垫：邀战/对手强/旁人看衰/盘口赌注] → [气氛+双方反差登场] → [裁判规则+行礼] → [结果预判博弈] → [打斗：写实/写虚/虚实结合] → [反转/打脸/收尾意境]。
- **打斗三模式速选**：
  - 写实：招式名 + 一招一式动作。
  - 写虚：攻击者状态 + 效果 + 影响 + 反应。
  - 虚实：两者结合，按擅长调配。
- **自检清单**：
  - 是否先把对手垫高、主角压低制造反差？
  - 登场对比、旁观者反应是否到位？
  - 是否用了表情/动作/环境/心理/旁观者多维度？
  - 规则与裁判框架是否清晰？
  - 悬殊差距是否用"短写+内心/观众"处理？
- **避坑**：别上来就开打无铺垫（读者不疼不痒）；别只喊招式名无画面；别让配角抢了主角戏。

## 红线
- 用通用措辞，不照搬专属设定 / IP 的门派名、比武名称与具体招式。

## `novel-how-violence-implicit` · 暴力留白怎么写


# 暴力留白怎么写

## 适用场景
- 打斗/残酷场面，需要力度却不想靠血腥堆砌。
- 想用"不写过程写后果"制造更狠的余震。
- 平台合规或风格克制，需要收敛暴力描写。

## 核心技法
- **写结果不写过程**：不描刀如何入肉，写"他低头，看见自己胸前多了一截柄"。留白让读者脑补出比描写更狠的画面。
- **以静写暴**：暴行之后写一个反常的静——风停了、鸟不叫了、血滴在青石上的声。寂静是暴力的回声。
- **旁观者反应**：不写受害者多惨，写旁人"别过了头，喉结动了动没敢出声"。他人反应即暴力的度量。
- **声音与气味**：闷响、金属磕碰、铁锈味漫开——用非视觉感官暗示暴力，既克制又有沉浸感。
- **后果即审判**：暴行后写留下的痕迹（歪掉的凳、地上的碎瓷、某人此后见血就僵），余震比当场更持久。
- **克制即高级**：真正恐怖不靠直观血腥，靠"发生了什么但不说尽"。留白让读者的想象完成最后一刀。

## 可直接套用模板/清单
- **留白公式**：不写过程___ → 写结果（一截柄/静/反应）___。
- **感官替代**：声音___ / 气味___ / 旁观反应___。
- **余震痕迹**：歪凳___ / 碎瓷___ / 此后应激___。
- **自查**：写结果不写过程了吗？以静写暴了吗？余震留痕了吗？

## 红线
- 用通用措辞，不照搬专属 IP 暴力戏。
- 暴力靠留白与后果，不靠血腥堆砌，克制即高级。

## `novel-how-war-epic` · 战争大场面怎么写


# 战争大场面怎么写

## 适用场景
- 冷兵器会战、热武器大战、奇幻国战、千军万马级冲突。
- 想写出"波澜壮阔、热血沸腾"的史诗感而非数字堆砌。
- 宏观战场全景与微观个体体验的结合。

## 核心技法
- **战前铺垫（庙算）**：缓慢推进、节奏放轻；刻画社会矛盾与人民境遇；多方势力角逐、朝野争斗；高层决策开打。紧张气氛从上到下慢慢加温，给战争以理由。
- **面到点（宏观→微观）**：先大场景渲染氛围，再从面到点刻画具体士兵，最后聚焦主角如何冲锋陷阵、力挽狂澜。目的是突出惨烈、主角能力、反差、结局意外。
- **五感渲染法**：视觉（旌旗如云、箭雨如瀑）、听觉（战鼓/号角/喊杀/金铁/哀嚎）、嗅觉（血腥/焦糊/泥土）、触觉（甲胄沉重/武器震动/伤口灼痛）、心理感（面对死亡的战栗、战友倒下的绝望、杀红眼后的麻木）。用体验替代数字堆砌。
- **宏观与微观交响**：全景视角展现多线战局，穿插显微镜下的个体体验（受伤者注意到"高远宁静的蓝天"），让大历史由小细节构成。
- **热武器战争差异**：开战前通过情报/沙盘布防调兵遣将；落实战壕/伤亡/时间节点；按战争目的用兵法；最后刻画主角关键作用。
- **战争-政治双螺旋**：战争是政治延续，每场战争有明确政治目的；谈判桌的让步对应战场伤亡。与权谋线交织提升深度。
- **战争多样性**：正规大战/小战、非正规大战/小战按比例混用，避免单调。
- **类型配比**：根据剧情作用决定落笔——为打压主角则败、为人设则惨烈、为突出技能则制造反差甚至以少胜多。

## 可直接套用模板 / 清单
- **冷兵器大战模板**：[战前庙算/社会矛盾] → [大场景氛围渲染] → [具体士兵群像（面到点）] → [主角冲锋/关键转折] → [反差结局/出乎意料]。
- **热武器大战模板**：[情报沙盘/调兵] → [第一枪+声效渲染] → [战壕/伤亡/时间节点] → [兵法运用] → [主角关键作用+冲锋号/结局]。
- **史诗感清单**：
  - 是否有战前缓慢铺垫与开战理由？
  - 是否"面到点"从全景缩到个体？
  - 五感是否齐全（视觉/听觉/嗅觉/触觉/第六感）？
  - 是否宏观全景 + 微观个体双线？
  - 是否避免纯数字堆砌（出兵多少、死伤多少）？
  - 战争是否有政治/剧情目的支撑？
- **避坑**：别通篇"枪林弹雨、血肉横飞、战斗激烈"空话；别只写宏大无个体无代入；别无生活体验硬编。

## 红线
- 用通用措辞，不照搬专属设定 / IP 的具体战役、兵种、阵营名词。

## `novel-how-warfare` · 战争大场面怎么写（战略战术）


# 战争大场面怎么写（战略战术）

## 适用场景
- 冷兵器/热武器/架空战争、海战、攻城战、守城战
- 需要展现主角的军事才能与临场应变
- 战役作为政治延续，而非孤立打斗
- 多兵种、多战线、战术流描写

## 核心技法
- **先定视角，再落笔**：①上帝视角（广角俯瞰战阵变幻，适合史诗感与战略层）②凡人/主角视角（耳边战鼓、眼前刀光，最具代入感）。新手从后者入手更易写出真情实感。无论多大场面，读者最终关心"人"，给主角一个具体而紧迫的目标。
- **全局与局部穿插**：全局=场景构建、环境、群众气氛（镜头拉远）；局部=主角团个人感受、所见所闻（镜头拉近）。穿插着写避免枯燥，主镜头始终在主角身上。
- **五感渲染法**：平庸战争是"数字游戏"，优秀战争是"五感体验"——视觉、听觉、嗅觉、触觉、心理感全面铺开，让读者"感受"而非仅"知道"战争。
- **战役三段式节奏**：①前奏章=情报判断、军事会议、兵力调动、间谍反间、战前悬念；②高潮章=地形天气、排兵布阵、始料未及的变化、关键转折点；③后续章=战果统计、功过赏罚、战略态势变化、新问题浮现。
- **战争-政治双螺旋**：每场战争都有明确政治目的，而非为打而打；谈判桌每让一分对应战场每伤一分。把战争胜负与庙堂权力博弈绑定，提升思想深度。
- **沙盘推演写法**：用沙盘/舆图具象化战术。借人物争论暴露地形、补给、敌情约束，让战术决策"看得见"。
- **战术多样性**：正规大战/小战、非正规大战/小战按配比混用；常用战术：迂回、水攻、火攻、夜战、撤退、诈降、围城必阙等。
- **从面到点**：大场景渲染氛围→刻画具体人物表现→落笔主角如何力挽狂澜。依战争对主线的作用力决定落笔。

## 可直接套用模板/清单
- **战役前奏清单**：情报是否清晰？将领方案是否分歧？后勤/调动是否写？有无间谍反间？战前悬念是否抛？
- **五感描写检查**：本章视觉/听觉/嗅觉/触觉/心理是否至少各 1 处？避免只报数字。
- **战术决策沙盘模板**：目标→地形约束→敌情→我方底牌→A 方案（保守）/B 方案（冒险）→争论焦点→最终选择及代价。
- **战争-政治绑定问句**：这场仗的政治目的？谈判桌对应哪分伤亡？胜负如何反哺庙堂线？
- **战局收尾清单**：战果统计、赏罚收心、态势变化、新敌/内矛盾浮现。

## 红线
- 用通用措辞，不照搬专属设定 / IP 的具体战役与人物。
- 避免金手指过强，给胜利加合理限制。
- 历史/兵种考据要自洽，架空亦需内部逻辑；战争不能脱离政治目的空打。

## `novel-how-witduel` · 智斗/破局怎么写


# 智斗/破局怎么写

## 适用场景
- 智斗、高智商对决、死局破局、读者期待"主角优雅掀桌"
- 两个聪明人互相算计，而非主角被反派牵着走
- 规则嵌套、信息差对抗、多层反转
- 避免"千层饼"疲劳与机械降神

## 核心技法
- **换规则掀桌**：反派精心设计的局，主角在原有规则里怎么玩都输时，直接引入规则外的维度。反派所有后手瞬间作废，降维打击。读者想看的是"还能这么玩？"的优雅掀桌，不是头铁硬刚靠运气险胜。
- **引入超规格变量**：智斗本质是信息差与逻辑推演，破局关键在引入对方算不到的东西（一个全新势力、一种对方世界观外的资源）。当所有人还在第一层争夺时，主角直接跳层破局。
- **威胁无效化**：反派常靠主角软肋拿捏，破局可让该威胁对本方无效（已无软肋、或主动弃子），反转权力关系。
- **规则嵌套法**：设定三到五条互相矛盾的核心规则，主角利用规则矛盾破局，每次破局后规则升级更矛盾。主角是"向内解"而非"向外打"，悬念密度更高。
- **信息差对抗法**：表层对抗+中层信息差+深层反转（信息差本身也是陷阱）。信息差不能是机械降神——必须是前文埋过伏笔的，读者回头一想"原来那句话是这个意思"。
- **反派必须聪明**：读者要看两个聪明人互相算计，只有反派也强，主角每次胜利才珍贵。
- **金手指变双刃剑**：每次使用能力付出代价，"刀尖舔血"的紧张感才是留住读者的终极武器。
- **智斗大纲法**：参与智斗的角色都得是智者，行为理性使然——明确目的，据目的想最合适解决方式。先定主要矛盾确主线，再细分剧情节点（后面节点往前埋伏笔）。常见坑：①斗不起来——需创造小破绽；②千层饼——"我预判你预判"宜少不宜多；③信息差存在条件是"时间"；④利用信息差前对手也会试探；⑤真与假——真可以是假，假未必不如真。
- **叙事时紧急**：发生情景立刻写角色应对，再返回讲思考分析过程，智商体现更明显。
- **信息分配**：打信息差不仅主角与敌，也包括主角与读者；让主角通过独有情报优势制胜；列信息表按需分配给角色。

## 可直接套用模板/清单
- **掀桌三选一**：换规则 / 引超规格变量 / 威胁无效化——本章破局用哪一招？
- **规则嵌套设计**：列 3–5 条矛盾规则（各一句话能说清）→主角如何利用矛盾→破局后规则如何升级。
- **信息差检查**：反转是否前文埋伏笔？是否机械降神？信息差本身是否也是陷阱？
- **智斗大纲卡**：主要矛盾→主线→剧情节点（时间序+前埋伏笔）→各方目的与最优解→制造的小破绽。
- **反派智商自检**：反派是否卷起来？胜利是否珍贵？金手指是否双刃？

## 红线
- 用通用措辞，不照搬专属设定 / IP 的具体智斗桥段与人物。
- 避免千层饼疲劳（反转不突兀、宜少不宜多）、避免机械降神（信息差须有前伏笔）。
- 主角不能是被反派牵着走的工具人，破局须"优雅掀桌"而非强行降智反杀。
