# 技法卡路由（L2 弹药路由 · 半自动凭证制）

> 定位：`技法卡/` 438 张卡片的唯一入口。写作时**不记卡，只调本路由**。
> 铁律：写/改任何正文前，先判章型 → 命中卡族 → 取 2-5 张最对口卡 → 提取结论注入 → 亮【技法卡匹配凭证】。缺凭证 = 违规 = G6 对质不通过。

## 一、章型判定

**输入**：本章大纲条目 + `章卡节奏标记`（爽点/爆点标记）+ `章卡规划区`（爽点模式）。

**判定章型（可多标签叠加，如「对话章 + 情绪渲染章」）**：

| 章型     | 判定信号                             |
| ------ | -------------------------------- |
| 对话章    | 本章以人物交锋/谈判/告白为主，对话占比高            |
| 情绪渲染章  | 大纲情绪落点为虐/甜/怒/悔等强情绪               |
| 打脸逆袭章  | rhythm\_tracker 标记爽点章，爽点模式为打脸/越级 |
| 战斗章    | 含打斗/法术/交锋场景                      |
| 钩子悬念章  | 章末留重大钩子或揭示秘密                     |
| 文笔展示章  | 重画面/质感/氛围，轻事件推进                  |
| 人物塑造章  | 重人设立住/内心转折/关系变化                  |
| 场景质感章  | 重环境/物件/生活质感（酒楼/后厨/宫室）            |
| 开篇黄金三章 | 全书前 3 章                          |
| 过渡章    | 承上启下，无重大冲突                       |

## 三、取卡规则

1. 到命中维度分册内，按本章具体需求（如「告白」「争吵」「打脸」）检索，取 **2-5 张**标题/内容最对口的卡。
2. 只提取每张卡的 **1-3 条可落笔结论**（不是整卡搬运），注入草稿生成的写作约束。
3. 一次 2-5 张，不堆砌，优先「最对口」而非「最多」。
4. fallback：若命中卡族内无对口卡（极冷门写法），不得硬套无关卡、也不得跳过凭证——按 G3 引擎约束写，凭证中该卡族行注明「扫描卡族 X，当前无更对口卡，按引擎约束写」，并记入项目台账待补卡。

## 四、【技法卡匹配凭证】模板（写/改正文前必亮，落盘 `章卡规划区`）

```
【技法卡匹配凭证】
- 章型：<对话章 + 情绪渲染章>
- 引擎约束：<writer-prompt 章节公式 + R1-R5 铁律>
- 常驻：六卡四关全开（见 文风六卡.md）
- 已取卡：<D05 潜台词 / D05 声口 / D08 情绪渲染>（2-5 张，各附一句落卡结论）
- 落卡结论：上述每张卡的结论已落进本章；本章无「凭空写、无卡支撑」的写法。
```

> 凭证不是走形式：列出的每张卡，必须在对应分册里真正检索到并展开其结论、落到本章产出。只写卡名不落结论 = 未执行 = G6 判失败。

## 五、纪律

* 本路由是「弹药取用器」，不是流程控制器——不替代 G3 的 Scene-Sequel / R1-R5 / 量化指标。

* 与 L3 文风六卡正交：六卡是每句必过及格线，本路由是本章写法弹药，二者叠加、不冲突。
