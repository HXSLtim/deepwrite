## `novel-how-blurb` · 简介/文案怎么写


# 简介/文案怎么写

## 适用场景
- 新书上传填简介、老书改文案救点击
- 平台推荐页/搜索结果里，简介是仅次于书名的第二门面
- 想让读者看完简介就产生"追更预期"

## 核心技法
- **前30字定生死**：移动端推荐页常截断，必须把最强钩子（身份反差/核心冲突/金手指）放进开头，别用"这是一个关于…"的慢热铺垫
- **核心卖点前置（万能公式）**：极致的冲突+唯一的金手指+爽感预期。简介里先亮"[角色A]有什么、要对抗什么、能获得什么"
- **埋钩不剧透**：给读者一个"为什么/后来怎么了"的悬念缺口，但别说破结局。例："所有人都以为[角色A]是废物，直到那晚他睡着了……"
- **爽点节奏展示**：用"前期小胜→中期翻盘→后期格局"的递进暗示，让读者预判追更回报，而非罗列剧情
- **人设一句话锚定**：简介里塞一句[角色A]人设标签（冷面笑匠/苟命理性人），降低读者理解成本

## 可直接套用模板/清单
- [ ] 第一句：身份/处境反差（"刚被开除的[某职业]，反手治好了[某大人物]"）
- [ ] 第二句：核心冲突+金手指（"绑定[某系统]，每次[某行为]折寿一天"）
- [ ] 第三句：爽感承诺/悬念缺口（"当全网笑他短命，他已救下半个城"）
- [ ] 自查：有没有剧透结局？有没有水字数？前30字够不够炸？
- [ ] 风格统一：简介文风≈正文文风，别简介文艺正文暴躁

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 简介是门面不是剧透器，留白比说尽更有勾引力

## `novel-how-first-meet` · 初遇怎么写


# 初遇怎么写

## 适用场景
- 男女主/重要关系角色的第一次见面
- 想让初遇"即命运"，决定感情线天花板
- 避免"他们在咖啡馆相遇了"这种零画面零期待的平庸开场

## 核心技法
- **好初遇三要素**：
  1. 有冲突或意外——不是"相遇"，是"[角色A]把咖啡泼在[角色B]裙子上"
  2. 留下独特印象——不是"[角色B]很美"，是"[角色B]反驳[角色A]的样子真带劲"
  3. 埋下延续理由——"后来[角色B]发现，[角色A]就是自己新项目的死对头"
- **反面教材**："[角色A]是高冷总裁，[角色B]是活泼少女，他们在公司相遇了"——读完脑子无画面无期待
- **正面教材**："[角色B]怎么也没想到，那个把她从总监位拽下来的人，竟坐在她旁边工位"——一句话塞进冲突+地位差+被迫相处+读者期待
- **强冲突场景变体**：重逢偶遇、暴雨错上车、身份碰撞（外卖员弄脏总裁西装），开篇3秒制造悬念
- **人设反差锚定**：外在标签+内在反差，如"高冷总裁手机壳印卡通图案"，初遇就立住反差魅力

## 可直接套用模板/清单
- [ ] 初遇有没有冲突/意外？（泼咖啡/撞车/对立立场）
- [ ] 留下什么独特印象？（一个动作/一句话立人设）
- [ ] 有没有延续理由？（死对头/同居/共同任务）
- [ ] 自查：读者看完这句，脑子里有画面吗？有期待吗？
- [ ] 不用"他很美/她很帅"概括，用具体行为

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 初遇是钩子不是说明，一句顶十句铺垫

## `novel-how-golden-finger` · 金手指怎么写


# 金手指怎么写

## 适用场景
- 设计主角独有外挂/系统/重生/特殊道具
- 避免"开局满级横扫两百章"让读者麻掉
- 让金手指成为剧情推进器而非装饰

## 核心技法
- **三性底线**：合理性（世界观自洽）、稀缺性（仅[角色A]有，避免全城都有系统）、成长性（可升级/变异，如"预知3秒"→"修改时间线"）
- **带刺的玫瑰**：优质金手指=收益伴风险。例"[角色A]的读心术每次消耗寿命"，读者爽在[角色A]"取舍"而非"无敌"
- **成长型>一次性**："每升一级+5%属性"比"开局属性99999"耐看百倍；常见拆法：等级解锁/任务解锁/阶段绑定/概率成长
- **抉择困境才是爽点**：给金手指设"资源稀缺"，二选一瞬间（异能强但有冷却，用了就救不了下个人）往往是单章追读飙升爆点
- **必须和剧情咬合**：拿到顶级系统后五章在跟室友打游戏——读者第三章就问"那个系统呢？"
- **强度预算表**：开局只解生存/首逆袭→前期稳定优势但打不过大势力→中期改一城格局→后期触世界核心→结局完成最终选择（非无限升级）
- **五种成长方向**：功能更深/范围更大/效率更高/组合更多/理解更完整（"升级"≠只加数值）
- **六大类型**：系统/重生/物品/血脉/认知/规则；黄金公式=能力形式×获取方式×使用限制

## 可直接套用模板/清单
- [ ] 能力形式 × 获取方式 × 使用限制（限制越清，破局越精彩）
- [ ] 是不是"带刺"？收益有无真实代价？
- [ ] 成长性：能随剧情进化吗？还是一次性买断？
- [ ] 和主线咬合：每3章至少用一次推动剧情？
- [ ] 强度预算：当前阶段该多强？别提前亮满底牌

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 金手指是合法外挂不是无敌作弊器，张力来自限制

## `novel-how-on-ship` · 船上/航行场景怎么写


# 船上/航行场景怎么写

## 适用场景
- 角色在船上，需要"流动中的封闭"——既漂泊又逃不掉。
- 想用航行写长途里的关系发酵、或风暴中的生死协作。
- 甲板对峙、舱内密谋、海盗来袭等海战戏。

## 核心技法
- **船=流动的牢笼**：四周是海，退路断绝，人际被迫浓缩。封闭感类似监狱，但多了一层"漂向未知"的不确定。
- **海浪即节奏器**：船的起伏、缆绳的绷紧、货物的移位——浪的节奏可同步人物心跳。平静海面=喘息；巨浪=危机。
- **甲板与舱内的空间对立**：甲板上是风浪与对峙（开阔、危险、公开）；舱内是密谋与喘息（密闭、私密、暗流）。两个空间切换即戏眼。
- **风暴试炼**：甲板在风暴中变成修罗场，每个人暴露本性——谁镇定、谁慌乱、谁挺身。风暴是人物试纸。
- **声音层次**：浪拍船身、风过帆索的啸叫、木板呻吟、远处雷——封闭水面上声音被放大成悬疑。
- **景随情变**：归心似箭者看海岸线一寸寸近；流亡者看陆地越远越空。

## 可直接套用模板/清单
- **空间对立**：甲板（公开/危险）___ / 舱内（私密/暗流）___。
- **浪之节奏**：平静=___ / 巨浪=___ / 同步哪个人物___。
- **风暴试纸**：谁镇定___ / 谁慌乱___ / 谁挺身___。
- **自查**：流动牢笼感有吗？甲板舱内对立清楚吗？风暴暴露本性了吗？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 船写漂泊封闭与试炼，不写航海教程。

## `novel-how-opening` · 开篇（黄金三章）怎么写


# 开篇（黄金三章）怎么写

## 适用场景
- 新书动笔，需要设计前三章结构
- 已有开头但留存/追读数据差，需要返修
- 评估大纲开篇是否"三章定生死"

## 核心技法
- **300 字内主角必须出场并建立锚点**：第一段就出场，带强情绪状态（愤怒/不甘/绝望），不要用大段世界观或天气开场。
- **前 300 字必须出现"困境+冲突"**：读者只关心三件事——[角色A]是谁、遇到什么麻烦、我为何继续看。
- **三章分工明确**：
  - 第一章=暴击：[角色A]+致命困境+即时冲突，反派立刻出场把矛盾砸脸上。
  - 第二章=压制+破局伏笔：压力翻倍，金手指/核心优势首次亮相，憋爽点不提前打脸。
  - 第三章=爽点落地：小胜利+明确目标+强悬念，给读者一颗糖再抛新钩子。
- **金手指 3000 字内必须亮相并产生效果**：这是读者追更核心动力，不能拖。
- **世界观边写边抖**：像撒孜然，不端一盘料倒上来；用后果倒推规则（"地铁安检第三次闪红"胜过"因灵气复苏十年后"）。
- **感官优先、逻辑靠后**：从身体感受（剧痛/寒冷/饥饿）切入，用动作替代心理描写（"抓起凉馒头啃了两口"而非"他很悲伤"）。
- **每章章末断章钩子**：制造"认知缺口"，别把故事讲圆满再结束。
- **视角聚焦**：前三章死盯[角色A]一人，配角有名有姓不超过 4 个。

## 可直接套用模板/清单
- **三章逐章拆解模板**
  - 第一章（2000-3000字）：首段暴击（谁+什么处境+面临什么）→ 身份一句话点明 → 困境具体（"马上要完蛋"非"很惨"）→ 反派出场砸矛盾 → 章末断章。
  - 第二章：困境推更糟 → 金手指/优势暗示亮相 → [角色A]被迫选择无路可退 → 章末钩子。
  - 第三章：即时反馈小胜利 → 主线目标确立 → 钩子收尾（新悬念/新敌人）。
- **开篇五步法自检**：①30秒抓住注意力（制造冲突）②快速建立人设（身份/性格/核心欲望，用行动）③亮金手指（基础能力/成长路径/独特优势）④制造爽点（打脸/收获/反转）⑤留钩子（信息差/危机预告/选择困境）。
- **开篇及格三问**：前300字读者知道[角色A]多惨吗？前三章看到金手指且起作用了吗？每章结尾有让读者点下一章的悬念吗？

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 误区警示：不写世界观堆砌、主角别晚出场、对话别泛滥、冲突要够强、金手指别太晚。

## `novel-how-opening-beatdown` · 退婚 / 废柴觉醒流


# 退婚 / 废柴觉醒流

## 适用场景
- 玄幻/仙侠/都市异能经典男频开局
- 读者预期：看废柴被踩后逆袭打脸

## 核心技法
1. **核心公式**：被欺辱 → 意外触发 → 觉醒 → 第一次展示实力。
2. **羞辱即钩子**：退婚书摔脸上、被骂"废物一辈子翻不了身"——用公开羞辱制造读者愤怒与期待。
3. **触发反转**：就在被踩最低点时，丹田沉睡十六年的力量醒了/系统激活——"我笑了。因为就在刚才，那股力量醒了。"
4. **首秀即打脸**：觉醒后立刻用小炮灰验证实力，引出背后小 boss 注意，结尾正面语言冲突把矛盾摆上台面。
5. **小炮灰+小boss结构**：第一章结尾必须是小 boss 一句狠话或主角更嚣张回应，让读者不得不追下一章。

## 模板清单
- 辱：退婚/被骂废物（公开羞辱）
- 醒：最低点触发力量/系统
- 秀：首秀打脸小炮灰
- 钩：小 boss 登场 + 狠话收尾

## 红线
- 忌觉醒太轻易无铺垫（需前压后弹）。
- 忌首秀无打脸对象（需小炮灰）。
- 忌章末无钩子。

## `novel-how-opening-character` · 500字内立人设


# 500字内立人设

## 适用场景
- 开篇前三章的人物锚定
- 防止"主角面目模糊、读者不知代入谁"

## 核心技法
1. **三维度标签**：
   - 身份标签：废柴/天才/重生者，一句话说清
   - 性格标签：隐忍/张扬/腹黑，用一个动作展示
   - 欲望标签：复仇/变强/回家，一句话点明
2. **用行动展示不用旁白**：
   - 差："[角色A]是一个性格坚韧不屈不挠的人。"
   - 好："[角色A]打断三根肋骨，愣是没吭一声。他盯着打手的眼睛，一字一顿：'记住这张脸。'"
3. **一个标签足够**：前三章不需要全面，给读者一个鲜明标签即可，其余后续展开。
4. **痛点即人设**：主角的核心痛点（被羞辱/无力感）本身就是人设锚。

## 模板清单
- 身份：开场一句话定位
- 性格：用第一个反应动作证明（非形容词）
- 欲望：用主角心声/目标点明

## 红线
- 忌用旁白罗列形容词（用动作证明）。
- 忌前三章人设模糊无标签。
- 忌一次性倒尽背景（留后续）。

## `novel-how-opening-cliffhanger` · 第三章结尾留钩子


# 第三章结尾留钩子

## 适用场景
- 黄金三章收尾、所有章节末尾
- 防止"一章写完读者无动力翻下一章"

## 核心技法
1. **三种钩子类型**：
   - 信息差：读者知道一个秘密但主角不知，想看主角何时发现
   - 危机预告：更大的敌人即将到来，想看主角怎么应对
   - 选择困境：主角面临两难，想看他选哪个
2. **必须为下一章设悬念**：每章结尾抛新问题/新危机（cliffhanger）。
3. **跨章钩子保留**：上一章章末悬念，下一章不得用一句废话提前化解，必须留给读者多章。
4. **钩子即期待点**：关系转变节点、反派登场、秘密揭露都是天然钩子。
5. **不套路结尾**：禁止决心式/睡觉式/盘算式结尾，必须引出下文。

## 模板清单
- 选型：信息差 / 危机预告 / 选择困境
- 落句：最后一句话抛出悬念
- 验：下一章首段是否误拆（不得提前化解）

## 红线
- 忌章末无钩子。
- 忌下一章首段用废话提前化解（跨章钩子铁律）。
- 忌决心式/睡觉式/盘算式套路结尾。

## `novel-how-opening-golden-finger` · 金手指亮相


# 金手指亮相

## 适用场景
- 所有带金手指文的开篇（系统/重生/空间/异能）
- 防止"金手指平淡、读者无感"

## 核心技法
1. **第三章前必须亮相**：金手指是核心卖点，前三章没出现读者凭什么继续看？
2. **场景戏剧性**：不是平淡"叮，系统绑定成功"，要在冲突顶点触发（绝境/被羞辱时）。
3. **首效明显**：第一次使用要产生"哇"的效果——"一夜从炼体三层突破六层""系统首奖 SSR 功法"。让读者直观感到牛。
4. **规则简单清晰**：读者一看就懂，不需解释半天；避免长篇"说明书式"介绍。
5. **通过小事件测试**：测试过程不能枯燥研究说明书，要借具体微小事件展开（获得透视立刻去看/获得神豪立刻去买最贵的东西），并引入"看门狗"级小炮灰被轻视。

## 模板清单
- 亮：冲突顶点触发（非平淡）
- 效：首用产生明显震撼效果
- 则：规则一句话说清
- 试：借小事件+小炮灰验证

## 红线
- 忌金手指第三章后才亮相。
- 忌首用零效果（需惊艳）。
- 忌规则复杂需长解释。

## `novel-how-opening-golden3` · 黄金三章结构


# 黄金三章结构

## 适用场景
- 所有网文开篇规划（编辑只看前三章）
- 防止"铺垫太久、读者划走"

## 核心技法
1. **第一章：极限困境+金手指触发**（2500–3500字）
   - 动态冲突场景（被羞辱/攻击/背叛）约 1000 字
   - 困境溯源（简短回忆+无力感）约 1000 字
   - 金手指触发（绝境中觉醒）约 500–1000 字，章末卡点"金手指能做什么？"
2. **第二章：强化冲突**
   - 给主角必须完成的短期目标 + 强力阻碍（目标可视化+阻碍具体化）
   - 例：重生文知三天后家族被害，须三天内找证据，反派处处监视
3. **第三章：爽点反馈**
   - 至少一个爽点（打脸/收获/反转），让读者尝甜头
   - 结尾留钩子（信息差/危机预告/选择困境）

## 模板清单
- 章1：冲突1000+溯源1000+触发500，卡点问句
- 章2：目标+阻碍具体化
- 章3：爽点+钩子结尾

## 红线
- 忌第一章介绍世界观/主角过去（后续穿插）。
- 忌前三章无爽点（读者累）。
- 忌第三章结尾无钩子。

# 开局避坑清单

## 适用场景

- 防止"常见坑导致读者3秒划走"

## 核心技法（五避坑）
1. **第一句话**：是否有冲突/悬念/意外？无则读者 3 秒划走。

- 第一章介绍世界观、第二章写日常、第三章才进正题——读者平均 3 秒划走一本。

- 金手指拖到很后面才亮。
- 只冲突无爽点（读者累）。

## `novel-how-opening-rebirth` · 重生开篇


# 重生开篇

## 适用场景
- 都市/仙侠/游戏/古言重生文
- 读者预期：看主角利用先知优势逆天改命

## 核心技法
1. **核心公式**：死亡 → 重生 → 发现回到关键时刻 → 决定改变命运。
2. **开场即冲击**：第一句直接给死亡与重生的反差——"我死于2026年6月1日，加班猝死。睁开眼，回到了大学毕业典礼前一天。"
3. **先知优势立刻用**：上辈子错过的面试/被害的家族/错信的人，本章内就要有"这次不一样"的具体行动，而非空表态。
4. **痛点即钩子**：重生文开篇写对新身体的狂喜或对前世屈辱的愤怒，用第一视角感受切入，语言精炼粗暴。
5. **短期目标锚定**：重生后给一个紧迫的近期目标（三天内救回被拐妹妹/阻止家族陷害），让读者有追的抓手。

## 模板清单
- 死：一句话交代前世结局（冲击）
- 生：回到哪个关键时刻（具体）
- 决：一句"这次我要…"的态度
- 行：本章内用先知做第一个具体改变

## 红线
- 忌重生后只感慨不行动（须立刻用优势）。
- 忌无具体改变目标（读者不知追什么）。
- 忌前世记忆交代冗长（用动作带出）。

# 系统流开局

## 适用场景
- 游戏/都市/末日/系统等金手指文
- 读者预期：看系统机制+主角第一次使用的爽感

## 核心技法
1. **核心公式**：普通场景 → 系统突然出现 → 第一次使用 → 效果震撼。
2. **触发即危机**：系统常在濒死/绝境激活——"检测到宿主濒死危机，救世主系统启动。首个任务：下一站下车，否则你会死。"危机感让系统绑定有重量。
3. **三步展现法**：
   - 触发（第1章）：绝境中系统觉醒，章末卡点"金手指能做什么？"
   - 试探（第2章）：完成小任务，产生初步改变但不足以逆转
   - 爆发（第3章）：第一次小逆袭，给读者首次爽感
4. **规则简单清晰**：第一次使用要产生明显效果（"一夜从炼体三层突破到六层"），读者一眼懂，不需解释半天。

- 触：濒死/绝境 + 系统降临（卡点问句）
- 试：小任务 + 初步改变
- 爆：第一次逆袭 + 爽感

## 红线
- 忌系统平淡亮相无危机。
- 忌规则复杂读者看不懂。
- 忌首次使用零效果（需"哇"一下）。

## `novel-how-penname` · 笔名怎么写


# 笔名怎么写

## 适用场景
- 新人第一次起笔名、老作者换马甲重开
- 想让笔名好记、有辨识度、不影响平台搜索
- 避免侵权、生僻、跟大神撞名

## 核心技法
- **好记优先**：2-4字最佳，读者扫一眼能拼出来、能搜到。生僻字/多音字会让读者搜不到你
- **风格匹配题材**：甜宠用软糯字、悬疑用冷硬字、历史用古意字——笔名是无声的"分类标签"
- **不侵权不撞名**：别用名人/品牌/已签约大神的笔名变体；平台检索会混淆，也惹官司
- **留扩展空间**：别把单一题材焊死在笔名里（如"某某甜文"），以后转型受限
- **念出来顺口**：自己念三遍，拗口的立刻否；能被口头安利的笔名传播力最强

## 可直接套用模板/清单
- [ ] 候选3-5个，每个过一遍：字数≤4？生僻字？念着顺？
- [ ] 搜平台看是否撞名/近似（撞了立刻换）
- [ ] 题材契合度自测：这名字放悬疑/甜宠/玄幻哪个不违和？
- [ ] 侵权排查：非名人、非商标、非大神变体
- [ ] 最终选一个"能口头安利"的

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 笔名是长期资产，别为蹭热度用易过时热词

## `novel-how-title` · 书名/标题怎么写


# 书名/标题怎么写

## 适用场景
- 新书立项起名、老书改名救数据
- 想让书名自带流量、在推荐页完成"3秒定生死"的点击
- 避免文青晦涩、设定堆砌、跟风蹭字三类毒点

## 核心技法
- **四大爆款公式**：
  1. 身份反差+行动结果："[身份]，[角色A]跑去[做某件反常事]"（不该做这事的人+做了什么）
  2. 金手指+冲突对象+爽感承诺："[某能力]起手，[某对手]也得给我跪下"（能力+对手+结果）
  3. 数字/极端化+结果预期："[某地]每人每天给[角色A]一块钱"（信息密度高，一眼脑补画面）
  4. 反问句+精准痛点："你欠债了吗，[某系统]要我替万人还债"（戳打工人情绪）
- **万能包装公式**：具体爽点+巨大反差+核心身份。从平淡书名改写为"刚被[某机构]开除，[角色A]反手治好了[某大人物]绝症"（有冲突、有反差、有结果）
- **核心梗+人设+吸睛场景**：梗+人设+场景三件套，画面感拉满
- **标签+矛盾冲突**：既蹭热点又造戏剧冲突

## 可直接套用模板/清单
- [ ] 书名≤15字，忌涉黑涉政涉黄、忌生僻晦涩、忌与内容脱节
- [ ] 先列：核心梗 / [角色A]人设 / 吸睛场景，三选组合成书名
- [ ] 套用四大公式之一，自检"扫一眼知不知道讲啥、想不想点"
- [ ] 雷区排查：文青晦涩？设定堆砌亮底牌？跟风蹭字（同名被算法降权）？
- [ ] 旧瓶换新酒：萌宝代称（祖宗/幼崽/三宝）、书名主语（我/她/萌宝）灵活替换防撞名

## 红线
- 用通用措辞，不照搬任何专属 IP。
- 金手指存在感应靠前三章情节展开，书名只给方向不亮全底牌
