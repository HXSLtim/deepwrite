# 反AI模式清单

> novelOps 原创化内容，无外部来源引用。
> 用途：G3禁词扫描、G5参考指标、Humanizer去AI化
> 集成位置：指标自检（文风六卡·卡6 体检清单） AI_PATTERN检测 + ORCHESTRATOR.md G3写作约束

---

## 一、词汇层面

### 1.1 绝对禁用词

**哲学废话类**：
- "在这个世界上"
- "不禁让人想起"
- "仿佛在诉说着什么"
- "这一刻，时间仿佛静止了"
- "命运的齿轮开始转动"
- "在历史的长河中"

**过度总结类**：
- "总而言之"
- "综上所述"
- "不得不说"
- "值得一提的是"
- "毫无疑问"

**情感过度类**：
- "内心深处涌起一股难以名状的感觉"
- "复杂的情感在心中交织"
- "百感交集"
- "一种说不清道不明的情绪"

**形容词堆砌类**：
- "巨大的、恐怖的、令人窒息的压力"（选一个就够）
- "美丽的、动人的、令人心醉的容颜"（别用三个形容词）

### 1.2 严控词汇（限用）

| 词汇 | 限制 | 替代方案 |
|------|------|---------|
| 不禁 | 全章≤1次 | 直接描写动作："他皱起眉头" |
| 竟然 | 全章≤1次 | 用具体反应代替 |
| 一股XX涌上心头 | 禁用 | 具体化感受："眼眶微热""指尖颤抖" |
| 心中暗道 | 禁用 | 直接内心独白或表情反映 |
| 嘴角微微上扬 | 禁用 | "挑了挑眉""眼中闪过一丝戏谑" |
| 目光如炬 | 禁用 | 具体生理反应 |
| 浑身一震 | 禁用 | 具体身体反应 |
| 倒吸一口凉气 | 禁用 | 具体呼吸变化 |

### 1.3 连接词滥用

- 然而/不过/但是/尽管如此
- AI模式：AI喜欢在段落间建立生硬转折
- 要求：连续三个段落内，转折连词不得超过1个

## 二、句式层面

### 2.1 过度比喻
- "XX的XX，如同XX一般"
- AI极度依赖这种比喻结构
- 替代：直接描写动作结果，或使用暗喻

### 2.2 段落起手式雷同
- 连续使用代词开头
- 替代：用环境描写、对话或时间状语起手

### 2.3 机械三段式节奏
- "主语+动作。主语+感受。总结陈词。"
- 替代：长短句结合，高潮用短句，情感用长句

### 2.4 禁用句式

| 句式 | 示例 | 替代 |
|------|------|------|
| "随着XXX的XXX，XXX也XXX了" | 随着修炼的深入，他的实力也水涨船高 | "又一个月过去了。当他再次凝聚灵力时，掌心的光芒明显比之前亮了三分。" |
| "他不知道的是，XXX" | 他不知道的是，远处有一双眼睛 | 直接切换视角或用环境暗示 |
| "如果XXX知道XXX的话，一定会XXX" | 如果他知道这块石头价值连城 | 删掉，让后续情节自然揭露 |
| "XXX看着XXX，嘴角微微上扬" | 他看着远方，嘴角微微上扬 | 换成有角色特色的表达 |
| "不由得/不禁"过度使用 | 他不由得吃了一惊 | 直接写反应："他猛地站起来" |

## 三、结构层面

### 3.1 场景公式化
- 战斗三步曲"试探→惊讶→爆种获胜" → 打破公式
- 过度完美的对话（一人说完一整段，另一人完美回复）
- 真实对话：包含打断、犹豫、误解、沉默、答非所问

### 3.2 角色同质化
- 所有人说话像一个人
- 防范：严格遵守角色语言档案

### 3.3 机械排比
- "X, Y, and Z"三词结构，且三项并不真正不同
- 替代：更自然的结构

### 3.4 对话标签滥用
- 避免：exclaimed, mused, retorted, quipped, declared, proclaimed
- 替换为：said（80%情况）或删除标签改用动作节拍

## 四、情节层面

### 4.1 叙事逻辑问题
- 机械降神：主角陷入绝境时突然出现未铺垫的高人
- 要求：所有解局方案必须在之前章节有暗示

- 无代价的胜利：越级战斗后毫发无伤
- 要求：越级必须付出代价

### 4.2 互动失真
- 无脑配角/脸谱化反派
- 全员崇拜综合征（只要主角出手，所有人都在惊呼赞叹）
- 要求：保留质疑者、嫉妒者或不关心主角的人

### 4.3 禁用叙事模式

| 模式 | 示例 | 替代 |
|------|------|------|
| 总结式叙事 | "经过三天的苦修，修为有很大提升" | 用一个具体场景展示提升效果 |
| 情感宣告 | "他感到非常愤怒" | "他的手指陷进了掌心的肉里，指节发白。" |
| 列举式描写 | AI喜欢列举角色特点 | 用叙事自然展现，一段只聚焦一两个特点 |
| 对称式表达 | "既有XXX的坚定，又有XXX的柔软" | 用不对称的、更自然的表达 |
| 万能感叹 | "这就是修仙者的世界吗？" | 用具体的感官细节代替空洞感叹 |

## 五、英文AI词汇（参考）

以下词汇在英文AI生成中频繁出现，中文网文中如出现英文也需标记：

- additionally, furthermore, moreover, notably
- testament, tapestry, landscape, delve, embark, foster
- pivotal, profound, nuanced, multifaceted, intricate
- resonate, underscore, encompass, facilitate
- in terms of, in the realm of, it's worth noting that

## 六、质检员行动指南

1. 若出现 **3次以上** 禁用词汇/句式 → 标记为重要问题，建议润色
2. 若出现 **机械降神** 或 **无代价胜利** → 标记为致命问题，必须重写
3. 最终审查报告中附上"反AI味检测指数"：极低/偏高/严重超标
