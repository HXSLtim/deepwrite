# 文风六卡（L3 常驻层 · 每句必过）

> 定位：**文风及格线，优先级高于文采**。这六张卡是「写/改每一句时」的常驻约束，不是写完后的事后修补。
> 与 `anti-ai-patterns.md` 的关系：禁词黑名单以 anti-ai-patterns.md 为准，本六卡补其缺口（语气 / 语序 / 标点 / 人味正向锚点）。
> 出处：借鉴外部「文风常驻卡」的分层机制，内容已按 novelOps 自身语料原创化。

***

## 一、每句四关（写/改每一句都过）

> 这是本卡的核心动作。AI 默认偏书面、偏解说、偏工整，这四关把它拉回活人写法。

1. **语气关**：这句是角色说 / 想的吗？是 → 大概率该带语气词；把语气词去掉就变「念稿腔」→ 补回去。
2. **语序关**：正常语序读着顺吗？顺 → 绝不倒装；倒了反而拗口 = AI 感 → 改回正常语序。
3. **AI 味关**：踩 `anti-ai-patterns.md` 禁用词句了吗？踩 → 删，或换成具体的动作画面（见第三节替换字典）。
4. **标点关**：一个主谓小句内部硬插了逗号吗（「像干涸的河床，涨满了水」）？插了 → 删逗号，连写成一个完整小句。

***

## 二、六卡规则

### 卡 1 · 去 AI 味词句（黑名单以 anti-ai-patterns.md 为准）

不重复罗列词表，只补三条**执行动作**：

* **逻辑连接词**：首先/其次/综上所述/然而/值得注意的是 → 全删或改成口语（「说白了 / 讲句实在的 / 这点别忽略」）。

* **三词连用 = 标准 AI 缝合句**：「眼中闪过 + 嘴角上扬 + 心中了然」这类神态三连，必拆。

* **解说句 = 删**：作者跳出来替读者解释原因/铺垫，直接换成画面直给。

### 卡 2 · 语气助词（治「句子太干、像念稿」）

* 对话几乎必带语气词（呀/吧/呢/啊/嘛/可/呗/靠/得），**每 3 句对话至少 1 处**。

* 带情绪的内心 / 动作叙述，可点缀语气词；冷静叙述、战斗高速段、客观交代段**克制，不加**（加多了矫情）。

* 判定：去掉语气词会不会变念稿腔？会，就加；整段已经很口语再加会腻，就只点一两句。

### 卡 3 · 禁倒装（治「正常句子硬倒装」）

* **正常叙述 = 正常语序（主谓宾）**。三种必须禁止的「假倒装」：

  1. 宾语前置倒装：「这顿打，他记了一辈子」→「他记了这一顿打一辈子」。
  2. 话题化倒装：「这事儿，他干得漂亮」→「他把这事儿干得漂亮」。
  3. 状语堆叠句首：「在风雪交加的情况下，他打开了门」→「风雪里，他推开了门」。

* 全书仅**刻意强调焦点**时偶用倒装（「刀，已经架在脖子上了」），且要稀、不连发。默认目标 0 处。

### 卡 4 · 人味基准（正向锚点，治「只会躲 AI 味、不知人味长什么样」）

| 维度   | 真人写法（目标）           | AI 写法（规避）       |
| ---- | ------------------ | --------------- |
| 段落长度 | 1-3 句为主，偶尔 1 句独占一行 | 每段 4-6 句整齐均匀    |
| 对话标签 | 60%+ 无标签，用动作替代「说」  | 几乎每句「说道/问道」     |
| 情绪表达 | 动作展示（「手在抖」）        | 直接告诉（「很紧张」）     |
| 比喻   | 生活化（「像哈士奇护食」）      | 文学化（「如寒冰般」）     |
| 语气词  | 有口癖、有「嘤/嘶/靠/行吧/得」  | 几乎没有            |
| 省略   | 大量留白，读者自己脑补        | 面面俱到，生怕读者不懂     |
| 排比   | 偶尔 1-2 个，从不连续      | 连续 3-5 个标配      |
| 结尾   | 动作/对话收尾            | 总结/升华/感慨收尾      |
| 句长   | 长短错落，穿插 1-3 字超短句   | 主谓宾齐全像教科书       |
| 词汇   | 有私货、口癖、生活细节        | 安全词（进行/使得/作为一个） |

* **写时对照三问**：① 这句读着太工整了吗？是 → 拆碎、加短句、加一处不完美。② 这段每句都在「好好说道理」吗？是 → 插一个画面跳跃或一句吐槽。③ 角色说话像播音员吗？是 → 加语气词、加口癖、允许被打断。

* 红线：**不完美、不规则、有私货 = 人味；完美 = 机器。**

### 卡 5 · 感官细节 + 生活私货（人类护城河）

* 五感优先于形容词：不写「天气很冷」，写「鼻尖冻得发痒，呼出的白气还没散就被风吹碎了」。

* 四感清单（关键场景至少点 1-2 个）：嗅觉（霉味/铁锈味/饭馊味/雨后泥土味）、触觉（汗毛立起/掌心黏腻/冷风割脸）、听觉（吱呀/远处狗吠/自己的心跳）、味觉（口苦/唇裂的血腥）。

* 生活私货：不写「他饿了」，写「他摸出兜里半块干硬的饼，掰开时掉了一地渣」；不写「她紧张」，写「她把手机屏点亮又按灭，第三回了」。

* 操作：生成后在 2-3 个关键情绪点手动加一句「只有活人才有的细节」——这步最该人来填。

### 卡 6 · 去味体检清单（交稿前必跑）

| # | 操作                                    | 标准              |
| - | ------------------------------------- | --------------- |
| 1 | 全文搜逻辑连接词                              | 全删或改口语          |
| 2 | 全文搜「深吸一口气/眼中闪过/嘴角勾起/仿佛/不禁/缓缓开口/微微/瞬间」 | 命中即换（见下节替换字典）   |
| 3 | 统计破折号（——）                             | > 3 处 → 删到 3 处内 |
| 4 | 找连续 3+ 排比                             | 拆成叙述式           |
| 5 | 找「XX 是…」定义句开头                         | 改提问或场景开头        |
| 6 | 找「感到/觉得/无比/深深/心中涌起」                   | 换成行为描写          |
| 7 | 至少 2 处加口语化表达                          | 说白了/有个坑/坦白说     |
| 8 | 找「主语谓语硬插逗号」和「两三字一刀」碎句                 | 主谓小句内部不留逗号      |

## 三、替换字典（禁词 → 活人写法）

| 禁词 / 原句            | 活人写法                      |
| ------------------ | ------------------------- |
| 深吸一口气              | 胸口起伏了一下 / 直接删             |
| 眼中闪过一丝…            | 垂下眼 / 眯起眼                 |
| 嘴角勾起一抹 / 嘴角微微上扬    | 笑了一下，没到眼底 / 乐了            |
| 仿佛… / 宛如 / 犹如 / 好似 | 像… / 直接白描                 |
| 不禁…                | 直接写动作                     |
| 缓缓开口               | 说 / 用动作引出对话               |
| 突然 / 忽然            | 每 500 字不超 1 次             |
| 感叹号（！）             | 每段不超 1 个                  |
| 破折号（——）            | 每章不超 3 处                  |
| 他感到… / 她很…         | 动作展示：手在抖 / 把杯放回桌上，轻得像怕吵醒谁 |

***

## 四、大声读验证（终极一招）

一句话：**把写好的文字大声读出来，任何读着别扭、喘不上气、像念稿的地方，就是 AI 味最重处**——重点改这些。
