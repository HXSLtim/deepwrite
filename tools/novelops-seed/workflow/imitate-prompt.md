# 仿写流程指令

> **触发条件**：用户说"仿写""模仿写""学习这个风格写"时执行
> **输入**：样本文件路径 + 仿写主题/大纲要求 + 目标字数（默认{{作品设置:单章字数下限}}-{{作品设置:单章字数上限}}）
> **输出**：仿写章节 + 风格相似度报告

---

## 流程概览

```
样本输入 → 风格提取（统计+结构+语言指纹）→ 风格规则生成 → 约束生成 → Humanizer去AI化 → 验证
```

---

## 步骤1：样本风格提取

### 1.1 统计特征提取

运行命令：
```bash
指标自检（文风六卡·卡6 体检清单）
```

提取以下硬门禁指标作为仿写目标值：
- σ²（句长方差）
- TTR（用词多样性）
- Pσ²（段长方差）
- BurstCV（句长变异系数）
- ParaCV（段长变异系数）
- 3gramRep（3-gram重复率）
- 3gramUniq（3-gram唯一率）

同时提取参考指标：
- 对话占比
- 标点CV
- Telling密度
- 具体度

### 1.2 叙事结构提取

对样本文件进行AI分析，提取以下结构特征：

**Scene-Sequel模式序列**：
- 识别样本中每个场景的类型（Scene/Sequel）
- Scene = Goal→Conflict→Disaster
- Sequel = Reaction→Dilemma→Decision
- 记录场景数量和排列顺序

**冲突层级**：
- 提取每个场景的冲突类型（人际/内心/环境/社会）
- 标记冲突升级路径

**情绪曲线**：
- 按段落标记情绪强度（1-10）
- 记录情绪起伏的波峰和波谷

**入场方式**：
- dialogue（对话开场）/ scene（场景开场）/ action（动作开场）/ introspection（内心开场）

**章末钩子类型**：
- 参考 `suspense-hooks.md` 的10种钩子类型
- 标记样本使用的钩子类型

### 1.3 语言指纹提取

**句长分布**：
- 短句（≤8字）占比
- 中句（9-15字）占比
- 长句（≥16字）占比
- 平均句长

**对话特征**：
- 对话占比（%）
- 平均对话长度
- 对话与叙述的交替模式

**感官偏好**：
- 触觉/视觉/听觉/味觉/嗅觉描写密度
- 参考词库：`tools/指标自检（文风六卡·卡6 体检清单）` 中的 SENSORY_WORDS

**标点模式**：
- 逗号/句号/省略号/破折号使用频率
- 标点间距变异系数

**高频词/口头禅**：
- 提取出现≥3次的实词
- 识别角色专属口头禅

## 步骤2：风格规则生成

将步骤1的提取结果转化为可执行的写作约束规则：

### 2.1 统计目标规则

```yaml
句长目标:
  sigma2目标值: <样本σ²值>
  短句占比目标: <样本短句占比>
  长句占比目标: <样本长句占比>

用词目标:
  TTR目标值: <样本TTR值>

节奏目标:
  段长分布: <样本Pσ²值>
  BurstCV目标: <样本BurstCV值>
  ParaCV目标: <样本ParaCV值>

对话目标:
  对话占比目标: <样本对话占比>
```

### 2.2 结构模板规则

```yaml
叙事结构:
  场景序列: <Scene-Sequel排列>
  冲突模式: <冲突层级路径>
  情绪曲线: <波峰波谷模式>
  入场方式: <样本入场方式>
  章末钩子: <样本钩子类型>
```

### 2.3 语言指纹规则

```yaml
语言风格:
  句长偏好: <短句为主/长短交替/长句铺陈>
  感官偏好: <触觉优先/视觉优先/...>
  标点习惯: <样本标点模式>
  高频词: <样本高频词列表>
```

## 步骤3：仿写生成

### 3.1 加载基础prompt

依次读取以下文件：
1. `writer-prompt.md` — 作为草稿生成的系统prompt
2. `文风六卡.md` — L3常驻层，随writer-prompt一起注入（每句四关：语气/语序/AI味/标点）
3. `genre-guides.md` — 提取当前题材的对话占比、爽点密度等参数
4. `anti-ai-patterns.md` — 提取4层反AI约束
5. `suspense-hooks.md` — 选择本章钩子类型

### 3.2 注入风格约束

在writer-prompt.md的基础上，追加步骤2生成的风格规则作为硬约束：
- 统计目标值作为写作目标（非强制，但偏差≤20%）
- 结构模板作为场景规划参照
- 语言指纹作为用词和句式参照

### 3.3 生成草稿

基于用户给定的主题/大纲，遵循风格约束，生成{{作品设置:单章字数下限}}-{{作品设置:单章字数上限}}字草稿。

**R1-R5铁律必须执行**：
- R1：禁止情绪标签化（"他感到愤怒"→用身体反应展示）
- R2：强制内心过程≥20%
- R3：每200字内必须有短句(≤5字)+长句(≥20字)
- R4：禁止场景结尾总结
- R5：对话必须携带潜台词

---

## 步骤4：去AI化（单 pass）

加载 `humanizer-prompt.md`，执行**单 pass**：一次性扫描10类AI模式（AI词汇/夸张抬高/同义词循环/叙事犹豫/机械排比/泛化描述/对话标签滥用/情感标签/华丽堆砌/系动词回避）并当场重写（保留作者 voice + 角色对话模式）；去AI效果交由 `指标自检（文风六卡·卡6 体检清单） --aitext` 一次复核，不再分 Detection/Rewrite/Audit 三遍。

---

## 步骤5：仿写验证

### 5.1 风格相似度

```bash
指标自检（文风六卡·卡6 体检清单）
```

评分标准：
- ≥75分：达标（风格模仿成功）
- 50-74分：部分模仿（统计指标偏差较大）
- <50分：失败（风格差异显著）

### 5.2 抄袭检查

```bash
指标自检（文风六卡·卡6 体检清单）
```

要求：连续8字以上雷同≤2处

### 5.3 AI检测

```bash
指标自检（文风六卡·卡6 体检清单）
```

要求：
- 7项硬门禁指标全部通过
- AIText比例≤30%

## 步骤6：输出

### 6.1 仿写章节

保存仿写结果到用户指定路径或默认路径 `output/imitate/`

### 6.2 风格相似度报告

输出格式：
```
=== 仿写验证报告 ===

风格相似度评分：XX/100

统计指标对比：
| 指标 | 样本值 | 仿写值 | 偏差 | 达标 |
|------|--------|--------|------|------|
| σ²   | XX     | XX     | XX%  | ✓/✗ |
| TTR  | XX     | XX     | XX%  | ✓/✗ |
| ...

抄袭检查：X处雷同（≤2处达标）
AI检测：XX% AI比例（≤30%达标）

结论：达标/不达标
改进建议：...
```

### 6.3 改进建议

若不达标，输出具体改进方向：
- 统计指标偏差最大的项及调整建议
- 叙事结构差异及调整建议
- 语言指纹偏差及调整建议
