# 续写流程指令

> **触发条件**：用户说"续写""接着写""继续往下写"时执行
> **输入**：已有章节目录路径 + 续写章数（默认1章）+ 是否走门禁（默认否）
> **输出**：续写章节 + 更新的动态轨文件
> **核心原则**：续写默认不走G1-G7门禁循环，直接生成章节。用户明确要求时才走门禁。

***

## 流程概览

```
已有章节输入 → 动态轨重建 → 续写规划 → 生成下一章 → 输出
                                                    ↓（可选）
                                              门禁检查（用户要求时）
```

***

## 步骤1：动态轨增量更新

> **性能原则**：动态轨台账由每章 G7 落盘持续维护，本身就是最新状态。因此**默认不重扫历史正文**，只对"上一章正文"做增量提取并合并进台账，杜绝每章全文重读导致"越写越慢"。

**更新策略（三选一，系统判定）**：

| 场景          | 动作                         |
| ----------- | -------------------------- |
| 台账齐全（常态）    | 只读台账 + 对上一章正文做增量提取，更新受影响条目 |
| 台账缺失/损坏     | 一次性全量重建：扫描全部已有章节           |
| 用户要求"重建/重扫" | 全量重建                       |

**台账分类**：追加型（summaries/established-facts/used-tropes/timeline/main-quest/location-index/compliance-log/gate-log/decisions/emotion-beat/progress）只 append；状态覆盖型（character-state/current-state/continuity-brief/fingerprint/next-hook）只更新最近态；台账计算型（foreshadowing/main-quest/subplot/used-tropes/emotion-beat 的超期/停滞预警）由台账内章号差值计算，不重读正文。

> 下方各子节点**默认对"上一章正文"做增量提取**（仅全量重建时才扫描全部已有章节）。

### 1.1 进度（章卡/卷元数据） — 进度追踪

扫描已有章节文件，提取：

* 当前章号（最后一个章节文件的章号）

* 已完成章数

* 总字数

* 当前卷号（如文件名含卷号）

写入 `进度（章卡/卷元数据）`

### 1.2 连续性·章节摘要 — 章节摘要

对每章生成200-300字摘要，包含：

* 本章核心事件（1-2句）

* 关键冲突和转折

* 新出场角色

* 章末钩子内容

* 情绪基调

**最近5章**生成详细摘要（500字），早期章节生成简摘要（200字）。

写入 `连续性·章节摘要`

### 1.3 人物卡 — 角色状态

从已有章节提取每个角色的当前状态：

* 物理状态（位置、健康、装备）

* 心理状态（情绪、目标、内心冲突）

* 关系状态（与其他角色的关系变化）

* 语言指纹（口头禅、标志性动作、说话习惯）

**提取方式**：扫描每章中该角色的对话和描写，记录最后出现的状态。

写入 `人物卡`

### 1.4 伏笔 — 伏笔追踪

扫描已有章节，提取：

* 已种植伏笔（标记种植章号、内容、预期回收位置）

* 已回收伏笔（标记回收章号）

* 未回收伏笔（按章号排序，标记逾期程度）

**识别信号**：异常物品、未解释现象、角色隐瞒的信息、预言/梦境、神秘人物

写入 `伏笔`

### 1.5 世界观·已确立事实 — 已确立事实

提取已确立的世界观和情节事实：

* 世界规则（力量体系、社会结构、地理）

* 已发生关键事件（时间线）

* 已揭示的角色背景

* 已确立的人物关系

写入 `世界观·已确立事实`

### 1.6 章卡·下钩清单 — 钩子台账

从最近章节提取：

* 章末钩子类型（参考 `suspense-hooks.md` 的10种类型）

* 待回报钩子列表

* 逾期钩子（超过5章未回报）

写入 `章卡·下钩清单`

### 1.7 其他动态轨文件

| 文件                   | 提取内容                     |
| -------------------- | ------------------------ |
| `used-tropes.md`     | 已使用的套路/桥段及使用章号           |
| `emotion-beat.md`    | 情感弧线记录（每章情绪强度、波峰波谷）      |
| `subplot-tracker.md` | 副线进度（每条副线的起始、当前状态、下一步预期） |
| `decisions.md`       | 关键决策记录（角色做出的重要选择及后果）     |
| `compliance-log.md`  | 合规日志（字数/节奏统计）            |
| `gate-log.md`        | 门禁日志（初始化为"续写模式-未走门禁"）    |
| `00_INDEX.md`        | 更新索引，标记续写起点和模式           |

### 1.8 角色语言指纹（文风六卡·卡6 自检） — 语言指纹

从最近5章提取角色语言指纹：

* phrases：角色高频口头禅

* actions：角色标志性动作

* style：句长分布、感官偏好、对话风格

写入 `角色语言指纹（文风六卡·卡6 自检）`

### 1.9 时间线 — 时间线追踪

从已有章节提取时间线：

* 故事开始时间和当前故事时间

* 每章对应的故事内时间节点

* 时间跳转记录（章间时间跨度）

* 角色年龄变化（出场年龄→当前年龄）

写入 `时间线`

### 1.10 卷/主线 — 主线任务追踪

从已有章节推断主线任务：

* 主角终极目标

* 阶段任务列表（已领取/进行中/已完成）

* 每章主线推进记录

* 当前主线停滞检查

写入 `卷/主线`

### 1.11 世界观·地点索引 — 地点索引

从已有章节提取地点信息：

* 地点注册表（名称/类型/出场章节）

* 空间关系表（地点间距离和通勤时间）

* 场景布局记录（重要场景内部描写）

写入 `世界观·地点索引`

### 1.12 章卡·承接清单 — 写前承接清单

从上一章正文提取尾幕快照（供下一章 R-C1 承接使用）：

* 尾幕时刻（故事内时间）

* 尾幕地点

* 在场 POV 角色

* 情绪基调

* 最后一句钩子（全文引用，用于开场重述锚点）

写入 `章卡·承接清单`

### 1.13 连续性·当前态 — 当前态

从上一章结尾提取：

* 此刻时刻（与 `timeline.md` 交叉校验）

* 此刻地点（与 `location-index.md` 交叉校验）

* 在场角色

* 待处理事项 / 待接事件

写入 `连续性·当前态`

### 1.14 连续性·信息差矩阵 — 信息差矩阵

从已有章节提取三方知情状态：

* 读者知 / 角色知 / 叙述者知的差异

* 已揭示信息与未揭示悬念

* 计划揭示的线索

写入 `连续性·信息差矩阵`

## 步骤2：续写规划

### 2.1 大纲推断

基于已有章节，AI分析以下要素：

* 主线进展（当前处于什么阶段：开局/发展/高潮/收尾）

* 未解决的冲突

* 待回收的伏笔

* 角色弧线走向

生成后续3-5章大纲，每章包含：

* 核心事件

* 冲突类型

* 爽点设计（参考 `genre-guides.md`）

* 钩子安排

写入 卷规划·续排（章卡）

### 2.2 节奏规划

基于已有章节的节奏模式，推断后续节奏：

* 统计已有章节的爽点分布

* 判断当前是否需要"张"（蓄势）还是"弛"（释放）

* 规划下一个爽点的位置

参考 `genre-guides.md` 中的节奏要求。

***

## 步骤3：生成下一章

### 3.1 加载上下文

按\*\*分层（省 token）\*\*读取：

**必载（全文注入写作 prompt，13项）**：

1. `连续性·章节摘要` — 最近5章摘要
2. `人物卡` — 角色当前状态含年龄/外貌
3. `伏笔` — 待回收伏笔含类型/优先级
4. `章卡·下钩清单` — 待回报钩子
5. `世界观·已确立事实` — 已确立事实
6. `时间线` — 时间线和角色年龄
7. `卷/主线` — 主线任务进度
8. `世界观·地点索引` — 地点和空间关系
9. 卷规划·续排（章卡） — 续写大纲
10. `章卡·承接清单` — 写前承接清单：上章尾幕锚点全文引用（执行R-C1）
11. `连续性·当前态` — 当前态：此刻时刻/地点/在场角色/待接事件
12. `连续性·信息差矩阵` — 信息差矩阵：读者/角色/叙述者知情现状
13. `作品设置` — 篇幅档位（本章字数目标/节奏章型）

**按需载（不注入全文，仅取一行提示）**：

* `已用套路（章卡元数据）` — 取"冷却期内已用套路"一行，作"本章避开"提示

* `情感弧线（章卡元数据）` — 取"当前情感方向"一行（连续同向预警在 G6 检查）

* `副线记录（章卡元数据）` — 取"待推进副线"一行

### 3.2 加载写作约束

依次读取：

1. `writer-prompt.md` — 草稿生成系统prompt
2. `文风六卡.md` — L3常驻层，随writer-prompt一起注入（每句四关：语气/语序/AI味/标点）
3. `genre-guides.md` — 题材参数（对话占比/爽点密度/铺垫容忍）
4. `anti-ai-patterns.md` — 4层反AI约束
5. `suspense-hooks.md` — 钩子系统
6. `character-templates.md` — 角色语言档案

### 3.3 Scene-Sequel场景规划

读取 `scene-plan.md` 模板，规划本章场景结构：

* 每个场景填写 Goal→Conflict(3层)→Disaster 或 Reaction→Dilemma→Decision

* 禁止"干净成功"结尾

* 场景数量2-4个

### 3.4 技法卡路由（L2 弹药）

加载 `技法卡路由.md`，执行章型判定 + 取卡 + 亮凭证：

1. **判章型**：输入本章大纲条目 + `章卡节奏标记` + `章卡规划区` 爽点模式
2. **查映射表**：命中卡族 → 到 `技法卡/` 对应维度分册检索，取 2-5 张最对口卡
3. **提结论**：每张卡只取 1-3 条可落笔结论（不整卡搬运）
4. **亮凭证**：将【技法卡匹配凭证】（章型 + 已取卡名 + 落卡结论）写入 `章卡规划区` 的凭证区

> 凭证必须真在分册里检索到并落结论，只写卡名不落结论 = 未执行。无对口卡时按 G3 引擎约束写，凭证注明 fallback。

### 3.5 生成草稿

* 字数：参考{{作品设置:单章字数下限}}-{{作品设置:单章字数上限}}字（不达标不阻塞，仅预警）

* **R1-R5铁律必须执行**：

  * R1：禁止情绪标签化

  * R2：强制内心过程≥20%

  * R3：每200字内必须有短句(≤5字)+长句(≥20字)

  * R4：禁止场景结尾总结

  * R5：对话必须携带潜台词

* **R-C1承接硬约束**：本章开场前2个Scene内必须显式重述 `continuity-brief.md` 的≥3个锚点（尾幕时刻/地点/POV/情绪），并接续P0待接事件

* 承接上一章章末钩子

* 部署本章章末钩子

* 对话占比按场景类型动态调整（冲突60-80%/日常40-60%/过渡20-40%）

### 3.6 Humanizer去AI化（单 pass）

加载 `humanizer-prompt.md`，执行**单 pass**：检测+改写一次完成（扫描 AI 模式并当场改写），去AI效果交由 `指标自检（文风六卡·卡6 体检清单） --aitext` 一次复核，不再分 Detection/Rewrite/Audit 三遍。

***

## 步骤4：质检模式执行

> **首次续写前询问用户质检模式**，选择后写入 `项目索引（作品设置·北极星）`，后续不再重复提示。
> 三种模式：`QC_FULL`（质检+自动重写）/ `QC_CHECK`（仅质检不重写）/ `QC_SKIP`（跳过质检）。

### 4.1 按模式执行门禁

| 门禁       | QC\_FULL  | QC\_CHECK | QC\_SKIP |
| -------- | --------- | --------- | -------- |
| G4 平台规则  | ✅ 执行+自动修复 | ✅ 执行+报告   | ⏭️ 跳过    |
| G5 指标门禁  | ✅ 执行+自动修复 | ✅ 执行+报告   | ⏭️ 跳过    |
| G6 一致性门禁 | ✅ 执行+自动修复 | ✅ 执行+报告   | ⏭️ 跳过    |

### 4.2 G4 平台规则门

* 字数：参考{{作品设置:单章字数下限}}-{{作品设置:单章字数上限}}字（不达标不阻塞，仅预警）

* 节奏：不连续2章无进展

* 钩子：章末必须有钩子

### 4.3 G5 metrics指标门

```bash
指标自检（文风六卡·卡6 体检清单）
```

* 7项硬门禁全部通过

* AIText比例≤30%

### 4.4 G6 一致性门

* 本章开头是否与上章结尾衔接

* 角色状态是否连续（含年龄/外貌/知识状态）

* 伏笔是否有新种植或回收（按scope预警）

* 时间线是否一致

* 主线任务是否推进

***

## 步骤5：输出

### 5.1 续写章节

保存到用户指定路径或默认 `chapters/` 目录。

### 5.2 更新动态轨

续写完成后，更新以下动态轨文件：

* `progress.md` — 章号+1

* `summaries.md` — 添加本章摘要

* `character-state.md` — 更新角色状态（含年龄/外貌变化）

* `foreshadowing.md` — 新种植/回收的伏笔（含类型/优先级）

* `next-hook.md` — 新部署/回报的钩子

* `used-tropes.md` — 本章使用的套路

* `emotion-beat.md` — 本章情绪强度

* `gate-log.md` — 门禁结果（如走了门禁）

* `timeline.md` — 本章时间节点/时间跳转/年龄变化

* `main-quest.md` — 本章主线推进记录

* `location-index.md` — 新出现的地点/场景布局

* `continuity-brief.md` — 重写本章尾幕快照（作为下一章的承接清单）

* `current-state.md` — 更新此刻时刻/地点/在场角色/待接事件/情绪基调

* `information-gap.md` — 更新本章揭示的信息条目与各方知情状态

### 5.3 下一章建议

输出后续续写建议：

* 下章核心事件

* 待回收伏笔提醒

* 节奏建议（张/弛）

> **与标准章节循环的区别**：
>
> * 标准循环（ORCHESTRATOR.md）：G1→G2→G3→G4→G5→G6→G7 全部门禁
>
> * 续写流程：动态轨重建→生成→输出（默认跳过门禁）
>
> * 续写流程复用G3写作门的核心能力（writer-prompt + R1-R5 + Humanizer），但不强制走G1-G7循环
>
> * 用户可通过"走门禁"指令切换到完整门禁模式
