# ORCHESTRATOR-modes.md — 独立流程与特殊模式

> **所属系统**：novelOps v2.3 小说写作系统
> **主文件**：`ORCHESTRATOR.md`（章节循环 G1-G7 门禁）
> **本文件包含**：仿写模式、续写模式、前3章特殊流程

***

## 一、仿写模式

> **触发条件**：用户说"仿写""模仿写""学习这个风格写"时执行。
> **流程文件**：`imitate-prompt.md`
> **输入**：样本文件路径 + 仿写主题/大纲要求 + 目标字数（默认{{作品设置:单章字数下限}}-{{作品设置:单章字数上限}}）
> **特点**：独立于G1-G7门禁循环，不依赖22个动态轨文件，适用于无项目背景的单章仿写场景。

**执行操作**：读取 `imitate-prompt.md`，按6步流程执行：

1. **样本风格提取**：`指标自检（文风六卡·卡6 体检清单）` 提取统计特征 + AI分析叙事结构 + 提取语言指纹
2. **风格规则生成**：将提取结果转化为可执行的写作约束（统计目标/结构模板/语言指纹）
3. **仿写生成**：加载 `writer-prompt.md` + 风格约束 + R1-R5铁律，生成草稿
4. **去AI化**：加载 `humanizer-prompt.md`，执行单pass（检测+改写合并，指标自检（文风六卡·卡6 体检清单）复核）
5. **仿写验证**：`指标自检（文风六卡·卡6 体检清单） --compare` 风格相似度 + `--plagiarism` 抄袭检查 + `--aitext` AI检测
6. **输出**：仿写章节 + 风格相似度报告 + 改进建议

***

## 二、续写模式

> **触发条件**：用户说"续写""接着写""继续往下写"时执行。
> **流程文件**：`continue-prompt.md`
> **输入**：已有章节目录路径 + 续写章数（默认1章）+ 是否走门禁（默认否）
> **特点**：默认不走G1-G7门禁循环，直接生成章节。用户明确要求"走门禁"时才执行G4/G5/G6检查。

**执行操作**：读取 `continue-prompt.md`，按5步流程执行：

1. **动态轨增量更新**：读台账 + 对上一章正文做增量提取（summaries/character-state/foreshadowing/next-hook/timeline/main-quest/location-index等）；仅台账缺失/损坏时全量重建
2. **续写规划**：基于已有章节推断后续大纲和节奏
3. **生成下一章**：加载动态轨上下文 + writer-prompt + R1-R5铁律 + Humanizer去AI化
4. **可选门禁**：默认跳过。用户要求时执行G4(平台规则)/G5(metrics)/G6(一致性)
5. **输出**：续写章节 + 更新动态轨 + 下一章建议

> **与标准章节循环的区别**：标准循环走完整G1→G2→G3→G4→G5→G6→G7，续写流程默认跳过门禁，复用G3写作核心能力但不强制走循环。

***

## 三、前3章特殊流程

> **原则**：前3章决定留存率，是全书的"生死线"。番茄编辑审稿时间约几分钟，前300字决定生死。

### 3.1 前3章质量要求

| 维度    | 标准             | 反面示例         |
| ----- | -------------- | ------------ |
| 前300字 | 直接冲突切入，无铺垫描写   | 用环境/体感描写开场铺垫 |
| 第一章   | 重生触发 + 初次打脸/反转 | 只有日常交代，无冲突事件 |
| 第二章   | 打脸升级 + 情感线种子   | 冲突原地打转，不升级   |
| 第三章   | 第一个小爽点释放       | 主角仍被动挨打，无爽点  |
| σ²    | ≥10（人写区间）      | 句式单一（AI区间）   |
| 字数    | {{作品设置:单章字数下限}}-{{作品设置:单章字数上限}}字（参考） | 仅预警，不阻塞      |

### 3.2 前3章特殊流程

1. **双重G5检查**：前3章的metrics指标需达到人写区间（σ²>10, TTR>0.48, BurstCV>0.50, Pσ²>28, ParaCV>0.40, 3gramUniq>0.90），而非仅达标
2. **开篇钩子审查**：前300字必须包含至少1个冲突元素（背叛/危机/反转/悬念）
3. **读者代入测试**：模拟读者视角，检查"前3章是否让人想继续读"
4. **额外打磨轮次**：前3章允许最多2次重写（普通章1次）
5. **用户强制审核**：前3章完成后必须经过G8用户审核，不可跳过
